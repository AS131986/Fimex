## Предусловия

Клиенты с активной/истёкшей подпиской и блокировкой, корпоративный пользователь и реселлер; удалённый и заблокированный реселлер; основной аккаунт без подписки и заблокированный. Иметь действующие идентификаторы/пароли, два устройства, аккаунт с языком/темой, отличающимися от устройства, и сборку с обязательным обновлением. При отсутствии состояния или сборки зависимая проверка Blocked.

## ID

- [ ] **LOGIN-ID-01 — Вход клиента по ID**

  <details>
  <summary>Подробности проверки</summary>

  - Клиент входит по действующему ID вида `F:01011` и действующему паролю.

  </details>

- [ ] **LOGIN-ID-02 — Вход корпоративного пользователя по ID**

  <details>
  <summary>Подробности проверки</summary>

  - Корп входит по действующему ID вида `F:01011/A` при доступном основном аккаунте.

  </details>

- [ ] **LOGIN-ID-03 — Вход реселлера по ID**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер входит по действующему ID вида `F:01011/1` при доступном основном аккаунте.

  </details>

- [ ] **LOGIN-ID-04 — Допустимость ID с разным количеством цифр**

  <details>
  <summary>Подробности проверки</summary>

  - Действующие ID с разным количеством цифр принимаются; фиктивные ID не считать позитивными данными.

  </details>

- [ ] **LOGIN-ID-05 — Независимость букв ID от регистра**

  <details>
  <summary>Подробности проверки</summary>

  - Регистр первой буквы и корпоративного буквенного суффикса не влияет на вход.

  </details>

- [ ] **LOGIN-ID-06 — Обязательность двоеточия в ID**

  <details>
  <summary>Подробности проверки</summary>

  - Отсутствующее двоеточие не принимается как правильный формат ID.

  </details>

- [ ] **LOGIN-ID-07 — Обязательность суффикса дочернего аккаунта**

  <details>
  <summary>Подробности проверки</summary>

  - Отсутствующие slash/суффикс не принимаются как ID дочернего аккаунта.
  - Использовать пароль дочернего аккаунта; корневой ID сам по себе может быть валидным ID клиента.

  </details>

- [ ] **LOGIN-ID-08 — Отклонение кириллицы в буквенных частях ID**

  <details>
  <summary>Подробности проверки</summary>

  - Кириллическая буква вместо латинской в первой части или корпоративном суффиксе не принимается как валидный формат.

  </details>

- [ ] **LOGIN-ID-09 — Отказ входа с неверным ID или паролем**

  <details>
  <summary>Подробности проверки</summary>

  - Действующий ID с неверным паролем и несуществующий ID не дают успешного входа.

  </details>

  <details>

  - UI и момент реакции — LOGIN-Q06.

  <details>
  <summary>Подробности проверки</summary>

  - Это единственная проверка обязательного обновления в данном наборе.

  </details>
