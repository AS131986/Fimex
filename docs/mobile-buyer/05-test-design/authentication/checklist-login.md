## Предусловия

Клиенты с активной/истёкшей подпиской и блокировкой, корпоративный пользователь и реселлер; удалённый и заблокированный реселлер; основной аккаунт без подписки и заблокированный. Иметь действующие идентификаторы/пароли, два устройства, аккаунт с языком/темой, отличающимися от устройства, и сборку с обязательным обновлением. При отсутствии состояния или сборки зависимая проверка Blocked.

## Форма

- [ ] **LOGIN-FORM-01** — Отображаются идентификатор, Password, переключатель видимости, Login, восстановление, регистрация и возврат.
- [ ] **LOGIN-FORM-02** — При пустом идентификаторе или пароле Login неактивна; при заполнении обоих полей активируется.
- [ ] **LOGIN-FORM-03** — Валидация срабатывает при закрытии клавиатуры.
- [ ] **LOGIN-FORM-04** — Показ/скрытие пароля не изменяет его значение.

## Email

- [ ] **LOGIN-EMAIL-01** — Клиент с активной подпиской входит по email и верному паролю.
- [ ] **LOGIN-EMAIL-02** — Корпоративный пользователь входит по email при доступном основном аккаунте.
- [ ] **LOGIN-EMAIL-03** — Разный регистр букв одного email не меняет идентичность аккаунта.
- [ ] **LOGIN-EMAIL-04** — Пробелы нельзя ввести в email; вставка — открытый вопрос REG-Q04 в регистрации.
- [ ] **LOGIN-EMAIL-05** — Некорректный email и корректный, но отсутствующий email не дают успешного входа; точные сообщения — LOGIN-Q02.
- [ ] **LOGIN-EMAIL-06** — Email с неверным паролем не даёт войти.
- [ ] **LOGIN-EMAIL-07** — Реселлер не может войти по email; разрешён только ID.

## ID

- [ ] **LOGIN-ID-01** — Клиент входит по действующему ID вида `F:01011` и действующему паролю.
- [ ] **LOGIN-ID-02** — Корп входит по действующему ID вида `F:01011/A` при доступном основном аккаунте.
- [ ] **LOGIN-ID-03** — Реселлер входит по действующему ID вида `F:01011/1` при доступном основном аккаунте.
- [ ] **LOGIN-ID-04** — Действующие ID с разным количеством цифр принимаются; фиктивные ID не считать позитивными данными.
- [ ] **LOGIN-ID-05** — Регистр первой буквы и корпоративного буквенного суффикса не влияет на вход.
- [ ] **LOGIN-ID-06** — Отсутствующее двоеточие не принимается как правильный формат ID.
- [ ] **LOGIN-ID-07** — Отсутствующие slash/суффикс не принимаются как ID дочернего аккаунта. Использовать пароль дочернего аккаунта; корневой ID сам по себе может быть валидным ID клиента.
- [ ] **LOGIN-ID-08** — Кириллическая буква вместо латинской в первой части или корпоративном суффиксе не принимается как валидный формат.
- [ ] **LOGIN-ID-09** — Действующий ID с неверным паролем и несуществующий ID не дают успешного входа.

## Статусы

- [ ] **LOGIN-STATUS-01** — Заблокированный клиент получает ошибку авторизации и не получает доступ к покупкам.
- [ ] **LOGIN-STATUS-02** — Клиент с истёкшей подпиской авторизуется; alert о продлении перекрывает главную, покупки недоступны.
- [ ] **LOGIN-STATUS-03** — Клиент с истёкшей подпиской может перейти к продлению и выйти из аккаунта.
- [ ] **LOGIN-STATUS-04** — Удалённый реселлер получает ошибку авторизации.
- [ ] **LOGIN-STATUS-05** — Заблокированный реселлер авторизуется, видит сообщение о блокировке, главная недоступна для покупок.
- [ ] **LOGIN-STATUS-06** — Корп при отсутствии подписки основного аккаунта видит сообщение о необходимости связаться с основным аккаунтом; главная/покупки недоступны.
- [ ] **LOGIN-STATUS-07** — Реселлер при отсутствии подписки основного аккаунта видит такое же по смыслу сообщение; главная/покупки недоступны.
- [ ] **LOGIN-STATUS-08** — При блокировке основного аккаунта корп и реселлер не получают доступ к покупкам; точный результат авторизации/UI — LOGIN-Q04.

## Настройки, сессия и обновление

- [ ] **LOGIN-PREF-01** — После входа используется язык аккаунта с backend, даже если язык устройства или выбор до входа другой.
- [ ] **LOGIN-PREF-02** — После входа используется тема аккаунта с backend, даже если тема устройства или выбор до входа другая.
- [ ] **LOGIN-SESSION-01** — Вход того же аккаунта на втором устройстве завершает первую сессию; первое устройство не остаётся авторизованным. UI и момент реакции — LOGIN-Q06.
- [ ] **LOGIN-UPDATE-01** — После авторизации на версии с обязательным обновлением alert блокирует использование; ссылка открывает App Store для Fimex; возврат без обновления оставляет alert и блокировку. Это единственная проверка обязательного обновления в данном наборе.

## Навигация и UI

- [ ] **LOGIN-NAV-01** — Forgot your password? открывает ввод email восстановления.
- [ ] **LOGIN-NAV-02** — Create an account открывает регистрацию; возврат со входа открывает стартовый экран.
- [ ] **LOGIN-UI-01** — Поля, ошибки и кнопки доступны на поддерживаемых iPhone с клавиатурой, в русском/английском интерфейсе и обеих темах.
