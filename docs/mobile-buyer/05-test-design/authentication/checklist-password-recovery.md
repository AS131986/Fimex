- [ ] **RESETMSG-UI-01** — Отображаются сообщение о письме, адрес получателя, Continue и возврат.
- [ ] **RESETMSG-EMAIL-01** — Показанный адрес относится к текущему запросу восстановления, а не к предыдущему аккаунту.
- [ ] **RESETMSG-MAIL-01** — На указанную тестовую почту приходит письмо с четырёхзначным кодом восстановления; надпись на экране не засчитывать как подтверждение доставки. Допустимое время доставки не задано.
- [ ] **RESETMSG-NAV-01** — Continue открывает ввод кода для этого же email.
- [ ] **RESETMSG-UI-02** — Длинный email и локализованный текст не скрывают Continue на поддерживаемых iPhone.

Возврат, ошибка отправки и таймер требуют RESETMSG-Q01–Q03.

### Предусловия

- [ ] **RESETCODE-UI-01** — Отображаются четыре позиции, email текущего восстановления, таймер, Continue и возврат.
- [ ] **RESETCODE-INPUT-01** — Код восстановления содержит ровно четыре цифры.
- [ ] **RESETCODE-INPUT-02** — Неполный код не подтверждает восстановление.
- [ ] **RESETCODE-INPUT-03** — Буквы и специальные символы не принимаются как допустимый код; механизм ограничения ввода не задан.
- [ ] **RESETCODE-INPUT-04** — Корректный код открывает ввод нового пароля для текущего аккаунта. Способ запуска проверки — REGCODE-Q04.
- [ ] **RESETCODE-INPUT-05** — Неверный код не позволяет перейти к смене пароля; конкретные ошибка/очистка — REGCODE-Q05.
- [ ] **RESETCODE-RESEND-01** — Повторная отправка недоступна до истечения 120 секунд и доступна после.
- [ ] **RESETCODE-RESEND-02** — Повторное письмо направляется на текущий email восстановления; действительность старого кода — REGCODE-Q03.
- [ ] **RESETCODE-UI-02** — Цифровая клавиатура не перекрывает код и Continue на поддерживаемых iPhone.

Не добавлять фиксированные ожидания срока действия, лимитов и изоляции регистрационного/восстановительного кода до согласования открытых вопросов.

## Новый пароль и автоматический вход

Проверки не выполнялись. `[ ]` — Not run. Результаты отдельно: Pass / Fail / Blocked / Not run / N/A. Зависимые ожидания Blocked до уточнения Q. ID стабильные. [Правила](../../04-business-rules/authentication.md#password-reset-new-password).

### Предусловия

Подтверждён код восстановления клиента/корпа. Подготовить активную подписку для позитивного входа, истёкшую подписку клиента/основного аккаунта для ограничений; второе устройство с активной сессией. Для корпа условия основного аккаунта заданы явно.

### Форма и пароль

- [ ] **NEWPASS-FORM-01** — Отображаются оба поля пароля, отдельные переключатели видимости, Save и возврат.
- [ ] **NEWPASS-FORM-02** — При пустых полях Save неактивна; после заполнения активируется. Обязательность Confirmation — REG-Q02.
- [ ] **NEWPASS-FORM-03** — Валидация срабатывает при закрытии клавиатуры.
- [ ] **NEWPASS-PASS-01** — 7 разрешённых символов с заглавной буквой и цифрой не проходят минимальную длину.
- [ ] **NEWPASS-PASS-02** — 8 разрешённых символов с заглавной буквой и цифрой проходят валидацию.
- [ ] **NEWPASS-PASS-03** — 99 и 100 разрешённых символов с обязательными категориями проходят валидацию.
- [ ] **NEWPASS-PASS-04** — 101 символ не принимается как допустимый пароль; механизм — REG-Q05.
- [ ] **NEWPASS-PASS-05** — Пароль без заглавной буквы или без цифры отклоняется; проверить каждое условие отдельно.
- [ ] **NEWPASS-PASS-06** — Латинские буквы обоих регистров, цифры и точка допустимы при выполнении остальных условий.
- [ ] **NEWPASS-PASS-07** — Кириллица, пробел, дефис, подчёркивание, `@` и emoji не принимаются.
- [ ] **NEWPASS-PASS-08** — Отсутствие точки или строчной буквы не мешает принять пароль, удовлетворяющий подтверждённым условиям.
- [ ] **NEWPASS-PASS-09** — Показ/скрытие каждого поля не изменяет значение и не переключает второе поле.
- [ ] **NEWPASS-PASS-10** — Совпадение и несовпадение Confirmation, включая отличие регистра, проверить после REG-Q02.

### Сохранение и вход

- [ ] **NEWPASS-SAVE-01** — Успешное сохранение нового пароля клиента с активной подпиской сразу авторизует его, без дополнительного ввода учётных данных.
- [ ] **NEWPASS-SAVE-02** — Успешное сохранение нового пароля корпа при доступном основном аккаунте сразу авторизует его.
- [ ] **NEWPASS-SAVE-03** — После выхода можно авторизоваться с установленным новым паролем и разрешённым для роли email/ID.
- [ ] **NEWPASS-STATUS-01** — После восстановления клиент с истёкшей подпиской видит alert продления; автоматический вход не даёт совершать покупки.
- [ ] **NEWPASS-STATUS-02** — После восстановления корпа без подписки основного аккаунта отображается сообщение о необходимости связаться с основным; главная/покупки недоступны.
- [ ] **NEWPASS-SESSION-01** — Автоматический вход после восстановления завершает сессию того же аккаунта на другом устройстве; две активные сессии не сохраняются. Конкретный UI — LOGIN-Q06.
- [ ] **NEWPASS-PREF-01** — После автоматического входа применяются язык и тема аккаунта с backend.
- [ ] **NEWPASS-UI-01** — Поля, ошибки и Save доступны с клавиатурой на поддерживаемых iPhone, в обоих языках и темах.

Обязательное обновление здесь не дублируется: по указанию пользователя оставлена одна проверка LOGIN-UPDATE-01. Блокировка на запросе кода проверяется в RESETEMAIL-STATUS-01.
