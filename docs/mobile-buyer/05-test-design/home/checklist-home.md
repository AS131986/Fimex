# Чек-лист: Главная — Fimex Buyer, iOS

## Область и использование

Хедер, каталог, переходы в прайс, Top sellers, загрузка, обновление и сброс Главной. Нижнее меню проверяется в [отдельном чек-листе](checklist-bottom-navigation.md). Для соседних экранов — только факт перехода; не дублировать полный прогон Price List, поиска, настроек или уведомлений.

Проверки не выполнялись. `[ ]` означает Not run, не Fail. Результаты фиксировать отдельно: Pass / Fail / Blocked / Not run / N/A. Зависимая от вопроса часть Blocked до согласования ожидаемого результата. ID стабильные и не переиспользуются.

## Предусловия и данные

- Доступный клиент, корп и реселлер; заблокированный реселлер для ограничения Главной.
- Бренд с категориями; бренд без категорий в структуре. Категория с моделями и без моделей в структуре. Бренд/категория/модель с единственным продаваемым товаром для отрицательных сценариев.
- Два бренда с различающимися категориями; две категории с различающимися моделями. Известный порядок из админки.
- Предложения со stock 49/50/51 и настройка глубины 50+; бренд/категория/модель без подходящих предложений и другие с подходящими.
- Настроенный Top sellers с несколькими брендами/моделями, вариант без настройки; возможность снять/отключить модель.
- Новые уведомления для аккаунта, возможность вызвать сетевую/серверную ошибку и получить текущее состояние через разрешённые инструменты.
- При отсутствии данных или возможности изменить конфигурацию зависимая проверка Blocked, а не Pass.

## Хедер

- [ ] **HOME-HEADER-01** — Tap по бургеру открывает настройки.
- [ ] **HOME-HEADER-02** — Tap по поисковой строке открывает экран поиска, а не ввод непосредственно на Главной.
- [ ] **HOME-HEADER-03** — Отображается USD; tap по валюте не открывает выбор валюты и не меняет USD.
- [ ] **HOME-HEADER-04** — Tap по кнопке уведомлений открывает экран уведомлений.
- [ ] **HOME-HEADER-05** — При наличии новых уведомлений отображается красная точка.
- [ ] **HOME-HEADER-06** — При новом уведомлении на открытой Главной точка появляется без ручного обновления. Допустимая техническая задержка не задана; измерение зафиксировать, произвольный SLA не назначать.
- [ ] **HOME-HEADER-07** — Открытие уведомлений считает их прочитанными; после возврата точка скрыта, если новых уведомлений за это время не было.
- [ ] **HOME-HEADER-08** — После прочтения приход нового уведомления снова включает точку.

## Видимость и порядок каталога

- [ ] **HOME-BRAND-01** — На Главной показаны бренды с продаваемыми товарами; бренды без продаваемых товаров скрыты.
- [ ] **HOME-BRAND-02** — Логотип каждой карточки соответствует бренду.
- [ ] **HOME-BRAND-03** — Порядок брендов соответствует известному порядку товаров из админки; не подменять ожидание алфавитной сортировкой.
- [ ] **HOME-CATALOG-01** — Категории без продаваемых товаров не отображаются; категории с подходящими товарами отображаются в своём бренде.
- [ ] **HOME-CATALOG-02** — Модели без продаваемых товаров не отображаются; модели с подходящими товарами отображаются в своей категории.
- [ ] **HOME-CATALOG-03** — После снятия последнего продаваемого товара и обновления Главной соответствующие модель/категория/бренд не остаются видимыми, если у них нет других продаваемых товаров.
- [ ] **HOME-CATALOG-04** — Снятие товара одного бренда не скрывает подходящие товары другого бренда.
- [ ] **HOME-CATALOG-05** — Отключённые в админке модели не отображаются как продаваемые; использовать подтверждённый уровень отключения без других продаваемых товаров в модели.

## Выбор бренда и категории

- [ ] **HOME-CAT-01** — Tap по бренду с категориями подсвечивает бренд и открывает его категории.
- [ ] **HOME-CAT-02** — У категорий отображаются корректные название и иконка.
- [ ] **HOME-CAT-03** — Порядок категорий соответствует известной конфигурации админки.
- [ ] **HOME-CAT-04** — Price-list в блоке категорий открывает прайс всего выбранного бренда, а не одной категории или предыдущего бренда.
- [ ] **HOME-CAT-05** — Бренд без категорий в структуре сразу открывает прайс. Отсутствие категорий только после фильтрации — HOME-Q02.
- [ ] **HOME-CAT-06** — Выбор категории подсвечивает её иконку и открывает модели именно этой категории.
- [ ] **HOME-CAT-07** — Смена бренда сбрасывает предыдущую категорию и прежний список моделей; категории нового бренда не смешиваются со старыми.
- [ ] **HOME-CAT-08** — Повторный tap по выбранному бренду сворачивает блок категорий; судьба вложенного выбора — HOME-Q03.
- [ ] **HOME-CAT-09** — Повторный tap по выбранной категории сворачивает её блок моделей; состояние подсветки после сворачивания — HOME-Q03.

## Модели и область прайса

- [ ] **HOME-MODEL-01** — Модели относятся к выбранной категории и бренду; их порядок соответствует конфигурации админки.
- [ ] **HOME-MODEL-02** — Price-list в блоке моделей открывает общий прайс всех товаров выбранной категории, а не всего бренда или другой категории.
- [ ] **HOME-MODEL-03** — Tap по модели открывает прайс этой модели с правильным брендом и областью данных.
- [ ] **HOME-MODEL-04** — Категория без моделей в структуре сразу открывает прайс категории. Пустой после фильтра список — HOME-Q02.
- [ ] **HOME-MODEL-05** — Последовательный выбор товаров разных брендов/категорий открывает соответствующие прайсы без подмены последним ранее выбранным товаром.

## Глубина

Данные обновить поддерживаемым жестом до оценки видимости. Момент применения изменения глубины без refresh не задан — HOME-Q02.

- [ ] **HOME-DEPTH-01** — При глубине 50+ предложение со stock 49 не делает свой товар/модель/категорию/бренд видимыми, если у них нет других подходящих предложений.
- [ ] **HOME-DEPTH-02** — При глубине 50+ предложения со stock 50 и 51 обеспечивают видимость соответствующих элементов; проверить оба значения отдельно.
- [ ] **HOME-DEPTH-03** — Категория, модель и бренд, содержащие хотя бы один подходящий продаваемый товар, не скрываются только из-за других предложений ниже порога.
- [ ] **HOME-DEPTH-04** — Stock 49 → 50 и refresh возвращают подходящие уровни каталога при 50+; stock 50 → 49 и refresh скрывают их при отсутствии других подходящих товаров.
- [ ] **HOME-DEPTH-05** — После изменения порога и refresh состав Главной соответствует новой глубине; конкретный момент применения без refresh — HOME-Q02.
- [ ] **HOME-DEPTH-06** — Предложения разных моделей и категорий фильтруются по их собственным данным; подходящая категория не получает строки неподходящей модели.

## Снятие с продажи между загрузкой и выбором

После загрузки снять с продажи все подходящие товары выбранного элемента, не обновляя Главную перед tap. Снятие одного предложения при наличии других — HOME-Q02.

- [ ] **HOME-STALE-01** — Выбор ранее показанного, ставшего недоступным бренда показывает alert об отсутствии товара. Точный текст/кнопки — HOME-Q01.
- [ ] **HOME-STALE-02** — Выбор ранее показанной, ставшей недоступной категории показывает alert об отсутствии товара.
- [ ] **HOME-STALE-03** — Выбор ранее показанной, ставшей недоступной модели показывает alert об отсутствии товара.

## Top sellers

- [ ] **HOME-TOP-01** — Набор брендов и моделей блока соответствует настройкам админки; автоматический рейтинг продаж не используется как ожидание.
- [ ] **HOME-TOP-02** — У каждой модели корректные название и иконка.
- [ ] **HOME-TOP-03** — Порядок вкладок брендов и моделей соответствует известному порядку добавления товаров админом.
- [ ] **HOME-TOP-04** — Tap по модели открывает прайс соответствующей модели.
- [ ] **HOME-TOP-05** — Tap по вкладке другого бренда показывает его модели.
- [ ] **HOME-TOP-06** — Свайпы влево/вправо переключают вкладки и соответствующие модели. Переход за крайнюю вкладку — HOME-Q05.
- [ ] **HOME-TOP-07** — Модель, снятая с продажи либо отключённая, скрывается после обновления; проверить оба основания отдельно.
- [ ] **HOME-TOP-08** — Если блок не настроен, он отсутствует целиком, а не показывает произвольный набор моделей.

## Загрузка, обновление и ошибки

- [ ] **HOME-REFRESH-01** — Длинный жест вниз запускает обновление Главной.
- [ ] **HOME-REFRESH-02** — При первоначальной загрузке показывается скелетон; после успешной загрузки он заменяется актуальными данными.
- [ ] **HOME-REFRESH-03** — При refresh показывается скелетон; после успеха отображаются обновлённые данные каталога и Top sellers.
- [ ] **HOME-ERROR-01** — Ошибка отсутствия соединения показывает соответствующий alert, а не ошибку сервера. Точный текст и retry — HOME-Q01.
- [ ] **HOME-ERROR-02** — Ошибка сервера показывает соответствующий alert, а не сообщение об отсутствии соединения; ответ контролируется тестовыми средствами.

## Возврат, роли и UI

- [ ] **HOME-RESET-01** — После закрытия прайса каталог свёрнут до дефолтного состояния; прежний выбор бренда/категории и раскрытые модели не сохраняются.
- [ ] **HOME-RESET-02** — Переход в другой раздел нижнего меню и возврат на Главную сворачивает каталог до дефолтного состояния; проверить возврат из каждого раздела.
- [ ] **HOME-ROLE-01** — Доступные клиент, корп и реселлер имеют одинаковую описанную структуру Главной; содержимое сравнивать при согласованном одинаковом наборе доступных товаров/глубине.
- [ ] **HOME-ROLE-02** — Заблокированному реселлеру Главная недоступна; точная компоновка меню — NAV-Q04. Другие статусные проверки не дублировать из авторизации.
- [ ] **HOME-UI-01** — Длинные названия, множество брендов/категорий/моделей и прокрутка не скрывают доступные элементы под нижним меню; последние строки достижимы.
- [ ] **HOME-UI-02** — В русском/английском интерфейсе и светлой/тёмной теме элементы Главной читаемы, кнопки и подсветка выбора различимы, нет смешения локализаций.

## Ограничения

Прокрутка при обычном возврате, дефолтная вкладка Top sellers, фильтр глубины внутри Top sellers, счётчики меню и нештатная полностью пустая Главная не имеют дополнительных выдуманных ожиданий. См. HOME-Q01–Q08 и вопросы NAV в правилах. Скриншоты не подтверждают выполнение пунктов.
