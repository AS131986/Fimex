# Чек-лист: Главная — Fimex Buyer, iOS

## Область и использование

Хедер, каталог, переходы в прайс, Top sellers, загрузка, обновление и сброс Главной. Нижнее меню проверяется в [отдельном чек-листе](checklist-bottom-navigation.md). Для соседних экранов — только факт перехода; не дублировать полный прогон Price List, поиска, настроек или уведомлений.

Проверки не выполнялись. `[ ]` означает Not run, не Fail. Результаты фиксировать отдельно: Pass / Fail / Blocked / Not run / N/A. Зависимая от вопроса часть Blocked до согласования ожидаемого результата. ID стабильные и не переиспользуются.

## Предусловия и данные

- Доступный клиент, корп и реселлер; заблокированный реселлер для ограничения Главной.
- Бренд с категориями; бренд без категорий в структуре. Категория с моделями и без моделей в структуре. Бренд/категория/модель с единственным продаваемым товаром для отрицательных сценариев.
- Два бренда с различающимися категориями; две категории с различающимися моделями. Известный порядок из админки.
- Предложения со stock 49/50/51 и настройка глубины 50+; бренд/категория/модель без подходящих предложений и другие с подходящими.
- Настроенный Top sellers с несколькими брендами/моделями, вариант без настройки; возможность снять/отключить модель.
- Новые уведомления для аккаунта, возможность вызвать сетевую/серверную ошибку и получить текущее состояние через разрешённые инструменты.
- При отсутствии данных или возможности изменить конфигурацию зависимая проверка Blocked, а не Pass.

## Глубина

Изменение глубины применяется по галочке Настроек и автоматически обновляет Главную. Если меняются сами данные stock, для оценки видимости выполнить поддерживаемый refresh.

- [ ] **HOME-DEPTH-01 — Скрытие предложения ниже порога глубины**

  <details>
  <summary>Подробности проверки</summary>

  - При глубине 50+ предложение со stock 49 не делает свой товар/модель/категорию/бренд видимыми, если у них нет других подходящих предложений.

  </details>

- [ ] **HOME-DEPTH-02 — Видимость предложений на пороге и выше**

  <details>
  <summary>Подробности проверки</summary>

  - При глубине 50+ предложения со stock 50 и 51 обеспечивают видимость соответствующих элементов; проверить оба значения отдельно.

  </details>

- [ ] **HOME-DEPTH-03 — Видимость уровня с хотя бы одним подходящим товаром**

  <details>
  <summary>Подробности проверки</summary>

  - Категория, модель и бренд, содержащие хотя бы один подходящий продаваемый товар, не скрываются только из-за других предложений ниже порога.

  </details>

- [ ] **HOME-DEPTH-04 — Обновление каталога при переходе stock через порог**

  <details>
  <summary>Подробности проверки</summary>

  - Stock 49 → 50 и refresh возвращают подходящие уровни каталога при 50+; stock 50 → 49 и refresh скрывают их при отсутствии других подходящих товаров.

  </details>

- [ ] **HOME-DEPTH-05 — Применение глубины после подтверждения настройки**

  <details>
  <summary>Подробности проверки</summary>

  - Изменение порога без галочки не применяется; после сохранения в Настройках Главная автоматически обновляется и соответствует новой глубине, без дополнительного ручного refresh.

  </details>

- [ ] **HOME-DEPTH-06 — Независимая фильтрация моделей и категорий**

  <details>
  <summary>Подробности проверки</summary>

  - Предложения разных моделей и категорий фильтруются по их собственным данным; подходящая категория не получает строки неподходящей модели.

  </details>
