# Чек-лист: Уведомления — Fimex Buyer, iOS

## Область и использование

Список событий, типы, переходы, прочтение, очистка и доступ по ролям. Не дублировать полную покупку, поддержку, P2P, оплату заказа или компенсацию.

Проверки не выполнялись. `[ ]` — Not run, не Fail. Результаты отдельно: Pass / Fail / Blocked / Not run / N/A. Часть, зависимая от NOTIF-Qxx, Blocked до согласования. ID стабильные, снятые ID не переиспользовать.

## Предусловия

- Клиент и связанный корп с общими заказами/P2P/балансом; отдельные события поддержки/товарных подписок для каждого.
- Реселлер с собственными событиями заказа, P2P и депозита.
- Пустой список и набор всех подтверждённых типов с известными иконками/текстами из согласованной конфигурации.
- Товар доступен для покупки, отдельный товар снят после возникновения события; уведомление достижения цены при фактической цене ниже target.
- Разрешённые средства создания событий и ошибок. Не выполнять реальные финансовые действия ради прогона без подходящего тестового окружения.

## Smoke

NOTIF-OPEN-01, NOTIF-READ-01, NOTIF-NAV-01/03, NOTIF-P2P-01, NOTIF-CLEAR-01, NOTIF-EMPTY-01. Использовать результаты основных пунктов.

## Открытие, загрузка и обновление

- [ ] **NOTIF-OPEN-01 — Открытие списка уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Кнопка Главной открывает Notifications с закрытием и списком; для непустого списка доступен Clear.

  </details>

- [ ] **NOTIF-OPEN-02 — Закрытие списка уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Верхний крестик закрывает список и возвращает на предыдущий экран.

  </details>

- [ ] **NOTIF-LOAD-01 — Скелетон загрузки уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - При подгрузке списка показывается скелетон, после успешного ответа отображается список либо пустое состояние.

  </details>

- [ ] **NOTIF-LOAD-02 — Актуализация уведомлений при открытии**

  <details>
  <summary>Подробности проверки</summary>

  - При каждом новом открытии список обновляется и содержит актуально доступные события.

  </details>

- [ ] **NOTIF-LOAD-03 — Новое событие в уже открытом списке**

  <details>
  <summary>Подробности проверки</summary>

  - Новый event не добавляется автоматически в уже открытый список; после повторного открытия отображается.
  - Прочтение события, пришедшего при открытом списке, — NOTIF-Q06.

  </details>

- [ ] **NOTIF-SORT-01 — Сортировка уведомлений по времени**

  <details>
  <summary>Подробности проверки</summary>

  - Более новые события выше старых; для проверки использовать разные времена, не задавать порядок одинаковых времён.

  </details>


## Прочтение

- [ ] **NOTIF-READ-01 — Прочтение уведомлений при открытии**

  <details>
  <summary>Подробности проверки</summary>

  - Открытие списка помечает события прочитанными; после возврата на Главную точка скрыта, если новых событий не приходило.

  </details>

- [ ] **NOTIF-READ-02 — Сохранение строк после прочтения**

  <details>
  <summary>Подробности проверки</summary>

  - Само открытие/прочтение не удаляет строки; они остаются до tap/Clear.

  </details>


## Типы и данные

- [ ] **NOTIF-TYPE-01 — Уведомление об ответе поставщика**

  <details>
  <summary>Подробности проверки</summary>

  - Ответ поставщика содержит данные соответствующей заявки/товара/ответа и иконку этого типа.

  </details>

- [ ] **NOTIF-TYPE-02 — Уведомление об ответе поддержки**

  <details>
  <summary>Подробности проверки</summary>

  - Ответ поддержки показан с иконкой и текстом поддержки; текст `11` не принимается как универсальное ожидание.

  </details>

- [ ] **NOTIF-TYPE-03 — Уведомление о поступлении товара**

  <details>
  <summary>Подробности проверки</summary>

  - Поступление товара показывает правильный товар и иконку товарного события.

  </details>

- [ ] **NOTIF-TYPE-04 — Уведомление о достижении цены**

  <details>
  <summary>Подробности проверки</summary>

  - Достижение цены показывает правильный товар и фактическую цену, которая может быть ниже target.

  </details>

- [ ] **NOTIF-TYPE-05 — Уведомление о пополнении баланса**

  <details>
  <summary>Подробности проверки</summary>

  - Пополнение баланса показывает данные соответствующего пополнения; сумму не брать из соседнего события.

  </details>

- [ ] **NOTIF-TYPE-06 — Уведомление о смене статуса заказа**

  <details>
  <summary>Подробности проверки</summary>

  - Смена статуса показывает правильный заказ/статус и иконку; проверить на известном номере заказа.

  </details>

- [ ] **NOTIF-TYPE-07 — Уведомление об оплате заказа**

  <details>
  <summary>Подробности проверки</summary>

  - Оплата показывает правильные заказ и сумму; две оплаты разных заказов не смешиваются.

  </details>

- [ ] **NOTIF-TYPE-08 — Уведомление о компенсации**

  <details>
  <summary>Подробности проверки</summary>

  - Компенсация за отменённый товар появляется как событие компенсации.
  - Точные поля/иконка — NOTIF-Q02.

  </details>


## Tap и назначение

- [ ] **NOTIF-NAV-01 — Переход из уведомления о статусе**

  <details>
  <summary>Подробности проверки</summary>

  - Смена статуса открывает детали соответствующего заказа, событие удаляется из списка.

  </details>

- [ ] **NOTIF-NAV-02 — Переход из уведомления об оплате**

  <details>
  <summary>Подробности проверки</summary>

  - Оплата открывает детали соответствующего заказа, событие удаляется.

  </details>

- [ ] **NOTIF-NAV-03 — Переход из уведомления о поступлении**

  <details>
  <summary>Подробности проверки</summary>

  - Поступление товара открывает покупку соответствующего доступного товара, событие удаляется.

  </details>

- [ ] **NOTIF-NAV-04 — Переход из уведомления о цене**

  <details>
  <summary>Подробности проверки</summary>

  - Достижение цены открывает покупку соответствующего доступного товара, событие удаляется.

  </details>

- [ ] **NOTIF-NAV-05 — Переход из уведомления о пополнении**

  <details>
  <summary>Подробности проверки</summary>

  - Пополнение баланса открывает баланс; событие удаляется.

  </details>

- [ ] **NOTIF-NAV-06 — Переход из уведомления поддержки**

  <details>
  <summary>Подробности проверки</summary>

  - Ответ поддержки открывает поддержку; событие удаляется.

  </details>

- [ ] **NOTIF-NAV-07 — Переход из уведомления о компенсации**

  <details>
  <summary>Подробности проверки</summary>

  - Компенсация открывает экран компенсации.
  - Детали объекта назначения и удаление строки после tap — NOTIF-Q07.

  </details>

- [ ] **NOTIF-P2P-01 — Скрытие P2P-ответа без перехода**

  <details>
  <summary>Подробности проверки</summary>

  - Tap по ответу поставщика P2P только скрывает событие, не открывает другой экран.

  </details>

- [ ] **NOTIF-NAV-08 — Alert при переходе к недоступному товару**

  <details>
  <summary>Подробности проверки</summary>

  - При tap по товару, который стал недоступен, показывается alert.
  - Удаление этой строки после отказа — NOTIF-Q03, не назначать ожидание без ответа.

  </details>


## Clear и пустой список

- [ ] **NOTIF-CLEAR-01 — Немедленная очистка списка уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Clear сразу удаляет весь отображаемый список без confirm dialog.

  </details>

- [ ] **NOTIF-CLEAR-02 — Очистка разных типов уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Clear очищает смесь разных типов событий, а не только один тип.

  </details>

- [ ] **NOTIF-EMPTY-01 — Пустое состояние после очистки**

  <details>
  <summary>Подробности проверки</summary>

  - После очистки показывается пустое состояние с колокольчиком и No notifications, без оставшихся строк.

  </details>

- [ ] **NOTIF-EMPTY-02 — Изначально пустой список уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Изначально пустой ответ отображает то же состояние; на предоставленном образце нет Clear.

  </details>


## Роли и общие/персональные события

- [ ] **NOTIF-ROLE-01 — Общие события клиента и корпа**

  <details>
  <summary>Подробности проверки</summary>

  - Клиент и связанный корп получают общие события ответа поставщика P2P, компенсации, пополнения баланса, оплаты и смены статуса.
  - Каждый тип проверить отдельно.

  </details>

- [ ] **NOTIF-ROLE-02 — Персональные события поддержки**

  <details>
  <summary>Подробности проверки</summary>

  - События поддержки клиента и корпа персональные; чужой ответ не появляется в другом аккаунте.

  </details>

- [ ] **NOTIF-ROLE-03 — Персональные товарные уведомления**

  <details>
  <summary>Подробности проверки</summary>

  - События поступления и достижения цены клиента и корпа персональные; подписка одного не создаёт товарное событие другому.

  </details>

- [ ] **NOTIF-ROLE-04 — Собственные финансовые и P2P-события реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер получает собственные события смены статуса, оплаты, P2P и пополнения депозита, отдельные от событий других аккаунтов.

  </details>

- [ ] **NOTIF-ROLE-05 — Отсутствие поддержки и компенсаций у реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - У реселлера нет событий поддержки и компенсации.

  </details>

- [ ] **NOTIF-ROLE-06 — Изоляция событий несвязанных клиентов**

  <details>
  <summary>Подробности проверки</summary>

  - Персональные события одного несвязанного клиента не попадают в список другого; общность клиент/корп не расширяется на чужую группу.

  </details>

- [ ] **NOTIF-ROLE-07 — Товарные уведомления реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер получает поступление товара и достижение выбранной цены по своим подпискам; эти события не смешиваются с событиями клиента/корпа.

  </details>


## Ошибки и UI

- [ ] **NOTIF-ERROR-01 — Сетевая ошибка загрузки уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Отсутствие интернета при загрузке вызывает стандартный alert; точный текст/retry — NOTIF-Q08.

  </details>

- [ ] **NOTIF-ERROR-02 — Серверная ошибка загрузки уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Серверная ошибка загрузки вызывает стандартный alert, а не успешное пустое состояние.

  </details>

- [ ] **NOTIF-UI-01 — Доступность длинного списка уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - Длинные тексты, названия товаров, номера заказов и суммы не перекрывают кнопки; список прокручивается, последние строки доступны.

  </details>

- [ ] **NOTIF-UI-02 — Локализация и темы уведомлений**

  <details>
  <summary>Подробности проверки</summary>

  - В обоих языках и темах строки, иконки и пустое состояние читаемы; точные переводы — NOTIF-Q02.

  </details>


## Ограничения

Синхронизация удаления общего события (NOTIF-Q04), судьба подписок/счётчика P2P после Clear (Q05), иконки/поля без согласованных образцов (Q02) не имеют выдуманных ожиданий. NOTIF-Q01 закрыт и покрыт NOTIF-ROLE-07. Прочтение списка, удаление события и удаление подписки — разные действия.
