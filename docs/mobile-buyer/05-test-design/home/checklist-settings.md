# Чек-лист: Настройки — Fimex Buyer, iOS

## Область и использование

Глубина, сохранение/отмена, тип оплаты, общая настройка связанных аккаунтов и Excel-прайс из Настроек. Обычный экран Price List и Share на нём — отдельные сценарии.

Проверки не выполнялись. `[ ]` — Not run, не Fail. Результаты отдельно: Pass / Fail / Blocked / Not run / N/A. Неизвестная часть ожидаемого поведения Blocked до ответа на SETTINGS-Qxx. ID стабильные; снятые ID не переиспользовать.

## Предусловия

- Доступные клиент, его корп(ы) и реселлер. Для общего типа оплаты — разные связанные аккаунты на устройствах; не две одновременные сессии одного аккаунта.
- Предложения с количеством `t−1`, `t`, `t+1` для порогов 1/5/20/50/100; при t=1 количество 0 означает отсутствие продаваемого предложения.
- Категории/модели/бренды, содержащие только товары ниже порога, и другие с подходящими товарами.
- Известные цена поставщика, рейтинг, проценты типа оплаты и индивидуальной наценки; конфигурация общего и более конкретного процента из админки.
- Средства сохранения/чтения конфигурации и анализа Excel, возможность вызвать ошибку сети/сервера. Недоступные действия — Blocked, не Pass.

## Smoke

SET-OPEN-01, SET-DEPTH-03/04, SET-SAVE-01, SET-CANCEL-01, SET-PAY-01/02, SET-EXPORT-01/04. Использовать результаты основных пунктов.

## Открытие и роли

- [ ] **SET-OPEN-01** — Бургер Главной открывает sheet Настроек с заголовком, галочкой, глубиной и Price-list.
- [ ] **SET-OPEN-02** — Клиент и корп видят Cash/Online и выбранный вариант.
- [ ] **SET-OPEN-03** — У реселлера Cash/Online скрыты; глубина и экспорт доступны.

## Глубина

- [ ] **SET-DEPTH-01** — Доступны только 1+/5+/20+/50+/100+, промежуточное значение нельзя выбрать как настройку.
- [ ] **SET-DEPTH-02** — Tap по каждому значению выбирает его и отражает выбор в ползунке/подсветке.
- [ ] **SET-DEPTH-03** — Перетягивание позволяет выбрать каждое из пяти значений; итоговый выбор соответствует одному из них.
- [ ] **SET-DEPTH-04** — Для каждого порога t после сохранения количество t проходит фильтр; t−1 не проходит; t+1 проходит. Проверить все пять порогов, а не только 50+.
- [ ] **SET-DEPTH-05** — До галочки новая глубина не применяется как сохранённая настройка; закрытие без сохранения сохраняет предыдущую глубину.
- [ ] **SET-DEPTH-06** — Сохранение индивидуальной глубины клиента не меняет глубину корпа и реселлера.
- [ ] **SET-DEPTH-07** — Сохранение глубины корпа не меняет глубину клиента/другого корпа/реселлера.
- [ ] **SET-DEPTH-08** — Реселлер может сохранить свою глубину; глубина связанных аккаунтов не меняется.

## Сохранение, отмена и Главная

- [ ] **SET-SAVE-01** — Галочка сохраняет выбранные глубину/оплату и закрывает sheet.
- [ ] **SET-SAVE-02** — Повторное открытие Настроек в текущей сессии показывает сохранённые значения, а не прежние.
- [ ] **SET-SAVE-03** — После сохранения глубины Главная обновляется автоматически; дополнительный pull-to-refresh не требуется.
- [ ] **SET-SAVE-04** — После увеличения порога бренды/категории/модели без подходящих товаров исчезают; имеющие подходящие товары остаются.
- [ ] **SET-SAVE-05** — После уменьшения порога подходящие продаваемые товары и их уровни каталога снова доступны.
- [ ] **SET-SAVE-06** — После изменения глубины и оплаты за один save применяются оба выбранных значения; Главная соответствует сохранённой глубине.
- [ ] **SET-CANCEL-01** — Изменить глубину, закрыть sheet жестом без галочки: изменение отменено; повторное открытие показывает прежний порог.
- [ ] **SET-CANCEL-02** — Изменить глубину, закрыть tap снаружи: изменение отменено.
- [ ] **SET-CANCEL-03** — Изменить оплату без галочки и закрыть любым из двух способов: сохранённая оплата связанной группы не меняется.
- [ ] **SET-CANCEL-04** — Изменить глубину и оплату, закрыть без галочки: оба изменения отменены.

## Тип оплаты

- [ ] **SET-PAY-01** — Клиент может выбрать и сохранить Cash и Online; проверить оба направления переключения.
- [ ] **SET-PAY-02** — Корп может выбрать и сохранить Cash и Online; выбор общий со связанным клиентом.
- [ ] **SET-PAY-03** — После сохранения клиентом тип оплаты общий для всех связанных корпов и реселлеров; индивидуальная глубина при этом остаётся прежней.
- [ ] **SET-PAY-04** — После сохранения любым корпом тип оплаты меняется для всей связанной группы.
- [ ] **SET-PAY-05** — У реселлера нет собственного выбора типа оплаты; используется установленный клиентом/корпом.
- [ ] **SET-PAY-06** — У сохраняющего аккаунта изменение применяется сразу; для расчёта не добавляется отдельная комиссия площадки поверх процента типа оплаты. Округление — SETTINGS-Q03.
- [ ] **SET-PAY-07** — На другом связанном аккаунте с уже загруженной старой ценой попытка купить после смены оплаты показывает ошибку изменения цены. Подобрать конфигурацию, где новая цена действительно отличается; точный UI — SETTINGS-Q09.
- [ ] **SET-PAY-08** — Повторный запрос прайса другим связанным аккаунтом получает цену с актуальным типом оплаты. Точная формула — SETTINGS-Q03.

## Барабан и файл

- [ ] **SET-EXPORT-01** — Tap по Price-list открывает барабан выбора процента для Excel-прайса.
- [ ] **SET-EXPORT-02** — Доступны границы 0,25% и 4,25%, при открытии выбран 0,55%. Значения 0,25–0,95% с шагом 0,1, затем 1,00%, 1,25–4,25% с шагом 0,25. Проверить отдельно стык 0,95 → 1,00 → 1,25; SETTINGS-Q02 закрыт.
- [ ] **SET-EXPORT-03** — На допустимом выбранном проценте можно сформировать и открыть Excel-файл. Способ подтверждения/передачи и расширение — SETTINGS-Q05/Q06.
- [ ] **SET-EXPORT-04** — В файл включены только продаваемые товары с первым рейтингом; другие конкуренты, отсутствующие товары и подписки не добавляются как товарные строки.
- [ ] **SET-EXPORT-05** — При сохранённой глубине файл содержит подходящие по ней товары, а ниже порога — нет. Рейтинг-победитель ниже порога — SETTINGS-Q05.
- [ ] **SET-EXPORT-06** — После сохранения другой глубины новый экспорт соответствует новому порогу.
- [ ] **SET-EXPORT-07** — Для клиента/корпа/реселлера экспорт использует применимые настройки аккаунта; дополнительная наценка клиента только у реселлера. База этой наценки и округление — SETTINGS-Q03.
- [ ] **SET-EXPORT-08** — При общем проценте 1% для iPhone и переопределении 0,5% для iPhone 18 выбирается конкретный процент для 18, остальные получают общий. Числовая итоговая цена зависит от SETTINGS-Q03.
- [ ] **SET-EXPORT-09** — Изменение админом применимого процента учитывается в следующем формировании файла; не закреплять 0,5% Cash/0,25% Online как постоянные значения.
- [ ] **SET-EXPORT-10** — Изменить глубину и оплату без галочки и сформировать файл: используются ранее сохранённые глубина и оплата. Проверить различающийся состав/цену, а не только подписи выбранных настроек.
- [ ] **SET-EXPORT-11** — Наценка файла применяется к итоговой цене приложения: до округления `P × (1 + m / 100)`. Подобрать данные без неоднозначного округления; правило округления — SETTINGS-Q03.
- [ ] **SET-EXPORT-12** — Для значений строго внутри нижнего диапазона соседние проценты отличаются на 0,1; внутри верхнего — на 0,25. Взять, например, 0,45/0,55 и 1,25/1,50. Переход около 1 — отдельно SETTINGS-Q02.

## Ошибки и UI

- [ ] **SET-ERROR-01** — При отсутствии интернета сохранение вызывает стандартный alert; точные строки, сохранение выбора и retry — SETTINGS-Q08.
- [ ] **SET-ERROR-02** — Серверная ошибка сохранения вызывает стандартный alert.
- [ ] **SET-ERROR-03** — Отсутствие интернета либо серверная ошибка формирования файла вызывает стандартный alert; проверить оба основания отдельно.
- [ ] **SET-UI-01** — Галочка, значения глубины и Price-list доступны на поддерживаемых iPhone, не перекрываются системной нижней областью.
- [ ] **SET-UI-02** — В русском/английском интерфейсе и обеих темах значения, выбранная оплата и подписи различимы.

## Пока не определены ожидаемые результаты

Стык шагов барабана около 1% (SETTINGS-Q02), база наценки реселлера и округление (Q03), схема Excel и равенство рейтингов (Q05), сохранение глубины после повторного входа (Q07). До уточнения зависимые части Blocked; проверка успешного открытия файла не заменяет проверку его цен и состава. SETTINGS-Q01 закрыт и покрыт SET-EXPORT-10.
