# Чек-лист: Price List

## Scope и условия
- Платформа: iOS.
- Покрывается экран Price List и создание, изменение, удаление и срабатывание уведомлений из этого экрана.
- Глубокая проверка Purchase screen и старого раздела уведомлений в Profile не входит в scope.

## 1. Открытие и закрытие экрана
- [ ] Price List открывается из прайса бренда.
- [ ] Price List открывается из прайса категории.
- [ ] Price List открывается из выбранной модели.
- [ ] В заголовке отображается корректное название выбранной модели/товара.
- [ ] Длинное название не перекрывает Share и Close.
- [ ] Кнопка Share отображается и доступна.
- [ ] Кнопка Close отображается и доступна.
- [ ] Tap по Close закрывает Price List.
- [ ] После полного закрытия и повторного открытия экран загружается в начальном состоянии.
- [ ] Экран корректно отображается на поддерживаемых размерах iPhone с учётом safe area.

## 2. Загрузка и ошибки экрана
- [ ] Во время первоначальной загрузки отображается ожидаемое состояние загрузки без устаревших данных другого товара.
- [ ] После успешной загрузки loader скрывается и отображаются данные выбранного товара.
- [ ] Пустой прайс отображается без поломанной верстки и бесконечного loader.
- [ ] Ошибка загрузки прайса отображается корректно и не маскируется под пустой результат.
- [ ] После восстановления сети повторная загрузка возвращает данные без повторного открытия приложения.
- [ ] Повторный запрос не создает дубли цветовых групп, строк и уведомлений.
- [ ] Переход приложения background → foreground не приводит к зависанию loader или потере уже загруженного экрана.

## 3. Верхние табы характеристик
- [ ] Отображаются только характеристики, для которых есть видимые позиции в Price List.
- [ ] Таб характеристики полностью скрыт, если для него нет ни одной видимой позиции.
- [ ] Характеристика товара, который никогда не продавался и не должен выводиться в прайсе, не отображается.
- [ ] Порядок табов соответствует порядку, заданному в админке.
- [ ] Активный таб визуально выделен.
- [ ] После переключения активным становится выбранный таб.
- [ ] После переключения отображаются только группы и строки выбранной характеристики.
- [ ] Строки предыдущей характеристики не остаются на экране после переключения.
- [ ] Быстрое последовательное переключение табов не смешивает данные разных характеристик.
- [ ] При возврате с Purchase screen выбранный таб сохраняется.
- [ ] После полного закрытия и повторного открытия Price List выбирается дефолтный таб.

## 4. Цветовые группы
- [ ] Цветовые группы отображаются в порядке, заданном в админке.
- [ ] При первом открытии Price List все цветовые группы свернуты.
- [ ] Tap по заголовку/стрелке раскрывает выбранную группу.
- [ ] Повторный tap сворачивает выбранную группу.
- [ ] Можно одновременно раскрыть несколько групп.
- [ ] Раскрытие одной группы не сворачивает другие раскрытые группы.
- [ ] При возврате с Purchase screen состояния раскрытых групп сохраняются.
- [ ] После полного закрытия и повторного открытия Price List все группы снова свернуты.
- [ ] После успешного добавления уведомления из свернутой группы эта группа автоматически раскрывается.
- [ ] После успешного добавления уведомления в раскрытой группе она остается раскрытой.
- [ ] Добавление уведомления не изменяет состояние других групп.
- [ ] После обновления данных проверить фактическое состояние раскрытых групп и зафиксировать расхождение, если состояние меняется непредсказуемо.

## 5. Состав доступной строки
- [ ] Доступная строка содержит дату.
- [ ] Доступная строка содержит страну и соответствующий ей флаг.
- [ ] Если страна отсутствует, вместо флага отображается иконка девайса.
- [ ] Доступная строка содержит цену в USD.
- [ ] Доступная строка содержит фактическое количество товара справа.
- [ ] Количество относится к правильной комбинации модели, характеристики, цвета, страны и даты.
- [ ] Значения количества `1`, обычное многозначное и большое значение отображаются без обрезания и наложений.
- [ ] Цена, количество, дата и страна не смешиваются между соседними строками.
- [ ] Tap по доступной строке открывает Purchase screen соответствующего товара.
- [ ] После возврата из Purchase screen пользователь возвращается в тот же Price List.

## 6. Расчёт и отображение даты
- [ ] При `delivery days = 0` отображается дата выставления товара на продажу.
- [ ] При `delivery days > 0` отображается дата выставления плюс количество дней доставки.
- [ ] Расчёт даты корректен при переходе на следующий месяц.
- [ ] Расчёт даты корректен при переходе на следующий год.
- [ ] Дата позиции с текущей КТ подсвечивается согласно дизайну.
- [ ] Позиции без текущей КТ не получают такую же подсветку ошибочно.

## 7. Расчёт и отображение цены
- [ ] Для обычного Buyer отображается цена продавца с процентом площадки.
- [ ] Применяется ожидаемое правило округления итоговой цены.
- [ ] Одинаковая итоговая цена используется в основной строке, модалке цены и связанных UI-состояниях.
- [ ] Для Reseller в Price List отображается цена с наценкой основного клиента.
- [ ] Для Reseller отдельно проверяется, от конечной или базовой цены строится диапазон price notification; неподтвержденное поведение фиксируется как открытый риск.

## 8. Фильтр по глубине товара
- [ ] Выбранная в настройках глубина товара применяется при открытии Price List.
- [ ] При выбранной глубине `50+` отображаются только доступные позиции с количеством `50` или больше.
- [ ] Позиция с количеством `49` не отображается при фильтре `50+`.
- [ ] Позиция с количеством `50` отображается при фильтре `50+`.
- [ ] Позиция с количеством `51` отображается при фильтре `50+`.
- [ ] Фильтр применяется к фактическому количеству конкретного предложения, а не к количеству соседней строки.
- [ ] Количество разных поставщиков не суммируется для прохождения порога, если каждое предложение отображается отдельно.
- [ ] Позиции разных стран фильтруются независимо.
- [ ] Позиции разных цветов фильтруются независимо.
- [ ] Позиции разных характеристик фильтруются независимо.
- [ ] Если после фильтрации в цветовой группе не остается доступных позиций, группа отображается/скрывается согласно правилам Price List без пустых некорректных строк.
- [ ] Если после фильтрации для характеристики не остается ни одной видимой позиции, соответствующий таб скрывается.
- [ ] Изменение глубины в настройках применяется к Price List после возврата/обновления согласно механике приложения.
- [ ] Уменьшение порога возвращает ранее отфильтрованные подходящие позиции.
- [ ] Увеличение порога скрывает позиции, количество которых ниже нового значения.
- [ ] Изменение stock с `49` на `50` делает позицию видимой при фильтре `50+` после обновления.
- [ ] Изменение stock с `50` на `49` скрывает позицию при фильтре `50+` после обновления.
- [ ] Фильтрация не изменяет фактическое количество у оставшихся строк.
- [ ] Фильтрация не создаёт дубли строк после повторного открытия или обновления Price List.
- [ ] Сохранённые уведомления для скрытой фильтром позиции не удаляются с backend из-за применения фильтра.

### Глубина товара и конкуренты
- [ ] Фильтр глубины применяется отдельно к основной и каждой конкурентной строке.
- [ ] При фильтре `50+` конкурент с количеством `49` не отображается.
- [ ] При фильтре `50+` конкурент с количеством `50` отображается.
- [ ] При фильтре `50+` конкурент с количеством больше `50` отображается.
- [ ] Стрелка конкурентов не отображается, если после фильтрации не осталось ни одного подходящего конкурента.
- [ ] Стрелка отображается, если после фильтрации остался хотя бы один подходящий конкурент.
- [ ] Если часть конкурентов отфильтрована, список заполняется следующими подходящими предложениями согласно сортировке.
- [ ] После фильтрации отображается максимум три подходящих конкурента.
- [ ] Основная строка не входит в лимит трёх конкурентов после применения фильтра.
- [ ] Лучшее предложение по рейтингу определяется среди предложений, прошедших фильтр глубины.
- [ ] Tap по конкурентной строке открывает Purchase screen с лучшим предложением среди позиций, прошедших фильтр.
- [ ] Цена в Purchase screen не относится к отфильтрованному предложению с количеством ниже порога.
- [ ] Изменение stock конкурента через границу порога пересчитывает состав и порядок раскрытого списка.
- [ ] После изменения глубины список конкурентов пересчитывается без дубликатов и содержит не более трёх строк.

## 9. Конкуренция предложений
- [ ] Конкуренция рассчитывается по модели + стране + характеристике.
- [ ] Если есть предложение на ближайшую дату, более дальнее предложение по умолчанию скрыто.
- [ ] Если предложение на дальней дате дешевле ближайшего, отображаются оба предложения.
- [ ] Если предложение на дальней дате дороже ближайшего, дальнее предложение скрыто.
- [ ] Если цены ближайшего и дальнего предложения равны, отображение соответствует фактическому бизнес-правилу и результат фиксируется.
- [ ] Правило одной страны не скрывает предложения другой страны.
- [ ] Правило одной характеристики не влияет на другую характеристику.
- [ ] После применения правил конкуренции видимые предложения сортируются по цене от меньшей к большей внутри соответствующего блока.
- [ ] Порядок стран соответствует порядку, заданному в админке.
- [ ] Обновление цены или даты приводит к корректному пересчёту состава видимых строк без дубликатов.

## 10. Просмотр цен конкурентов
- [ ] Стрелка раскрытия отображается у позиции, для которой есть конкурирующие предложения.
- [ ] Стрелка не отображается, если конкурирующих предложений нет.
- [ ] Конкуренты определяются для одной комбинации модели, характеристики, цвета, страны и актуальной даты.
- [ ] При первом открытии Price List список конкурентов свернут.
- [ ] Tap по стрелке раскрывает конкурирующие предложения выбранной позиции.
- [ ] После раскрытия состояние/направление стрелки меняется.
- [ ] Повторный tap по стрелке сворачивает конкурирующие предложения.
- [ ] После сворачивания остаётся основная строка предложения.
- [ ] Если найден один конкурент, отображается одна конкурентная строка.
- [ ] Если найдено два конкурента, отображаются две конкурентные строки.
- [ ] Если найдено три конкурента, отображаются три конкурентные строки.
- [ ] Если найдено более трёх конкурентов, отображаются только первые три конкурентных предложения.
- [ ] Четвёртое и последующие конкурентные предложения не выводятся в раскрытом списке.
- [ ] Лимит в три конкурента применяется отдельно к каждой основной позиции/стране.
- [ ] Основная строка не входит в лимит трёх конкурентов: на экране может отображаться одна основная строка и до трёх конкурентных строк.
- [ ] В лимит попадают первые три предложения согласно установленной сортировке конкурентов.
- [ ] Раскрываются конкуренты только выбранной страны.
- [ ] Раскрытие одной страны не раскрывает строки другой страны.
- [ ] Раскрытие одного цвета не влияет на другие цветовые группы.
- [ ] Раскрытие одной характеристики не влияет на другие табы.
- [ ] Каждая конкурентная строка содержит правильные дату, страну, флаг, цену и количество.
- [ ] Конкурентные предложения отсортированы по цене от меньшей к большей.
- [ ] Самое дешёвое конкурентное предложение отображается первым.
- [ ] Предложения с одинаковой ценой отображаются без пропуска или ошибочного объединения.
- [ ] Раскрытие, сворачивание и повторное раскрытие не создают дубли строк.
- [ ] Быстрые повторные tap по стрелке не ломают состояние списка.
- [ ] Tap по любой конкурентной строке открывает Purchase screen.
- [ ] В Purchase screen выбирается товар с лучшим предложением по рейтингу, а не нажатое конкурентное предложение.
- [ ] Цена в Purchase screen соответствует цене лучшего предложения по рейтингу.
- [ ] Tap по конкуренту с более высокой ценой не переносит его цену в Purchase screen.
- [ ] Tap по разным конкурентным строкам одной позиции приводит к одному и тому же лучшему предложению по рейтингу.
- [ ] Страна, модель, характеристика и цвет в Purchase screen соответствуют товарной позиции, для которой был открыт список конкурентов.
- [ ] Long press по конкурентной строке не открывает модалку настройки уведомления по цене.
- [ ] Long press по конкурентной строке не создаёт и не изменяет уведомление.
- [ ] После long press по конкурентной строке состояние списка, check, колокольчики и строки уведомлений не меняются.
- [ ] Настройка price notification остаётся доступна через long press по основной строке товарной позиции.
- [ ] После возврата из Purchase screen состояние раскрытого списка конкурентов сохраняется.
- [ ] После полного закрытия и повторного открытия Price List список конкурентов снова свернут.
- [ ] После обновления данных список пересчитывается и по-прежнему содержит не более трёх конкурентов.
- [ ] Исчезнувший конкурент удаляется из списка после обновления.
- [ ] Новый конкурент занимает правильное место по цене после обновления, не создавая дублей.

## 11. Предложения поставщиков и изменение цены

### Один поставщик
- [ ] Активное предложение поставщика отображается в правильных модели, характеристике, цвете и стране.
- [ ] Итоговая цена рассчитывается из цены поставщика с учетом комиссии площадки.
- [ ] Изменение цены поставщиком отображается после обновления Price List.
- [ ] Увеличение цены корректно обновляет строку предложения.
- [ ] Уменьшение цены корректно обновляет строку предложения.
- [ ] Неуспешно сохраненная цена поставщика не появляется в Price List как актуальная.
- [ ] Отключенное, архивное или удаленное предложение перестает отображаться.
- [ ] При `stock = 0` предложение перестает считаться доступным.
- [ ] После возврата положительного stock предложение снова становится доступным.

### Несколько поставщиков одного товара
- [ ] Предложения поставщиков объединяются только при совпадении модели, характеристики, цвета и страны.
- [ ] Предложения разных стран не объединяются в одну конкурентную группу.
- [ ] Предложения разных характеристик не объединяются.
- [ ] Предложения разных цветов не объединяются.
- [ ] При двух поставщиках корректно определяется основное/лучшее предложение.
- [ ] При трех и более поставщиках корректно определяется основное/лучшее предложение.
- [ ] Одинаковые цены разных поставщиков не приводят к потере или ошибочному объединению предложений.
- [ ] Цена и количество каждой конкурентной строки относятся к одному и тому же предложению поставщика.
- [ ] Количество одного поставщика не подменяется количеством другого поставщика.

### Пересчет после изменения цены
- [ ] Снижение цены конкурента пересчитывает его позицию в списке.
- [ ] Повышение цены конкурента пересчитывает его позицию в списке.
- [ ] Поставщик, вошедший в первую тройку конкурентов, появляется после обновления.
- [ ] Поставщик, вышедший из первой тройки конкурентов, скрывается после обновления.
- [ ] Изменение цены не создает дубликат предложения поставщика.
- [ ] Изменение цены одного поставщика не меняет цену другого поставщика.
- [ ] Изменение цены пересчитывает лучшее предложение по рейтингу.
- [ ] Если лучшим становится другой поставщик, Purchase screen открывает новое лучшее предложение.
- [ ] После обновления tap по строке не открывает устаревшее предложение или устаревшую цену.

### Граничные значения цены
- [ ] Минимально допустимая положительная цена обрабатывается корректно.
- [ ] Высокая цена не обрезается и не ломает верстку.
- [ ] Цена с дробной частью корректно обрабатывается и округляется по правилу площадки.
- [ ] Два предложения с разницей в `1 USD` сортируются корректно.
- [ ] Одинаковые итоговые цены разных поставщиков отображаются стабильно.
- [ ] Нулевая цена поставщика не отображается как валидное предложение, если она запрещена бизнес-правилами.
- [ ] Отрицательная цена поставщика не отображается как валидное предложение.

### Связь цены и даты
- [ ] Ближнее более дешевое предложение отображается согласно правилам Price List.
- [ ] Ближнее более дорогое и дальнее более дешевое предложения отображаются одновременно.
- [ ] Дальнее более дорогое предложение скрывается.
- [ ] Снижение цены дальнего предложения пересчитывает его видимость.
- [ ] Изменение даты поставщиком пересчитывает состав видимых предложений.
- [ ] Одновременное изменение цены и даты не оставляет устаревшую строку.

### Цена поставщика и уведомления
- [ ] Снижение итоговой цены до значения, равного target, вызывает price notification.
- [ ] Снижение итоговой цены на `1 USD` ниже target вызывает price notification.
- [ ] Цена на `1 USD` выше target не вызывает price notification.
- [ ] Снижение цены поставщика другой страны не вызывает уведомление выбранной страны.
- [ ] Снижение цены другого цвета или характеристики не вызывает уведомление выбранной позиции.
- [ ] Последовательные изменения цен нескольких поставщиков не создают дубли пользовательского уведомления.
- [ ] После удаления price notification изменение цены поставщиком не вызывает уведомление.
- [ ] Смена лучшего поставщика не удаляет и не дублирует существующую подписку.

### Stock нескольких поставщиков
- [ ] Обнуление stock одного поставщика удаляет/скрывает только его доступное предложение.
- [ ] При наличии stock у другого подходящего поставщика товар остается доступным.
- [ ] Товар становится отсутствующим только после исчезновения всех подходящих активных предложений.
- [ ] In-stock notification срабатывает при появлении подходящего предложения хотя бы у одного поставщика.
- [ ] Появление stock у поставщика другой страны не вызывает уведомление выбранной страны.

## 12. Отсутствующие товары
- [ ] Ранее продававшийся, но сейчас отсутствующий товар отображается в раскрытом списке.
- [ ] Товар, который никогда не продавался, не отображается в Price List.
- [ ] У отсутствующей позиции не отображается дата.
- [ ] У отсутствующей позиции не отображается цена.
- [ ] У отсутствующей позиции не отображается количество.
- [ ] У отсутствующей позиции отображается страна и соответствующий флаг.
- [ ] Если страна отсутствует, отображается иконка девайса.
- [ ] Tap по отсутствующей позиции не открывает Purchase screen.
- [ ] Порядок отсутствующих позиций соответствует порядку стран из админки.
- [ ] Отсутствующие позиции визуально отличаются от продаваемых, но остаются интерактивными для уведомлений.

## 13. Onboarding-подсказки
- [ ] При выполнении условий первого показа отображается первый шаг подсказки по удержанию позиции и выбору цены.
- [ ] Первый шаг содержит корректный текст, индикатор `1/2` и кнопку `OK`.
- [ ] Первый шаг указывает на корректный элемент Price List.
- [ ] Tap по `OK` открывает второй шаг подсказки.
- [ ] Второй шаг содержит корректный текст, индикатор `2/2` и кнопку `OK`.
- [ ] Второй шаг указывает на сценарий выбора отсутствующего товара.
- [ ] Tap по `OK` на втором шаге закрывает onboarding.
- [ ] При открытой подсказке задний фон размывается согласно дизайну.
- [ ] Элементы, которые не должны затемняться, отображаются согласно дизайну.
- [ ] Размеры и позиционирование подсказок соответствуют дизайну и не выходят за safe area.
- [ ] Повторный показ onboarding после его завершения соответствует реализованному правилу и фиксируется, если правило не определено.

## 14. Общие правила уведомлений
- [ ] Уведомление создаётся для конкретной комбинации товара, характеристики, цвета и страны.
- [ ] Уведомление одной характеристики не отображается в другой характеристике.
- [ ] Уведомление одного цвета не отображается в другой цветовой группе.
- [ ] Уведомление одной страны не меняет состояние другой страны.
- [ ] Для одной позиции и страны одновременно существует только один тип уведомления.
- [ ] Для разных стран одной группы можно создать разные типы уведомлений.
- [ ] Уведомление можно создать только для позиции, присутствующей в Price List.
- [ ] После полного переоткрытия Price List сохранённые уведомления восстанавливаются без дубликатов.

## 15. Уведомление о появлении в продаже
- [ ] Tap по отсутствующей позиции создаёт уведомление о появлении в продаже без цены.
- [ ] Во время запроса повторные tap не создают дубликаты подписки.
- [ ] После успешного создания у позиции появляется выбранный check.
- [ ] После успешного создания появляется колокольчик и строка уведомления в раскрытой группе.
- [ ] Строка уведомления содержит правильные страну и флаг.
- [ ] Вместо цены в строке отображается check/индикатор уведомления о поступлении.
- [ ] В строке не отображается чужая цена, дата или количество.
- [ ] Основная позиция после создания не меняет своё место в списке.
- [ ] Если группа была свернута, после успешного создания она автоматически раскрывается.
- [ ] Показывается toast об успешном добавлении уведомления.
- [ ] Ошибка создания не включает check и не добавляет строку уведомления.
- [ ] Создание уведомления без `price`/с `price: null` не приводит к ошибке 500.
- [ ] Повторный tap по выбранной строке удаляет уведомление без confirm dialog.
- [ ] После успешного удаления check и строка уведомления исчезают.
- [ ] После удаления показывается toast/snackbar с возможностью Undo.
- [ ] Undo восстанавливает check и строку уведомления для правильной страны.
- [ ] Ошибка удаления не оставляет UI в ложном удалённом состоянии.

## 16. Открытие модалки уведомления по цене
- [ ] Long press по доступной позиции открывает модалку настройки цены.
- [ ] Long press по отсутствующей ранее продававшейся позиции также открывает модалку настройки цены.
- [ ] Обычный tap по доступной позиции не открывает модалку цены, а ведёт в Purchase screen.
- [ ] Обычный tap по отсутствующей позиции создаёт/снимает in-stock notification, а не открывает Purchase screen.
- [ ] При long press отображается ожидаемая анимация зажатия.
- [ ] Модалка появляется плавно, без скачков и мигания.
- [ ] Задний фон модалки размыт согласно дизайну.
- [ ] Размеры и положение модалки соответствуют дизайну.
- [ ] В модалке отсутствуют лишние полоски и визуальные артефакты.
- [ ] Модалка относится к правильным товару, характеристике, цвету и стране.

## 17. Диапазон и управление ценой
- [ ] Верхняя ценовая граница соответствует текущей/максимальной цене выбранной позиции.
- [ ] Нижняя ценовая граница соответствует верхней границе минус 50 USD.
- [ ] Валюта диапазона — USD.
- [ ] Каждый шаг ползунка изменяет значение на 1 USD.
- [ ] Можно выбрать нижнюю границу диапазона.
- [ ] Можно выбрать промежуточное значение диапазона.
- [ ] Возможность выбрать верхнюю границу не конфликтует с жестом удаления; неоднозначное поведение фиксируется как дефект требования/реализации.
- [ ] Для товара дешевле 50 USD нижняя граница не становится отрицательной и не принимает некорректное значение.
- [ ] Быстрое перемещение ползунка не пропускает итоговое выбранное значение.
- [ ] После отпускания ползунка сохраняется именно последнее выбранное значение.
- [ ] После отпускания ползунка выдерживается ожидаемая задержка около 0.5 секунды.
- [ ] Закрытие модалки без движения ползунка не создаёт и не изменяет уведомление.
- [ ] Закрытие модалки после автоматического сохранения не откатывает сохранённое значение.
- [ ] Закрытие модалки во время задержки сохранения не создаёт дубликат и не сохраняет промежуточное значение.

## 18. Создание уведомления по цене
- [ ] После выбора цены и успешного сохранения появляется колокольчик.
- [ ] Внизу раскрытой группы появляется отдельная строка price notification.
- [ ] Строка содержит правильную страну и флаг.
- [ ] Строка содержит выбранную целевую цену, а не текущую цену предложения.
- [ ] Строка добавляется в правильную характеристику и цветовую группу.
- [ ] Если группа была свернута, после успешного сохранения она автоматически раскрывается.
- [ ] Если группа была раскрыта, она остаётся раскрытой.
- [ ] Порядок основных предложений после добавления не меняется.
- [ ] Ошибка сохранения не добавляет строку и колокольчик в подтверждённое состояние.
- [ ] Повторное создание во время медленного ответа не создаёт дубликаты.

## 19. Редактирование уведомления по цене
- [ ] Tap по строке price notification открывает модалку редактирования.
- [ ] Long press по соответствующей основной позиции открывает редактирование существующего уведомления.
- [ ] При открытии модалки отображается ранее сохранённая целевая цена.
- [ ] Изменение значения обновляет существующую подписку, а не создаёт новую.
- [ ] После изменения в строке отображается новая целевая цена.
- [ ] При выборе строки той же страны с другой датой обновляется существующая строка уведомления.
- [ ] Изменение уведомления одной страны не меняет уведомление другой страны.
- [ ] Закрытие редактирования без изменения ползунка сохраняет прежнее значение.
- [ ] Ошибка обновления не заменяет старое подтверждённое значение новым в постоянном UI-состоянии.

## 20. Удаление уведомления по цене
- [ ] Перевод ползунка в предусмотренное крайнее состояние удаления удаляет price notification.
- [ ] Удаление не требует confirm dialog.
- [ ] После успешного удаления строка price notification исчезает.
- [ ] После успешного удаления не остаётся неактуальный колокольчик или выбранная цена.
- [ ] Удаление одной подписки не удаляет подписки других стран, цветов и характеристик.
- [ ] Ошибка удаления не должна безвозвратно скрывать активную подписку из UI.

## 21. Переключение типа уведомления
- [ ] Если установлено in-stock notification, создание price notification для той же позиции и страны снимает in-stock notification.
- [ ] После переключения check уведомления о поступлении исчезает.
- [ ] После переключения остаётся только строка price notification с выбранной ценой.
- [ ] На backend и в UI не остаются одновременно две подписки для одной позиции и страны.
- [ ] Переключение типа не влияет на уведомления других стран.

## 22. Отображение и сортировка строк уведомлений
- [ ] Строки уведомлений отображаются только внутри раскрытой группы.
- [ ] В свернутой группе нет отдельного индикатора наличия уведомлений.
- [ ] Строки уведомлений расположены ниже основных предложений группы.
- [ ] Порядок строк уведомлений соответствует порядку стран из админки, а не времени создания.
- [ ] Price notification визуально содержит колокольчик, страну и выбранную цену.
- [ ] In-stock notification визуально содержит колокольчик, страну и check вместо цены.
- [ ] Два разных типа уведомления для разных стран визуально различимы в одной группе.
- [ ] Добавление, изменение и удаление уведомления не пересортировывает основные предложения.
- [ ] Для одной позиции и страны не появляется две одинаковые строки уведомления.

## 23. Обновление данных и устойчивость состояния
- [ ] После обновления Price List сохранённые уведомления загружаются повторно без дубликатов.
- [ ] После обновления правильные check, колокольчики и целевые цены сохраняются.
- [ ] После изменения stock отсутствующая позиция становится доступной корректно.
- [ ] После изменения stock in-stock notification не отображается как ценовое уведомление.
- [ ] После изменения цены существующая целевая цена не подменяется новой текущей ценой товара.
- [ ] Background → foreground с открытой модалкой не создаёт подписку самопроизвольно.
- [ ] Background → foreground после сохранения показывает актуальное состояние подписки.
- [ ] Быстрые повторные tap/long press не создают дубликаты и не оставляют противоречивые check/колокольчики.

## 24. Срабатывание пользовательских уведомлений
- [ ] In-stock notification срабатывает при появлении товара в продаже для выбранной страны.
- [ ] In-stock notification не срабатывает для другой страны.
- [ ] Текст уведомления о поступлении: `Now in stock`.
- [ ] Price notification срабатывает, когда цена равна целевой.
- [ ] Price notification срабатывает, когда цена ниже целевой.
- [ ] Price notification не срабатывает, когда цена выше целевой.
- [ ] Price notification не срабатывает по изменению цены другой страны, цвета или характеристики.
- [ ] Текст ценового уведомления: `The price has reached your target`.
- [ ] Отображение/локализация обоих текстов проверяется хотя бы один раз.
- [ ] После удаления подписки соответствующее пользовательское уведомление больше не приходит.

## 25. Ошибки операций с уведомлениями
- [ ] При отсутствии сети создание in-stock notification завершается контролируемой ошибкой без ложного check.
- [ ] При отсутствии сети создание price notification завершается контролируемой ошибкой без ложной строки.
- [ ] При ошибке редактирования сохраняется последнее подтверждённое значение.
- [ ] При ошибке удаления активная подписка восстанавливается/остаётся видимой после синхронизации.
- [ ] После retry создаётся или изменяется одна подписка без дубликатов.
- [ ] Страна создаваемой подписки совпадает со страной выбранной строки и не заменяется на UAE по умолчанию.
- [ ] Условие ценовой подписки работает как `price <= target`, а не как `price > target`.
- [ ] Ответ списка подписок позволяет корректно восстановить товар, страну, тип и целевую цену.
