# Чек-лист: История P2P — все роли

## Область и статус

[Экран](../../03-screens/p2p/p2p-history.md) · [Правила/вопросы](../../04-business-rules/p2p-history.md). [Активные заявки](checklist-p2p-active-requests.md) и [управление](checklist-p2p-active-request.md) проверяются отдельно.

Все `[ ]` — **Not run**. Приложение/сделки/финансовые операции не проверялись; неизвестные ожидания **Blocked**. Стабильные ID не переиспользовать.

## Подготовка данных

- Общая группа клиента/корпа, два реселлера, чужая группа; успешные сделки обоих инициаторов, активные и удалённые/истёкшие без покупки.
- Разные даты создания заявки и покупки по обе стороны согласованных границ; равные даты покупки; ближайший период 6M при отсутствии 1M/3M.
- Товары с флагом/без страны, разные категории/метаданные; успешная покупка с выбранной допгарантией и без неё, положительная наценка реселлера.
- Подтверждённые исходные цена покупки без гарантии/количество/инициатор и обе даты из разрешённого источника. Если источник недоступен — Blocked, не выводить успех только из toast.

## Вход и область

- [ ] **P2PHIST-OPEN-01 — Открытие Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Книга в разделе П2П открывает всплывающую «Историю»/«History» с крестиком и доступными периодами; не Историю обычных заказов.

  </details>

- [ ] **P2PHIST-SCOPE-01 — Общая История сделок клиента и корпа**

  <details>
  <summary>Подробности проверки</summary>

  - Клиент/связанный корп видят общие успешные П2П-сделки, выполненные каждым из них; собственные реселлерские П2П сюда не входят.

  </details>

- [ ] **P2PHIST-SCOPE-02 — Изоляция собственной Истории реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер видит только свои успешные сделки, не клиента/корпа/другого реселлера/чужой группы, даже на одинаковом товаре.

  </details>

- [ ] **P2PHIST-SCOPE-03 — Успешные сделки пользователя и поставщика**

  <details>
  <summary>Подробности проверки</summary>

  - Успешные покупки, подтверждённые пользователем и поставщиком, обе доступны в Истории; активные/удалённые/истёкшие без покупки не показаны.

  </details>

- [ ] **P2PHIST-SCOPE-04 — История сделки без ожидания выдачи заказа**

  <details>
  <summary>Подробности проверки</summary>

  - Сделка после успешной П2П-покупки относится к истории сделок без ожидания выдачи/Paid обычного заказа; это не правила архивирования обычных заказов.

  </details>


## Периоды и разные даты

- [ ] **P2PHIST-PERIOD-01 — Первый доступный период Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Показаны 1M/3M/6M/12M; ближайший доступный с успешной историей выбран при входе.

  </details>

- [ ] **P2PHIST-PERIOD-02 — Выбор 6M при пустых ближайших периодах**

  <details>
  <summary>Подробности проверки</summary>

  - Нет истории в 1M/3M, есть в 6M/12M: первые недоступны, выбран 6M, как на светлом образце.

  </details>

- [ ] **P2PHIST-PERIOD-03 — Данные и итоги выбранного периода**

  <details>
  <summary>Подробности проверки</summary>

  - Сменить доступный период: набор сделок, количество и сумма относятся к выбранному периоду; прежний набор не добавлен повторно.

  </details>

- [ ] **P2PHIST-DATE-01 — Отбор по дате создания заявки**

  <details>
  <summary>Подробности проверки</summary>

  - Для отбора используется дата создания заявки, не дата покупки; взять успешную сделку с различными датами создания/закрытия.

  </details>

- [ ] **P2PHIST-DATE-02 — Исключение заявки, созданной вне периода**

  <details>
  <summary>Подробности проверки</summary>

  - Создание заявки вне выбранного периода, покупка внутри: не включать сделку только по покупке.
  - Точные границы периода — P2PHIST-Q01.

  </details>

- [ ] **P2PHIST-DATE-03 — Включение сделки в период создания заявки**

  <details>
  <summary>Подробности проверки</summary>

  - Создание заявки внутри выбранного периода, покупка позже: успешная сделка относится к периоду создания, не переносится в другой только по закрытию.

  </details>

- [ ] **P2PHIST-DATE-04 — Дата покупки в строке и информации**

  <details>
  <summary>Подробности проверки</summary>

  - В строке и информации дата покупки, не дата создания заявки/поставщика/выдачи обычного заказа.

  </details>

- [ ] **P2PHIST-DATE-05 — Сортировка сделок по дате покупки**

  <details>
  <summary>Подробности проверки</summary>

  - Сделки с разными датами покупки отсортированы по дате покупки, новые первыми; использовать набор с отличающимся порядком создания заявок, не применять сортировку активных по оформлению.

  </details>

- [ ] **P2PHIST-DATE-06 — Неуточнённый порядок равных дат покупки**

  <details>
  <summary>Подробности проверки</summary>

  - Равные даты покупки/вторичный ключ: **Blocked, P2PHIST-Q02**; новый ответ подтвердил направление, но не порядок равных дат.

  </details>

- [ ] **P2PHIST-PERIOD-04 — Неуточнённые календарные границы Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Граница месяца/год/часовой пояс/старше 12M: **Blocked, P2PHIST-Q01**; книга «за год» сохраняет P2PLIST-Q02.

  </details>


## Цены и показатели

- [ ] **P2PHIST-SUM-01 — Количество купленных единиц периода**

  <details>
  <summary>Подробности проверки</summary>

  - Общее количество равно сумме купленных единиц включённых сделок, не числу строк или заявок.

  </details>

- [ ] **P2PHIST-SUM-02 — Исключение дополнительной гарантии из Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Цена в строке/информации и сумма периода исключают дополнительную гарантию, даже когда пользователь выбрал её при П2П-покупке.

  </details>

- [ ] **P2PHIST-PRICE-01 — Наценка исторической цены согласно роли**

  <details>
  <summary>Подробности проверки</summary>

  - У клиента/корпа цены без клиентской наценки; у реселлера с наценкой клиента, но тоже без гарантии.

  </details>

- [ ] **P2PHIST-PRICE-02 — Цена принятого встречного предложения**

  <details>
  <summary>Подробности проверки</summary>

  - При успешном принятии встречного цена относится к принятой покупке, не старой собственной заявке; пример 581 после собственного предложения 580.

  </details>

- [ ] **P2PHIST-PRICE-03 — Цена подтверждённого поставщиком собственного предложения**

  <details>
  <summary>Подробности проверки</summary>

  - При подтверждении поставщиком цена успешной покупки соответствует принятому собственному предложению, без дополнительной гарантии.

  </details>

- [ ] **P2PHIST-SUM-03 — Расчёт суммы периода по цене и количеству**

  <details>
  <summary>Подробности проверки</summary>

  - Сумма периода = сумма цены покупки без гарантии × количество каждого включённого товара; не сумма одиночных цен без количеств.

  </details>

- [ ] **P2PHIST-SUM-04 — Контрольный расчёт количества и суммы**

  <details>
  <summary>Подробности проверки</summary>

  - Для образца 869×50 + 1400×51 + 581×50 = 143900; количество 50+51+50=151.
  - Значения не константы для других данных.

  </details>

- [ ] **P2PHIST-SUM-05 — Исключение чужих и неуспешных заявок из итогов**

  <details>
  <summary>Подробности проверки</summary>

  - Успешные сделки чужой области/другого периода, активные/удалённые без покупки не входят в Qty/Amount.

  </details>

- [ ] **P2PHIST-PRICE-04 — Неуточнённые точность и фиксация исторической цены**

  <details>
  <summary>Подробности проверки</summary>

  - Дробные цены/суммы, фиксация исторической цены после покупки и смена наценки до покупки: **Blocked, P2PHIST-Q05 / P2PACT-Q03** для неуточнённой части.

  </details>


## Строки и информация

- [ ] **P2PHIST-ROW-01 — Состав строки успешной сделки**

  <details>
  <summary>Подробности проверки</summary>

  - Строка показывает флаг при стране либо предусмотренную иконку, корректное название, цену единицы без гарантии, дату покупки и купленное количество.

  </details>

- [ ] **P2PHIST-ROW-02 — Отдельность разных покупок одного товара**

  <details>
  <summary>Подробности проверки</summary>

  - Разные покупки одноимённого товара показывают свои цены/количества/даты; просмотр не сливает их и не подставляет последнюю цену прайса.

  </details>

- [ ] **P2PHIST-ROW-03 — Открытие информации выбранной сделки**

  <details>
  <summary>Подробности проверки</summary>

  - Tap открывает информацию именно о выбранной покупке, не соседний товар/обычный заказ/новую П2П-заявку.

  </details>

- [ ] **P2PHIST-INFO-01 — Основные данные информации о покупке**

  <details>
  <summary>Подробности проверки</summary>

  - В окне название/флаг либо иконка, «Моя цена» без гарантии, «Кол-во» купленных единиц и крестик.

  </details>

- [ ] **P2PHIST-INFO-02 — Дополнительные сведения и инициатор сделки**

  <details>
  <summary>Подробности проверки</summary>

  - На соответствующем образцу товаре показаны код номера, страна, модель, дата/время и «Сделка закрыта» с данными этой покупки.

  </details>

- [ ] **P2PHIST-ACTOR-01 — Поставщик как инициатор завершения**

  <details>
  <summary>Подробности проверки</summary>

  - Поставщик подтвердил собственное предложение покупателя: «Сделка закрыта» показывает «Поставщик», не владельца заявки/открывший аккаунт.

  </details>

- [ ] **P2PHIST-ACTOR-02 — Пользователь как инициатор завершения**

  <details>
  <summary>Подробности проверки</summary>

  - Пользователь принял встречное: инициатор отражает пользователя, не поставщика.
  - Точная подпись/локализация — **Blocked, P2PHIST-Q05**.

  </details>

- [ ] **P2PHIST-ACTOR-03 — Неизменность инициатора при просмотре другим аккаунтом**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть общую сделку другим клиентом/корпом: просмотр не меняет сохранённого инициатора завершения на текущего зрителя.

  </details>

- [ ] **P2PHIST-INFO-03 — Неуточнённые поля разных категорий и время**

  <details>
  <summary>Подробности проверки</summary>

  - Отсутствующие поля/другие категории и источник времени/часовой пояс: **Blocked, P2PHIST-Q05/01**; не считать скрытие пустых полей подтверждённым.

  </details>


## Только просмотр

- [ ] **P2PHIST-LOCK-01 — Запрет редактирования цены и количества сделки**

  <details>
  <summary>Подробности проверки</summary>

  - Цена/количество не редактируются, клавиатура/Continue активного редактора не открываются из информации о покупке.

  </details>

- [ ] **P2PHIST-LOCK-02 — Недоступность повторной сделки и удаления как заявки**

  <details>
  <summary>Подробности проверки</summary>

  - Повторное подтверждение/покупка/изменение гарантии/удаление успешной сделки как активной заявки недоступны.

  </details>

- [ ] **P2PHIST-LOCK-03 — Просмотр без повторного резерва и финансовых изменений**

  <details>
  <summary>Подробности проверки</summary>

  - Открытие/закрытие/поворот/просмотр не занимают лимит повторно и не меняют депозит/баланс/связанный обычный заказ.

  </details>

- [ ] **P2PHIST-LOCK-04 — Отсутствие документов обычного заказа в P2P-информации**

  <details>
  <summary>Подробности проверки</summary>

  - Меню скачивания документов обычного архивного заказа не добавляется в информацию П2П по аналогии; в предоставленном составе только просмотр.

  </details>


## Полноэкранный режим

- [ ] **P2PHIST-FULL-01 — Горизонтальный список выбранного периода**

  <details>
  <summary>Подробности проверки</summary>

  - Кнопка fullscreen открывает горизонтальный список с периодами/крестиком и теми же сделками выбранного периода.

  </details>

- [ ] **P2PHIST-FULL-02 — Данные и роли горизонтальных строк**

  <details>
  <summary>Подробности проверки</summary>

  - Горизонтальные строки содержат название/флаг либо иконку, дату покупки, цену без гарантии и количество; роли/наценка и набор сохраняются.

  </details>

- [ ] **P2PHIST-FULL-03 — Состав горизонтального вида по образцу**

  <details>
  <summary>Подробности проверки</summary>

  - На горизонтальном образце блока общих показателей/заголовка нет; список и периоды соответствуют представленному виду.

  </details>

- [ ] **P2PHIST-FULL-04 — Смена периода в горизонтальном режиме**

  <details>
  <summary>Подробности проверки</summary>

  - Сменить период в горизонтальном режиме: строки относятся к новому периоду по созданию заявки, не по показанной дате покупки.

  </details>

- [ ] **P2PHIST-FULL-05 — Горизонтальная информация выбранной сделки**

  <details>
  <summary>Подробности проверки</summary>

  - Tap в горизонтальном списке открывает горизонтальную информацию о выбранной сделке: название/цена/количество и таблица/инициатор.

  </details>

- [ ] **P2PHIST-FULL-06 — Возврат к горизонтальному списку из информации**

  <details>
  <summary>Подробности проверки</summary>

  - Закрыть горизонтальную информацию крестиком: снова горизонтальный список, не обычная История/активный П2П.

  </details>

- [ ] **P2PHIST-FULL-07 — Возврат из full-screen с прежним периодом**

  <details>
  <summary>Подробности проверки</summary>

  - Крестик fullscreen возвращает обычную Историю с прежним периодом, не закрывает Историю целиком.

  </details>

- [ ] **P2PHIST-FULL-08 — Неизменность сделки при полноэкранном просмотре**

  <details>
  <summary>Подробности проверки</summary>

  - Просмотр/закрытие fullscreen не изменяют покупку и не вызывают новую заявку/финансовое действие.

  </details>


## Загрузка и неуточнённые переходы

- [ ] **P2PHIST-LOAD-01 — Скелетон загрузки Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Загрузка показывает скелетон; отсутствие строк во время запроса не считать доказанным пустым состоянием.

  </details>

- [ ] **P2PHIST-LOAD-02 — Отсутствие ручного обновления Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Ручного refresh / pull-to-refresh нет; не добавлять его из статистики или активного списка обычных заказов.

  </details>

- [ ] **P2PHIST-LOAD-03 — Неуточнённые события и ошибки открытой Истории**

  <details>
  <summary>Подробности проверки</summary>

  - Новая успешная сделка в уже открытой Истории, ошибки/фон/real-time/пустота: **Blocked, P2PHIST-Q04**.

  </details>

- [ ] **P2PHIST-BACK-01 — Независимость Истории от фильтра активного списка**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть Историю из «Все чаты», затем из «Поставщик»: состав успешных сделок соответствующей роли не зависит от фильтра исходного списка.

  </details>

- [ ] **P2PHIST-BACK-02 — Сохранение периода после просмотра информации**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать не первый доступный период, открыть информацию о сделке и закрыть её: выбранный период Истории сохранён.

  </details>

- [ ] **P2PHIST-BACK-03 — Дефолтный период при новом открытии Истории**

  <details>
  <summary>Подробности проверки</summary>

  - Закрыть Историю после выбора не первого доступного периода и открыть заново: снова ближайший доступный, прежний период не восстановлен.

  </details>

- [ ] **P2PHIST-BACK-04 — Неуточнённые закрытие и прокрутка Истории P2P**

  <details>
  <summary>Подробности проверки</summary>

  - Прокрутка/способы закрытия самой Истории: **Blocked, P2PHIST-Q03**; подтверждённые периоды/отсутствие влияния фильтра не задают эти детали.

  </details>
