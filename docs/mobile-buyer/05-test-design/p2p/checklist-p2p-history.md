# Чек-лист: История P2P — все роли

## Область и статус

[Экран](../../03-screens/p2p/p2p-history.md) · [Правила/вопросы](../../04-business-rules/p2p-history.md). [Активные заявки](checklist-p2p-active-requests.md) и [управление](checklist-p2p-active-request.md) проверяются отдельно.

Все `[ ]` — **Not run**. Приложение/сделки/финансовые операции не проверялись; неизвестные ожидания **Blocked**. Стабильные ID не переиспользовать.

## Подготовка данных

- Общая группа клиента/корпа, два реселлера, чужая группа; успешные сделки обоих инициаторов, активные и удалённые/истёкшие без покупки.
- Разные даты создания заявки и покупки по обе стороны согласованных границ; равные даты покупки; ближайший период 6M при отсутствии 1M/3M.
- Товары с флагом/без страны, разные категории/метаданные; успешная покупка с выбранной допгарантией и без неё, положительная наценка реселлера.
- Подтверждённые исходные цена покупки без гарантии/количество/инициатор и обе даты из разрешённого источника. Если источник недоступен — Blocked, не выводить успех только из toast.

## Вход и область

- [ ] **P2PHIST-OPEN-01** — Книга в разделе П2П открывает всплывающую «Историю»/«History» с крестиком и доступными периодами; не Историю обычных заказов.
- [ ] **P2PHIST-SCOPE-01** — Клиент/связанный корп видят общие успешные П2П-сделки, выполненные каждым из них; собственные реселлерские П2П сюда не входят.
- [ ] **P2PHIST-SCOPE-02** — Реселлер видит только свои успешные сделки, не клиента/корпа/другого реселлера/чужой группы, даже на одинаковом товаре.
- [ ] **P2PHIST-SCOPE-03** — Успешные покупки, подтверждённые пользователем и поставщиком, обе доступны в Истории; активные/удалённые/истёкшие без покупки не показаны.
- [ ] **P2PHIST-SCOPE-04** — Сделка после успешной П2П-покупки относится к истории сделок без ожидания выдачи/Paid обычного заказа; это не правила архивирования обычных заказов.

## Периоды и разные даты

- [ ] **P2PHIST-PERIOD-01** — Показаны 1M/3M/6M/12M; ближайший доступный с успешной историей выбран при входе.
- [ ] **P2PHIST-PERIOD-02** — Нет истории в 1M/3M, есть в 6M/12M: первые недоступны, выбран 6M, как на светлом образце.
- [ ] **P2PHIST-PERIOD-03** — Сменить доступный период: набор сделок, количество и сумма относятся к выбранному периоду; прежний набор не добавлен повторно.
- [ ] **P2PHIST-DATE-01** — Для отбора используется дата создания заявки, не дата покупки; взять успешную сделку с различными датами создания/закрытия.
- [ ] **P2PHIST-DATE-02** — Создание заявки вне выбранного периода, покупка внутри: не включать сделку только по покупке. Точные границы периода — P2PHIST-Q01.
- [ ] **P2PHIST-DATE-03** — Создание заявки внутри выбранного периода, покупка позже: успешная сделка относится к периоду создания, не переносится в другой только по закрытию.
- [ ] **P2PHIST-DATE-04** — В строке и информации дата покупки, не дата создания заявки/поставщика/выдачи обычного заказа.
- [ ] **P2PHIST-DATE-05** — Поле сортировки — дата покупки; направление/равные даты: **Blocked, P2PHIST-Q02**, не применять сортировку активных заявок по оформлению.
- [ ] **P2PHIST-PERIOD-04** — Граница месяца/год/часовой пояс/старше 12M: **Blocked, P2PHIST-Q01**; книга «за год» сохраняет P2PLIST-Q02.

## Цены и показатели

- [ ] **P2PHIST-SUM-01** — Общее количество равно сумме купленных единиц включённых сделок, не числу строк или заявок.
- [ ] **P2PHIST-SUM-02** — Цена в строке/информации и сумма периода исключают дополнительную гарантию, даже когда пользователь выбрал её при П2П-покупке.
- [ ] **P2PHIST-PRICE-01** — У клиента/корпа цены без клиентской наценки; у реселлера с наценкой клиента, но тоже без гарантии.
- [ ] **P2PHIST-PRICE-02** — При успешном принятии встречного цена относится к принятой покупке, не старой собственной заявке; пример 581 после собственного предложения 580.
- [ ] **P2PHIST-PRICE-03** — При подтверждении поставщиком цена успешной покупки соответствует принятому собственному предложению, без дополнительной гарантии.
- [ ] **P2PHIST-SUM-03** — Сумма периода = сумма цены покупки без гарантии × количество каждого включённого товара; не сумма одиночных цен без количеств.
- [ ] **P2PHIST-SUM-04** — Для образца 869×50 + 1400×51 + 581×50 = 143900; количество 50+51+50=151. Значения не константы для других данных.
- [ ] **P2PHIST-SUM-05** — Успешные сделки чужой области/другого периода, активные/удалённые без покупки не входят в Qty/Amount.
- [ ] **P2PHIST-PRICE-04** — Дробные цены/суммы, фиксация исторической цены после покупки и смена наценки до покупки: **Blocked, P2PHIST-Q05 / P2PACT-Q03** для неуточнённой части.

## Строки и информация

- [ ] **P2PHIST-ROW-01** — Строка показывает флаг при стране либо предусмотренную иконку, корректное название, цену единицы без гарантии, дату покупки и купленное количество.
- [ ] **P2PHIST-ROW-02** — Разные покупки одноимённого товара показывают свои цены/количества/даты; просмотр не сливает их и не подставляет последнюю цену прайса.
- [ ] **P2PHIST-ROW-03** — Tap открывает информацию именно о выбранной покупке, не соседний товар/обычный заказ/новую П2П-заявку.
- [ ] **P2PHIST-INFO-01** — В окне название/флаг либо иконка, «Моя цена» без гарантии, «Кол-во» купленных единиц и крестик.
- [ ] **P2PHIST-INFO-02** — На соответствующем образцу товаре показаны код номера, страна, модель, дата/время и «Сделка закрыта» с данными этой покупки.
- [ ] **P2PHIST-ACTOR-01** — Поставщик подтвердил собственное предложение покупателя: «Сделка закрыта» показывает «Поставщик», не владельца заявки/открывший аккаунт.
- [ ] **P2PHIST-ACTOR-02** — Пользователь принял встречное: инициатор отражает пользователя, не поставщика. Точная подпись/локализация — **Blocked, P2PHIST-Q05**.
- [ ] **P2PHIST-ACTOR-03** — Открыть общую сделку другим клиентом/корпом: просмотр не меняет сохранённого инициатора завершения на текущего зрителя.
- [ ] **P2PHIST-INFO-03** — Отсутствующие поля/другие категории и источник времени/часовой пояс: **Blocked, P2PHIST-Q05/01**; не считать скрытие пустых полей подтверждённым.

## Только просмотр

- [ ] **P2PHIST-LOCK-01** — Цена/количество не редактируются, клавиатура/Continue активного редактора не открываются из информации о покупке.
- [ ] **P2PHIST-LOCK-02** — Повторное подтверждение/покупка/изменение гарантии/удаление успешной сделки как активной заявки недоступны.
- [ ] **P2PHIST-LOCK-03** — Открытие/закрытие/поворот/просмотр не занимают лимит повторно и не меняют депозит/баланс/связанный обычный заказ.
- [ ] **P2PHIST-LOCK-04** — Меню скачивания документов обычного архивного заказа не добавляется в информацию П2П по аналогии; в предоставленном составе только просмотр.

## Полноэкранный режим

- [ ] **P2PHIST-FULL-01** — Кнопка fullscreen открывает горизонтальный список с периодами/крестиком и теми же сделками выбранного периода.
- [ ] **P2PHIST-FULL-02** — Горизонтальные строки содержат название/флаг либо иконку, дату покупки, цену без гарантии и количество; роли/наценка и набор сохраняются.
- [ ] **P2PHIST-FULL-03** — На горизонтальном образце блока общих показателей/заголовка нет; список и периоды соответствуют представленному виду.
- [ ] **P2PHIST-FULL-04** — Сменить период в горизонтальном режиме: строки относятся к новому периоду по созданию заявки, не по показанной дате покупки.
- [ ] **P2PHIST-FULL-05** — Tap в горизонтальном списке открывает горизонтальную информацию о выбранной сделке: название/цена/количество и таблица/инициатор.
- [ ] **P2PHIST-FULL-06** — Закрыть горизонтальную информацию крестиком: снова горизонтальный список, не обычная История/активный П2П.
- [ ] **P2PHIST-FULL-07** — Крестик fullscreen возвращает обычную Историю с прежним периодом, не закрывает Историю целиком.
- [ ] **P2PHIST-FULL-08** — Просмотр/закрытие fullscreen не изменяют покупку и не вызывают новую заявку/финансовое действие.

## Загрузка и неуточнённые переходы

- [ ] **P2PHIST-LOAD-01** — Загрузка показывает скелетон; отсутствие строк во время запроса не считать доказанным пустым состоянием.
- [ ] **P2PHIST-LOAD-02** — Ручного refresh / pull-to-refresh нет; не добавлять его из статистики или активного списка обычных заказов.
- [ ] **P2PHIST-LOAD-03** — Новая успешная сделка в уже открытой Истории, ошибки/фон/real-time/пустота: **Blocked, P2PHIST-Q04**.
- [ ] **P2PHIST-BACK-01** — Передача «Все чаты / Поставщик», период при обычном возврате из информации/повторном открытии и прокрутка: **Blocked, P2PHIST-Q03**; ответ «Нет» не разделил три условия.
