# Чек-лист: Профиль — все роли

## Область и статус

[Экран](../../03-screens/profile/profile.md) · [Правила и вопросы](../../04-business-rules/profile.md).

Все `[ ]` — **Not run**, не Fail. Приложение/средства/настройки не проверялись. Неизвестные ожидания **Blocked**. ID стабильны; префикс PROF не заменяет PROFILE регистрации.

## Подготовка

- Клиент, два связанных корпа, два реселлера, чужая группа; собственные имя/фото и варианты без фото, разные ID.
- Варианты с доступом/без доступа к реселлеру; собственная часть депозита и выделенные реселлерам части, общие средства клиента/корпа, разные средства реселлеров.
- Заказы/П2П с занятым лимитом; разрешённый источник изменения средств/резервов. При отсутствии такого доступа финансовая проверка Blocked, не Pass по одному отображению.
- Новые дочерние аккаунты для первого старта с языком/темой клиента, отличающимися от устройства; аккаунты с собственными сохранёнными настройками.
- Информация подписки клиента; релизная сборка, обе темы/языка и поддерживаемые размеры экрана. Dev-вариант только для проверки отличия Components.

## Вход, данные и роли

- [ ] **PROF-OPEN-01** — Вкладка профиля открывает данные текущего аккаунта; предыдущая роль/чужой аккаунт не подставляются.
- [ ] **PROF-ROLE-01** — Клиент: есть «Изм.», имя, аватар/заглушка и собственный ID.
- [ ] **PROF-ROLE-02** — Корп: есть «Изм.», собственные имя/аватар/ID, а не данные имени/фото клиента.
- [ ] **PROF-ROLE-03** — Реселлер: только стандартная заглушка и собственный ID, без имени и «Изм.».
- [ ] **PROF-AVATAR-01** — У клиента/корпа с установленным фото оно показано в профиле; без фото стандартная заглушка.
- [ ] **PROF-EDIT-01** — «Изм.» у клиента открывает редактирование его профиля; содержимое/сохранение — PROF-Q07.
- [ ] **PROF-EDIT-02** — «Изм.» у корпа открывает редактирование его профиля; не редактирование клиента. Содержимое — PROF-Q07.
- [ ] **PROF-ROLE-04** — Смена авторизованного аккаунта между ролями не оставляет меню/имя/баланс прежнего; проверять после открытия профиля.

## Баланс, депозит и лимит

- [ ] **PROF-MONEY-01** — Баланс отображается у клиента и корпа, отсутствует у реселлера.
- [ ] **PROF-MONEY-02** — После открытия/refresh клиент и связанные корпы видят один общий баланс; суммы чужой группы не смешиваются.
- [ ] **PROF-MONEY-03** — Tap по балансу клиента/корпа открывает экран баланса; операции этого экрана отдельно PROF-Q07.
- [ ] **PROF-MONEY-04** — Депозит и лимит показаны у всех трёх ролей, не подменяются балансом.
- [ ] **PROF-MONEY-05** — Клиент/корпы после обновления показывают общие депозит и доступный лимит; отдельные финансовые карточки корпа не создаются.
- [ ] **PROF-MONEY-06** — Реселлер после обновления показывает собственные депозит/лимит; суммы клиента и другого реселлера не подставляются.
- [ ] **PROF-DEPOSIT-01** — В карточке клиента/корпа собственный депозит исключает выделенные реселлерам средства; сверить с разрешённым источником.
- [ ] **PROF-LIMIT-01** — Есть занятый лимит заказов: профиль показывает свободный остаток, а не исходный депозит × 20.
- [ ] **PROF-LIMIT-02** — Есть резерв активной П2П-заявки: после открытия/refresh свободный лимит учитывает этот резерв.
- [ ] **PROF-LIMIT-03** — После удаления П2П и освобождения его резерва открыть/обновить профиль: доступный остаток соответствует новому значению.
- [ ] **PROF-LIMIT-04** — После подтверждённого события освобождения лимита заказа обновить профиль: показан доступный остаток, не прежняя занятая сумма.
- [ ] **PROF-TAP-01** — Карточка лимита у клиента, корпа и реселлера не открывает экран и не меняет средства.
- [ ] **PROF-TAP-02** — Карточка депозита реселлера не нажимается и не открывает управление средствами.
- [ ] **PROF-MONEY-07** — Дробный баланс/большие суммы читаемы и не обрезаны; точные правила округления/нулевые состояния без образца — Blocked, PROF-Q05.

## Окна депозита

- [ ] **PROF-DEPOSIT-02** — У клиента с доступом к функционалу реселлера tap депозита открывает список депозитов.
- [ ] **PROF-DEPOSIT-03** — У связанного корпа с тем же общим доступом tap депозита открывает список депозитов.
- [ ] **PROF-DEPOSIT-04** — Без доступа к функционалу реселлера tap депозита клиента/корпа открывает информационное окно вместо списка.
- [ ] **PROF-DEPOSIT-05** — Список показывает собственную часть клиента и части реселлеров с соответствующими ID/значениями, без повторного учёта общей суммы корпа.
- [ ] **PROF-DEPOSIT-06** — «итого» равно собственной части плюс выделенные части реселлеров; пример 104351 + 5154 = 109505 воспроизводится при таких данных.
- [ ] **PROF-DEPOSIT-07** — Tap по строке депозита запускает переход к редактированию; точный экран, поля, проверки и результат изменения — Blocked, PROF-Q03.
- [ ] **PROF-DEPOSIT-08** — Информационное окно содержит сведения о минимальном депозите, лимите, увеличении и возврате, банковском/наличном способах и поддержке по образцу.
- [ ] **PROF-DEPOSIT-09** — Банковский перевод / Наличный расчет представлены раскрывающимися строками; содержание и действия после раскрытия — Blocked, PROF-Q03.
- [ ] **PROF-DEPOSIT-10** — Открытие информационного окна само по себе не выполняет внесение/возврат/перераспределение средств.
- [ ] **PROF-DEPOSIT-11** — Кнопка X закрывает показанное окно депозита; нет изменения средств только от закрытия.

## Меню и доступ

- [ ] **PROF-MENU-01** — Корпоративный доступ есть только у клиента; у корпа/реселлера отсутствует.
- [ ] **PROF-CORP-01** — Tap Корпоративный доступ открывает список связанных корпов с ID и аватарами/заглушками и «Добавить участника».
- [ ] **PROF-CORP-02** — Добавление/редактирование участника, пустота и ограничения — Blocked, PROF-Q04; наличие кнопки не доказывает успешное создание.
- [ ] **PROF-RESELLER-01** — «Реселлер» присутствует у клиента/корпа, отсутствует у реселлера.
- [ ] **PROF-RESELLER-02** — Нет доступа: tap Реселлер открывает alert с предложением подключать клиентов/связаться с менеджером и «Закрыть».
- [ ] **PROF-RESELLER-03** — Закрыть информационный alert: список/редактирование реселлеров не открываются, доступ не активирован автоматически.
- [ ] **PROF-RESELLER-04** — Есть общий доступ: клиент и корп открывают список реселлеров с ID/статусом и «Добавить Клиента» вместо alert.
- [ ] **PROF-RESELLER-05** — Для активного реселлера на показанном варианте отображается «Актив»; остальные статусы/действия/добавление — Blocked, PROF-Q04.
- [ ] **PROF-MENU-02** — «Получатель» у клиента/корпа открывает список логистов; у реселлера пункта нет.
- [ ] **PROF-MENU-03** — «Компенсация» у клиента/корпа открывает соответствующий экран; у реселлера пункта нет.
- [ ] **PROF-MENU-04** — «Сервис» у клиента/корпа открывает соответствующий экран; у реселлера пункта нет.
- [ ] **PROF-SUPPORT-01** — «Служба поддержки» у клиента/корпа открывает чат поддержки текущего аккаунта; у реселлера пункта нет.
- [ ] **PROF-SUPPORT-02** — Клиент и связанный корп с разными сообщениями видят отдельные чат/историю; общий баланс не объединяет обращения.
- [ ] **PROF-MENU-05** — «Гарантия» есть у всех ролей, открывает экран гарантии; внутренние действия — PROF-Q07.
- [ ] **PROF-MENU-06** — «Fimex» у клиента/корпа открывает «О нас», у реселлера пункта нет; информация/ссылки отдельно PROF-Q07.
- [ ] **PROF-MENU-07** — Кнопка X закрывает показанные списки корпов/реселлеров; создание аккаунта не происходит от закрытия.

## Язык

- [ ] **PROF-LANG-01** — «Язык» доступен у клиента, корпа и реселлера и открывает окно выбора языка.
- [ ] **PROF-LANG-02** — Русский/английский с флагами/названиями и отметкой текущего языка по образцу; правильная отметка при открытии.
- [ ] **PROF-LANG-03** — Выбрать English из русского: интерфейс сразу переключается, окно закрывается автоматически, отдельного подтверждения нет.
- [ ] **PROF-LANG-04** — Выбрать Russian из английского: интерфейс сразу переключается, окно закрывается автоматически.
- [ ] **PROF-LANG-05** — Повторно открыть профиль/войти в тот же аккаунт: используется его сохранённый язык на backend, не язык прежнего аккаунта.
- [ ] **PROF-LANG-06** — Корп меняет свой язык: язык клиента и соседнего корпа остаётся их собственным.
- [ ] **PROF-LANG-07** — Реселлер меняет свой язык: язык клиента и другого реселлера остаётся их собственным.
- [ ] **PROF-LANG-08** — При первом старте нового корпа исходный язык берётся из профиля клиента, в том числе при отличающемся языке устройства.
- [ ] **PROF-LANG-09** — При первом старте нового реселлера исходный язык берётся из профиля клиента; после собственного выбора новый вход не сбрасывает его к клиентскому.

## Оформление

- [ ] **PROF-THEME-01** — «Оформление» доступно всем ролям, открывает «Выберите фон» со светлой/тёмной карточками и отметкой текущей.
- [ ] **PROF-THEME-02** — Выбрать Светлый из тёмной темы: интерфейс сразу меняется, окно автоматически закрывается, отдельного подтверждения нет.
- [ ] **PROF-THEME-03** — Выбрать Темный из светлой темы: интерфейс сразу меняется, окно автоматически закрывается.
- [ ] **PROF-THEME-04** — После повторного открытия/входа используется сохранённая тема этого аккаунта на backend.
- [ ] **PROF-THEME-05** — Корп меняет свою тему: темы клиента и соседнего корпа не меняются.
- [ ] **PROF-THEME-06** — Реселлер меняет свою тему: темы клиента и другого реселлера не меняются.
- [ ] **PROF-THEME-07** — При первом старте нового корпа тема берётся из профиля клиента, в том числе при другой теме устройства.
- [ ] **PROF-THEME-08** — При первом старте нового реселлера тема берётся из профиля клиента; после собственного выбора новый вход использует её.
- [ ] **PROF-SETTINGS-01** — Изменение языка не сбрасывает сохранённую тему, изменение темы не сбрасывает язык того же аккаунта.
- [ ] **PROF-SETTINGS-02** — Офлайн/ошибка сохранения, два устройства и изменение настроек клиента до собственного выбора дочернего — Blocked, PROF-Q06.

## Подписка, выход и сборка

- [ ] **PROF-SUB-01** — «Подписка» есть только у клиента; у корпа и реселлера отсутствует.
- [ ] **PROF-SUB-02** — Tap Подписка открывает информацию клиента с тарифом/периодом/валютой и следующим платежом; не фиксировать пример ₽44990/дату для всех аккаунтов.
- [ ] **PROF-SUB-03** — В окне есть «Управление подписками» и ссылки на соглашение/политику; их назначения и системный экран — Blocked, PROF-Q02.
- [ ] **PROF-SUB-04** — Кнопка X закрывает информацию о подписке; просмотр/закрытие не оформляет новую подписку и не меняет баланс.
- [ ] **PROF-SUB-05** — Истёкшая/отменённая/пробная подписка: состав информации и действий — Blocked, PROF-Q02; ограничения входа проверяются отдельно.
- [ ] **PROF-EXIT-01** — У клиента/корпа «Выйти» находится в редактировании профиля, у реселлера непосредственно в профиле.
- [ ] **PROF-EXIT-02** — Подтверждение выхода, экран после выхода и очистка сессии/автовхода — Blocked, PROF-Q01.
- [ ] **PROF-BUILD-01** — В релизной сборке Components отсутствует у всех ролей; Dev-экран не включать в релизный профиль.

## Загрузка, refresh и интерфейс

- [ ] **PROF-LOAD-01** — При загрузке профиля скелетон, не ложные нулевые финансовые данные вместо результата.
- [ ] **PROF-REFRESH-01** — Ручной refresh профиля доступен; не применять отсутствие обновления Истории/П2П к этому экрану.
- [ ] **PROF-REFRESH-02** — Изменить баланс через разрешённый источник при открытом профиле: real-time обновления карточки нет; после refresh показано актуальное значение.
- [ ] **PROF-REFRESH-03** — Изменить депозит при открытом профиле: карточка обновляется после refresh; без него real-time нет.
- [ ] **PROF-REFRESH-04** — Изменить занятый лимит при открытом профиле: свободный остаток обновляется после refresh; без него real-time нет.
- [ ] **PROF-REFRESH-05** — После изменения финансов вне профиля открыть его: баланс/депозит/лимит загружаются актуальными для текущей роли.
- [ ] **PROF-LOAD-02** — Сеть/ошибка refresh/фон/возврат из вложенного окна, старые данные и обновление вложенных списков — Blocked, PROF-Q05.
- [ ] **PROF-UI-01** — На поддерживаемых размерах экрана меню прокручивается до нижних пунктов, элементы доступны для tap и не скрыты нижней панелью Liquid Glass.
- [ ] **PROF-UI-02** — Светлая/тёмная темы: финансовые значения, имена/ID, отметки выбора и alert читаемы по образцам; нет наложений/обрезания длинного имени/ID/суммы.
- [ ] **PROF-UI-03** — Окна выбора языка/темы и показанные модальные окна: кнопки X доступны, фон/стек не мешают выбору, правильная роль сохраняется после закрытия.
