# Чек-лист: Профиль — все роли

## Область и статус

[Экран](../../03-screens/profile/profile.md) · [Правила и вопросы](../../04-business-rules/profile.md).

Все `[ ]` — **Not run**, не Fail. Приложение/средства/настройки не проверялись. Неизвестные ожидания **Blocked**. ID стабильны; префикс PROF не заменяет PROFILE регистрации.

## Подготовка

- Клиент, два связанных корпа, два реселлера, чужая группа; собственные имя/фото и варианты без фото, разные ID.
- Варианты с доступом/без доступа к реселлеру; собственная часть депозита и выделенные реселлерам части, общие средства клиента/корпа, разные средства реселлеров.
- Заказы/П2П с занятым лимитом; разрешённый источник изменения средств/резервов. При отсутствии такого доступа финансовая проверка Blocked, не Pass по одному отображению.
- Новые дочерние аккаунты для первого старта с языком/темой клиента, отличающимися от устройства; аккаунты с собственными сохранёнными настройками.
- Информация подписки клиента; релизная сборка, обе темы/языка и поддерживаемые размеры экрана. Dev-вариант только для проверки отличия Components.

## Вход, данные и роли

- [ ] **PROF-OPEN-01 — Данные текущего аккаунта в профиле**

  <details>
  <summary>Подробности проверки</summary>

  - Вкладка профиля открывает данные текущего аккаунта; предыдущая роль/чужой аккаунт не подставляются.

  </details>

- [ ] **PROF-ROLE-01 — Профиль основного клиента**

  <details>
  <summary>Подробности проверки</summary>

  - Клиент: есть «Изм.», имя, аватар/заглушка и собственный ID.

  </details>

- [ ] **PROF-ROLE-02 — Собственный профиль корпоративного пользователя**

  <details>
  <summary>Подробности проверки</summary>

  - Корп: есть «Изм.», собственные имя/аватар/ID, а не данные имени/фото клиента.

  </details>

- [ ] **PROF-ROLE-03 — Ограниченный состав профиля реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер: только стандартная заглушка и собственный ID, без имени и «Изм.».

  </details>

- [ ] **PROF-AVATAR-01 — Аватар и стандартная заглушка**

  <details>
  <summary>Подробности проверки</summary>

  - У клиента/корпа с установленным фото оно показано в профиле; без фото стандартная заглушка.

  </details>

- [ ] **PROF-EDIT-01 — Переход к редактированию профиля клиента**

  <details>
  <summary>Подробности проверки</summary>

  - «Изм.» у клиента открывает редактирование его профиля; содержимое/сохранение — PROF-Q07.

  </details>

- [ ] **PROF-EDIT-02 — Переход к редактированию профиля корпа**

  <details>
  <summary>Подробности проверки</summary>

  - «Изм.» у корпа открывает редактирование его профиля; не редактирование клиента.
  - Содержимое — PROF-Q07.

  </details>

- [ ] **PROF-ROLE-04 — Отсутствие данных прежней роли после смены аккаунта**

  <details>
  <summary>Подробности проверки</summary>

  - Смена авторизованного аккаунта между ролями не оставляет меню/имя/баланс прежнего; проверять после открытия профиля.

  </details>


## Баланс, депозит и лимит

- [ ] **PROF-MONEY-01 — Видимость баланса по роли**

  <details>
  <summary>Подробности проверки</summary>

  - Баланс отображается у клиента и корпа, отсутствует у реселлера.

  </details>

- [ ] **PROF-MONEY-02 — Общий баланс клиента и корпов**

  <details>
  <summary>Подробности проверки</summary>

  - После открытия/refresh клиент и связанные корпы видят один общий баланс; суммы чужой группы не смешиваются.

  </details>

- [ ] **PROF-MONEY-03 — Переход к экрану баланса**

  <details>
  <summary>Подробности проверки</summary>

  - Tap по балансу клиента/корпа открывает экран баланса; операции этого экрана отдельно PROF-Q07.

  </details>

- [ ] **PROF-MONEY-04 — Депозит и лимит всех ролей**

  <details>
  <summary>Подробности проверки</summary>

  - Депозит и лимит показаны у всех трёх ролей, не подменяются балансом.

  </details>

- [ ] **PROF-MONEY-05 — Общие депозит и лимит клиента и корпа**

  <details>
  <summary>Подробности проверки</summary>

  - Клиент/корпы после обновления показывают общие депозит и доступный лимит; отдельные финансовые карточки корпа не создаются.

  </details>

- [ ] **PROF-MONEY-06 — Собственные депозит и лимит реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер после обновления показывает собственные депозит/лимит; суммы клиента и другого реселлера не подставляются.

  </details>

- [ ] **PROF-DEPOSIT-01 — Исключение выделенных средств из депозита клиента**

  <details>
  <summary>Подробности проверки</summary>

  - В карточке клиента/корпа собственный депозит исключает выделенные реселлерам средства; сверить с разрешённым источником.

  </details>

- [ ] **PROF-LIMIT-01 — Свободный лимит с учётом заказов**

  <details>
  <summary>Подробности проверки</summary>

  - Есть занятый лимит заказов: профиль показывает свободный остаток, а не исходный депозит × 20.

  </details>

- [ ] **PROF-LIMIT-02 — Свободный лимит с учётом P2P-резерва**

  <details>
  <summary>Подробности проверки</summary>

  - Есть резерв активной П2П-заявки: после открытия/refresh свободный лимит учитывает этот резерв.

  </details>

- [ ] **PROF-LIMIT-03 — Обновление лимита после удаления P2P**

  <details>
  <summary>Подробности проверки</summary>

  - После удаления П2П и освобождения его резерва открыть/обновить профиль: доступный остаток соответствует новому значению.

  </details>

- [ ] **PROF-LIMIT-04 — Обновление лимита после освобождения заказом**

  <details>
  <summary>Подробности проверки</summary>

  - После подтверждённого события освобождения лимита заказа обновить профиль: показан доступный остаток, не прежняя занятая сумма.

  </details>

- [ ] **PROF-TAP-01 — Неинтерактивная карточка лимита**

  <details>
  <summary>Подробности проверки</summary>

  - Карточка лимита у клиента, корпа и реселлера не открывает экран и не меняет средства.

  </details>

- [ ] **PROF-TAP-02 — Неинтерактивный депозит реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Карточка депозита реселлера не нажимается и не открывает управление средствами.

  </details>

- [ ] **PROF-MONEY-07 — Отображение дробных и больших финансовых сумм**

  <details>
  <summary>Подробности проверки</summary>

  - Дробный баланс/большие суммы читаемы и не обрезаны; точные правила округления/нулевые состояния без образца — Blocked, PROF-Q05.

  </details>


## Окна депозита

- [ ] **PROF-DEPOSIT-02 — Список депозитов клиента с доступом**

  <details>
  <summary>Подробности проверки</summary>

  - У клиента с доступом к функционалу реселлера tap депозита открывает список депозитов.

  </details>

- [ ] **PROF-DEPOSIT-03 — Список депозитов корпа с доступом**

  <details>
  <summary>Подробности проверки</summary>

  - У связанного корпа с тем же общим доступом tap депозита открывает список депозитов.

  </details>

- [ ] **PROF-DEPOSIT-04 — Информация о депозите без доступа к реселлерам**

  <details>
  <summary>Подробности проверки</summary>

  - Без доступа к функционалу реселлера tap депозита клиента/корпа открывает информационное окно вместо списка.

  </details>

- [ ] **PROF-DEPOSIT-05 — Состав частей депозита в списке**

  <details>
  <summary>Подробности проверки</summary>

  - Список показывает собственную часть клиента и части реселлеров с соответствующими ID/значениями, без повторного учёта общей суммы корпа.

  </details>

- [ ] **PROF-DEPOSIT-06 — Сумма частей депозита**

  <details>
  <summary>Подробности проверки</summary>

  - «итого» равно собственной части плюс выделенные части реселлеров; пример 104351 + 5154 = 109505 воспроизводится при таких данных.

  </details>

- [ ] **PROF-DEPOSIT-07 — Неуточнённое редактирование депозита**

  <details>
  <summary>Подробности проверки</summary>

  - Tap по строке депозита запускает переход к редактированию; точный экран, поля, проверки и результат изменения — Blocked, PROF-Q03.

  </details>

- [ ] **PROF-DEPOSIT-08 — Содержание информации о депозите**

  <details>
  <summary>Подробности проверки</summary>

  - Информационное окно содержит сведения о минимальном депозите, лимите, увеличении и возврате, банковском/наличном способах и поддержке по образцу.

  </details>

- [ ] **PROF-DEPOSIT-09 — Раскрытие способов внесения депозита**

  <details>
  <summary>Подробности проверки</summary>

  - Банковский перевод / Наличный расчет представлены раскрывающимися строками; содержание и действия после раскрытия — Blocked, PROF-Q03.

  </details>

- [ ] **PROF-DEPOSIT-10 — Отсутствие операций от открытия информации**

  <details>
  <summary>Подробности проверки</summary>

  - Открытие информационного окна само по себе не выполняет внесение/возврат/перераспределение средств.

  </details>

- [ ] **PROF-DEPOSIT-11 — Закрытие окна депозита без изменений**

  <details>
  <summary>Подробности проверки</summary>

  - Кнопка X закрывает показанное окно депозита; нет изменения средств только от закрытия.

  </details>

## Язык

- [ ] **PROF-LANG-01 — Доступность выбора языка всем ролям**

  <details>
  <summary>Подробности проверки</summary>

  - «Язык» доступен у клиента, корпа и реселлера и открывает окно выбора языка.

  </details>

- [ ] **PROF-LANG-02 — Языки и отметка текущего выбора**

  <details>
  <summary>Подробности проверки</summary>

  - Русский/английский с флагами/названиями и отметкой текущего языка по образцу; правильная отметка при открытии.

  </details>

- [ ] **PROF-LANG-03 — Немедленное переключение на английский**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать English из русского: интерфейс сразу переключается, окно закрывается автоматически, отдельного подтверждения нет.

  </details>

- [ ] **PROF-LANG-04 — Немедленное переключение на русский**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать Russian из английского: интерфейс сразу переключается, окно закрывается автоматически.

  </details>

- [ ] **PROF-LANG-05 — Сохранённый язык аккаунта после входа**

  <details>
  <summary>Подробности проверки</summary>

  - Повторно открыть профиль/войти в тот же аккаунт: используется его сохранённый язык на backend, не язык прежнего аккаунта.

  </details>

- [ ] **PROF-LANG-06 — Независимость языка корпа**

  <details>
  <summary>Подробности проверки</summary>

  - Корп меняет свой язык: язык клиента и соседнего корпа остаётся их собственным.

  </details>

- [ ] **PROF-LANG-07 — Независимость языка реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - Реселлер меняет свой язык: язык клиента и другого реселлера остаётся их собственным.

  </details>

- [ ] **PROF-LANG-08 — Начальный язык нового корпа**

  <details>
  <summary>Подробности проверки</summary>

  - При первом старте нового корпа исходный язык берётся из профиля клиента, в том числе при отличающемся языке устройства.

  </details>

- [ ] **PROF-LANG-09 — Начальный и собственный язык реселлера**

  <details>
  <summary>Подробности проверки</summary>

  - При первом старте нового реселлера исходный язык берётся из профиля клиента; после собственного выбора новый вход не сбрасывает его к клиентскому.

  </details>

  <details>

## Загрузка, refresh и интерфейс

- [ ] **PROF-LOAD-01 — Скелетон загрузки профиля**

  <details>
  <summary>Подробности проверки</summary>

  - При загрузке профиля скелетон, не ложные нулевые финансовые данные вместо результата.

  </details>

- [ ] **PROF-REFRESH-01 — Доступность ручного обновления профиля**

  <details>
  <summary>Подробности проверки</summary>

  - Ручной refresh профиля доступен; не применять отсутствие обновления Истории/П2П к этому экрану.

  </details>

- [ ] **PROF-REFRESH-02 — Баланс после refresh без real-time**

  <details>
  <summary>Подробности проверки</summary>

  - Изменить баланс через разрешённый источник при открытом профиле: real-time обновления карточки нет; после refresh показано актуальное значение.

  </details>

- [ ] **PROF-REFRESH-03 — Депозит после refresh без real-time**

  <details>
  <summary>Подробности проверки</summary>

  - Изменить депозит при открытом профиле: карточка обновляется после refresh; без него real-time нет.

  </details>

- [ ] **PROF-REFRESH-04 — Лимит после refresh без real-time**

  <details>
  <summary>Подробности проверки</summary>

  - Изменить занятый лимит при открытом профиле: свободный остаток обновляется после refresh; без него real-time нет.

  </details>

- [ ] **PROF-REFRESH-05 — Актуальные финансы при открытии профиля**

  <details>
  <summary>Подробности проверки</summary>

  - После изменения финансов вне профиля открыть его: баланс/депозит/лимит загружаются актуальными для текущей роли.

  </details>

- [ ] **PROF-LOAD-02 — Неуточнённые ошибки и возврат из вложенных окон**

  <details>
  <summary>Подробности проверки</summary>

  - Сеть/ошибка refresh/фон/возврат из вложенного окна, старые данные и обновление вложенных списков — Blocked, PROF-Q05.

  </details>

- [ ] **PROF-UI-01 — Доступность нижних пунктов профиля**

  <details>
  <summary>Подробности проверки</summary>

  - На поддерживаемых размерах экрана меню прокручивается до нижних пунктов, элементы доступны для tap и не скрыты нижней панелью Liquid Glass.

  </details>

- [ ] **PROF-UI-02 — Читаемость данных профиля в обеих темах**

  <details>
  <summary>Подробности проверки</summary>

  </details>

  <details>
  <summary>Подробности проверки</summary>

  </details>
