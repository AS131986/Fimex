# Чек-лист: Статистика из «Моих заказов» — реселлер, Fimex Buyer, iOS

## Область и использование

Статистика собственного списка реселлера: только его покупки всех статусов/оплаты/Истории, те же периоды, иерархия/выбор характеристик, доли/сортировка, пустое состояние и обновление, но **все суммы с клиентской наценкой**. Себестоимость/размер наценки не раскрываются; доли покупок показываются. Общая статистика клиента/корпа имеет отдельный чек-лист, [клиентская статистика](checklist-customer-orders-statistics-client-corporate.md) покрывает продажи/прибыль отдельно.

Проверки не выполнялись. `[ ]` — Not run, не Fail; результаты отдельно: Pass / Fail / Blocked / Not run / N/A. Неопределённая часть Blocked по RESSTAT-Qxx. ID стабильные, снятые не переиспользовать.

## Предусловия

- Два реселлера одного клиента с собственными покупками, покупки клиента/корпа и чужая группа для изоляции. Смешанный общий заказ и отдельные клиентские/собственные представления для отсутствия двойного учёта. У одного реселлера нет собственных данных, у других пользователей они есть.
- Собственные заказы первого/второго/Released, Paid/Not paid, заказы в Истории; отдельно пустой активный список при собственных данных статистики. Использовать обычные полные заказы без частичных возвратов для базовой арифметики.
- Согласованный источник состава доступных периодов и заказов в каждом; 1M доступен, 1M без данных при доступном следующем, единственный доступный период и все без данных. Не вычислять границы месяцев по догадке — RESSTAT-Q01.
- Несколько собственных брендов/категорий/моделей с различными суммами; количества больше 1, гарантия/тип оплаты, положительная и разная зафиксированная наценка позиций, сохранённые цены отличаются от текущего прайса. Известные база/наценка — только в разрешённом тестовом источнике, не в интерфейсе реселлера.
- Полная ветка память→цвет→страна, ветка без памяти с другим параметром (например размеры часов), сокращённая ветка с последним блоком другого типа. Только реальные параметры/иконки источника.
- Доли с дробной частью (в том числе менее 1%), согласованные ожидаемые суммы/доли; для базового процента использовать конечные дроби, не изобретать формат бесконечной дроби.
- Управляемая задержка/ошибки, возможность применимого изменения заказа/новой покупки и повторного получения данных. Нет доступа к источнику расчёта — Blocked, не Pass по приблизительным суммам скриншота.

## Smoke

RESSTAT-OPEN-01/02, RESSTAT-SCOPE-01/02/04, RESSTAT-PERIOD-01/02/03, RESSTAT-SUM-01/03, RESSTAT-BRAND-02, RESSTAT-CAT-02, RESSTAT-ATTR-03/04, RESSTAT-SHARE-01/02, RESSTAT-TOTAL-01/02, RESSTAT-EMPTY-01, RESSTAT-SYNC-01/03. Использовать результаты основных пунктов.

## Вход и загрузка

- [ ] **RESSTAT-OPEN-01** — График из собственных «Моих заказов» реселлера открывает его Статистику с заголовком/крестиком, не общую/клиентскую статистику клиента/корпа.
- [ ] **RESSTAT-OPEN-02** — Переключиться между двумя реселлерскими аккаунтами: после загрузки каждый видит только свои покупки/суммы/периоды, данные предыдущего аккаунта не подставлены как текущие.
- [ ] **RESSTAT-OPEN-03** — Войти из собственного списка с выбранным статусом: статистика включает все покупки этого реселлера периода, а не только отфильтрованные активные строки.
- [ ] **RESSTAT-LOAD-01** — При загрузке скелетон, после успеха актуальные периоды/бренды либо полное пустое состояние; задержка не показывается как успешное «Нет данных».
- [ ] **RESSTAT-LOAD-02** — После завершения загрузки показан первый доступный период с начальными брендами/«Всего»; прежние дочерние блоки не подставляются как выбранная ветка нового входа.

## Собственный владелец и состояния заказов

- [ ] **RESSTAT-SCOPE-01** — В суммы/периоды входят только покупки текущего реселлера; покупки клиента, корпа и других реселлеров того же клиента не добавлены.
- [ ] **RESSTAT-SCOPE-02** — Входят активные/неоплаченные и уже выданные заказы Истории соответствующего периода; фильтра «только Paid» либо «только текущие» нет.
- [ ] **RESSTAT-SCOPE-03** — Другой реселлер того же клиента и чужая группа не попадают в суммы/доли даже при совпадении бренда/модели/даты.
- [ ] **RESSTAT-SCOPE-04** — Собственные покупки, также отображённые внутри общего смешанного/клиентского заказа, учитываются один раз, не повторно из-за нескольких представлений. Чужая часть общего заказа исключена.

## Периоды

- [ ] **RESSTAT-PERIOD-01** — Сегменты 1M/3M/6M/12M в этом порядке; при данных в 1M по умолчанию выбран он, наличие данных в 12M не меняет default.
- [ ] **RESSTAT-PERIOD-02** — 1M без данных: заблокирован и не выбирается, автоматически выбран первый следующий доступный. Проверить согласованные источником варианты доступности, включая один доступный период.
- [ ] **RESSTAT-PERIOD-03** — Tap по заблокированному пустому периоду не меняет выбранный непустой период/данные и не показывает полное пустое состояние вместо него.
- [ ] **RESSTAT-PERIOD-04** — Выбрать другой доступный период: бренды/суммы/доли/порядок соответствуют его данным, предыдущая выбранная ветка сброшена, дочерних блоков нет, «Всего» вновь видна.
- [ ] **RESSTAT-PERIOD-05** — Календарные/скользящие окна, точное поле даты заказа, часовой пояс и границы месяцев: **Blocked, RESSTAT-Q01**. Критерий «дата заказа» подтверждён, не подменять его моментом выдачи без источника.

## Стоимость покупок

- [ ] **RESSTAT-SUM-01** — Начальная общая сумма равна итоговой стоимости всех собственных товаров в периоде с наценкой; учитываются количества, не только по одной единице каждой строки/заказа.
- [ ] **RESSTAT-SUM-02** — Выбранная гарантия и применимый Cash/Online учитываются в сохранённой стоимости; не показывается база без гарантии вместо суммы покупки.
- [ ] **RESSTAT-SUM-03** — Клиентская наценка включена во все суммы брендов/категорий/моделей/характеристик и «Всего», как в собственном заказе. На наборе с положительной наценкой не копируются цены без неё из общей статистики клиента/корпа; гарантия также учтена.
- [ ] **RESSTAT-SUM-04** — Изменить текущий прайс/настройку клиентской наценки без изменения уже купленных позиций: после открытия/обновления статистика использует сохранённые цены заказа, не текущий каталог/новую наценку.
- [ ] **RESSTAT-SUM-05** — Суммы дочерних строк соответствуют сумме их родителя по разрешённым данным и составу ветки; товары иных брендов/категорий не добавлены. Частичные возвраты/изменения заказа и денежное округление отдельно RESSTAT-Q02/04.

- [ ] **RESSTAT-SUM-06** — Ни один уровень/«Всего» не раскрывает себестоимость, отдельную сумму/процент клиентской наценки или переключатель цены; процент статистической доли остаётся доступен и не считается раскрытием процента наценки.

## Бренды

- [ ] **RESSTAT-BRAND-01** — Бренды показывают соответствующие название/лого, сумму, процент и прогресс; строки относятся к покупкам выбранного периода, не полному ассортименту.
- [ ] **RESSTAT-BRAND-02** — Выбрать бренд: его прогресс подсвечен, появился блок категорий только этого бренда, выполнена автопрокрутка к нему.
- [ ] **RESSTAT-BRAND-03** — Бренды отсортированы по сумме от большей к меньшей, не алфавиту/количеству заказов. Равные суммы — RESSTAT-Q02.
- [ ] **RESSTAT-BRAND-04** — Бренд с единственной строкой/долей 100% показывает её как долю общего набора, не искусственное разделение; при наличии дочерних данных выбор открывает следующий блок.

## Категории и модели

- [ ] **RESSTAT-CAT-01** — У категории название/иконка, прогресс, сумма и процент; в блоке только покупки выбранного бренда, сортировка по сумме вниз.
- [ ] **RESSTAT-CAT-02** — Выбрать категорию: подсвечен её прогресс, появились модели выбранных бренда/категории, автопрокрутка к новому блоку.
- [ ] **RESSTAT-CAT-03** — Одноимённая категория другого бренда не добавляется в текущие суммы/модели; смена бренда пересчитывает набор.
- [ ] **RESSTAT-MODEL-01** — У моделей соответствующие иконка/название, сумма, процент и прогресс; порядок по убыванию суммы выбранной категории.
- [ ] **RESSTAT-MODEL-02** — Выбор модели подсвечивает её прогресс и открывает следующий имеющийся параметр именно её ветки с автопрокруткой, без характеристик другой модели.

## Параметры товара и последний блок

- [ ] **RESSTAT-ATTR-01** — Для полной ветки последовательно доступны память, цвет, страна; каждый блок ограничен всеми выбранными выше параметрами и содержит соответствующие сумму/долю/прогресс.
- [ ] **RESSTAT-ATTR-02** — Выбор памяти/цвета подсвечивает прогресс и открывает следующий имеющийся блок с автопрокруткой; суммы не включают другие значения уже выбранного параметра.
- [ ] **RESSTAT-ATTR-03** — Модель без памяти: отсутствующий блок пропущен, используется её реальный следующий параметр, например размеры/циферблат; память телефона не подставлена для часов.
- [ ] **RESSTAT-ATTR-04** — Последний имеющийся блок, в том числе страна либо размеры: tap ничего не выбирает, не подсвечивает выбор и не открывает новый блок/экран товара.
- [ ] **RESSTAT-ATTR-05** — Память, цвет, страна, размеры/другие параметры сортируются по убыванию суммы этой ветки, не по объёму памяти/алфавиту/порядку каталога.

## Доли и прогресс

- [ ] **RESSTAT-SHARE-01** — Доля бренда от общей суммы периода, категории от выбранного бренда, модели от категории, каждого параметра от текущего родителя. Данные позволяют отличить эти знаменатели от общей суммы всего периода.
- [ ] **RESSTAT-SHARE-02** — На конечных дробных долях, например 0,3%, дробь сохраняется вместо округления до целого; для сложных дробей точная точность/формат — RESSTAT-Q02.
- [ ] **RESSTAT-SHARE-03** — Длина прогресса соответствует денежной доле; бренд с максимальной суммой меньше 100% не растягивается до 100% только потому, что он первый. Количество единиц с противоположным соотношением не подменяет долю стоимости.
- [ ] **RESSTAT-SHARE-04** — Смена периода/родителя пересчитывает доли/прогресс от нового набора; прежний процент/знаменатель не остаются в дочернем блоке. Минимальная видимая длина малой доли — RESSTAT-Q02.

- [ ] **RESSTAT-SHARE-05** — На собственных покупках с разными зафиксированными наценками сортировка, проценты и длины прогресса рассчитаны от итоговых сумм с наценкой. Использовать набор, отличающий их от себестоимости: надбавка не применяется только к «Всего», оставляя старые доли/порядок.

## Смена выбранной ветки

- [ ] **RESSTAT-SELECT-01** — Выбрать другую строку бренда после глубокой детализации: старые выборы/блоки ниже бренда сброшены, открыты категории нового бренда. Приглушённые строки остаются доступны для смены.
- [ ] **RESSTAT-SELECT-02** — Сменить категорию: выбранный бренд остаётся, прежние модель/параметры сброшены, модели относятся к новой категории.
- [ ] **RESSTAT-SELECT-03** — Сменить модель или промежуточный параметр: выборы выше остаются в ветке, все нижние выборы/блоки сброшены; новые значения не смешаны со старым путём.
- [ ] **RESSTAT-SELECT-04** — Закрыть статистику после глубокой детализации, вновь открыть: первый доступный период, бренды/«Всего», без сохранённой выбранной ветки.
- [ ] **RESSTAT-SELECT-05** — Повторный tap уже выбранной строки, точная позиция автопрокрутки и выбор/скролл после refresh: **Blocked, RESSTAT-Q03** для неопределённой части. Не выбирать произвольно между снятием/сохранением выбора.

## Строка «Всего»

- [ ] **RESSTAT-TOTAL-01** — До выбора бренда под списком «Всего», равная общей сумме собственных покупок с наценкой за период/сумме строк собственных брендов.
- [ ] **RESSTAT-TOTAL-02** — После выбора бренда и при дальнейших уровнях «Всего» скрыта: не заменена суммой выбранного бренда/модели и не перенесена под последний блок.
- [ ] **RESSTAT-TOTAL-03** — Сменить период либо повторно открыть статистику: выборы сброшены, «Всего» снова под брендами и соответствует текущему периоду, не предыдущей ветке.

## Пустое состояние

- [ ] **RESSTAT-EMPTY-01** — Во всех четырёх периодах нет данных после успешной загрузки: карточка с иконкой диаграммы, «Нет данных», текст «Похоже вы не совершили ни одного заказа, для отображения данных»; на светлом примере синяя круглая иконка.
- [ ] **RESSTAT-EMPTY-02** — В полном пустом состоянии периоды, бренды/дочерние строки и «Всего» скрыты; заголовок/крестик остаются, нет прежних сумм/подсветки. Отдельный заблокированный период при непустом другом не вызывает это состояние.
- [ ] **RESSTAT-EMPTY-03** — Активных собственных заказов нет, но есть собственные учитываемые покупки в Истории: статистика непустая. Пустота активного списка не подменяет пустоту всех собственных покупок периода.

- [ ] **RESSTAT-EMPTY-04** — У текущего реселлера нет данных во всех периодах, у клиента/корпа/другого реселлера покупки есть: показано его полное «Нет данных», чужие покупки не включают периоды и не заполняют бренды.

## Обновление, ошибки и закрытие

- [ ] **RESSTAT-SYNC-01** — Повторное открытие получает актуальные собственные покупки/периоды и сбрасывает ветку; новая учитываемая собственная покупка отражена в бренде/общей сумме с наценкой без дубля.
- [ ] **RESSTAT-SYNC-02** — Пока статистика открыта, изменение на сервере не обязано показываться real-time; последующее открытие/смена периода получает актуальные данные.
- [ ] **RESSTAT-SYNC-03** — Pull-to-refresh доступен и получает актуальные суммы/состав выбранного периода. Судьба выбранной ветки/скролла после обновления — RESSTAT-Q03, не требовать сброса по аналогии со сменой периода.
- [ ] **RESSTAT-ERROR-01** — Ошибка сети/сервера при загрузке/смене периода/refresh показывает стандартный alert, не успешное «Нет данных»; точные тексты/кнопки и старые данные/retry — RESSTAT-Q05.
- [ ] **RESSTAT-ERROR-02** — Отменённые/частично возвращённые покупки, изменение заказа после покупки, неоднородные/незаполненные параметры/иконки: **Blocked, RESSTAT-Q04** для состава/сумм/отображения. Не переносить обычный полный заказ на эти состояния.
- [ ] **RESSTAT-ERROR-03** — Очень малые доли/бесконечные дроби, денежные дроби, равные/нулевые суммы: **Blocked, RESSTAT-Q02** для точного формата/порядка/прогресса.
- [ ] **RESSTAT-CLOSE-01** — Крестик возвращает в исходные собственные «Мои заказы» реселлера. Свайп закрытия, поведение фильтра/обновления после возврата и закрепление хедера при прокрутке — RESSTAT-Q05.
