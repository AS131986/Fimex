# Чек-лист: История из «Моих заказов» — реселлер

## Область и статус

История, её периоды/показатели/карточки и просмотр архивного заказа. [Активная деталка](checklist-order-detail-reseller.md) проверяется отдельно; её возможности редактирования не действуют в архиве.

Все пункты `[ ]` — **Not run**. Неуточнённые ожидания отмечены **Blocked**; приложение/админка не проверялись. [Правила и вопросы](../../04-business-rules/my-orders-history-reseller.md), [экран](../../03-screens/orders/my-orders-history-reseller.md).

## Данные и подготовка

- Разрешённые аккаунты каждой роли, связанная группа с несколькими реселлерами и отдельная чужая группа.
- Архивные заказы в разных доступных периодах, только активные/незавершённые, полная пустота; неравные даты заказа/выдачи и равные даты карточек.
- Несколько позиций, количества >1, одинаковое название с разной ценой/гарантией, товары с флагом/без флага, разные типы оплаты, положительная сохранённая наценка.
- Для арифметики сохранённые цены единицы/гарантии/количества, подтверждённый источник цены; неизвестное округление не выводить из экранных примеров. Нужный доступ к админке/файлам при отсутствии — Blocked.

## Вход и область

- [ ] **RESHIST-ENTRY-01** — Книга исходного списка открывает всплывающую «Историю» с заголовком и крестиком, не статистику или активный список.
- [ ] **RESHIST-ENTRY-02** — Показаны только завершённые собственные заказы текущего реселлера; другой интерфейс/чужая группа не добавляют карточки.
- [ ] **RESHIST-ENTRY-03** — В исходном списке выбрать статус/доступный ID, открыть Историю: фильтры предыдущего экрана не ограничивают её архивный набор.
- [ ] **RESHIST-ENTRY-04** — Отсутствие активных заказов при наличии архивных данных не делает Историю пустой.

## Завершение заказа

- [ ] **RESHIST-ARCH-01** — Собственный заказ становится доступен в Истории после ручного Paid и подтверждённой выдачи клиентом/корпом, в любом порядке. «Выдать» доступно клиенту/корпу только после админского Released. Один Released или только одно из двух действий не завершают заказ. Реселлер сам оплату/выдачу не меняет.
- [ ] **RESHIST-ARCH-02** — В архив попадает только весь заказ со всеми его позициями/количествами; частично архивировать позицию или часть количества нельзя.
- [ ] **RESHIST-ARCH-03** — После завершения архив содержит соответствующий номер и товары; остальные незавершённые заказы не архивируются вместе с ним.

## Периоды и возврат

- [ ] **RESHIST-PERIOD-01** — Показаны 1M/3M/6M/12M; первое открытие выбирает первый доступный период, не обязательно 1M.
- [ ] **RESHIST-PERIOD-02** — Период без архивных данных заблокирован и не выбирается; наличие только активных данных не делает его доступным для Истории.
- [ ] **RESHIST-PERIOD-03** — При выборе доступного периода показатели и карточки относятся только к нему, данные прежнего периода не смешаны.
- [ ] **RESHIST-PERIOD-04** — Дата включения — дата заказа; взять заказ с отличающейся датой выдачи. Точные границы/поле: **Blocked, RESHIST-Q02**.
- [ ] **RESHIST-PERIOD-05** — Выбрать не первый доступный период, открыть заказ и закрыть его: выбранный период Истории сохранён.
- [ ] **RESHIST-PERIOD-06** — Закрыть Историю и открыть заново: первый доступный период, прежний выбор не восстановлен.
- [ ] **RESHIST-PERIOD-07** — Покупки на точной границе месяца/в другом часовом поясе/старше 12M: **Blocked, RESHIST-Q02**.

## Показатели и ячейки

- [ ] **RESHIST-SUM-01** — Кол-во соответствует сумме единиц во всех заказах периода; набор с несколькими позициями/количеством >1 отличает его от числа карточек.
- [ ] **RESHIST-SUM-02** — Сумма периода и суммы карточек с зафиксированной клиентской наценкой; итог совпадает с суммой включённых заказов, гарантия и применимый тип оплаты учтены.
- [ ] **RESHIST-SUM-03** — Сохранённые цены конкретных покупок используются при повторном просмотре после изменения прайса; нет переоценки архива.
- [ ] **RESHIST-SUM-04** — Общий Qty/Amount не включает активные/незавершённые, чужие области или заказы другого периода.
- [ ] **RESHIST-ROW-01** — Ячейка содержит иконку статуса, номер, дату, тип оплаты, сумму и статус оплаты; значения относятся к этому заказу.
- [ ] **RESHIST-ROW-02** — Порядок от новых к старым и дата ячейки: поле даты/равные даты **Blocked, RESHIST-Q01**; не подставлять автоматически дату выдачи.
- [ ] **RESHIST-ROW-03** — Tap по разным карточкам открывает правильный номер/состав/количество/суммы, не последнюю просмотренную карточку.

## Просмотр архива

- [ ] **RESHIST-VIEW-01** — Номер, текущий статус/цвет/иконка, статус оплаты, Qty/Amount, таймлайн и товары соответствуют правилам order-detail-reseller, с архивными ограничениями.
- [ ] **RESHIST-VIEW-02** — Строка товара показывает флаг либо предусмотренную иконку, название, цену единицы, количество и сохранённую выбранную гарантию.
- [ ] **RESHIST-VIEW-03** — Одноимённые товары с разной сохранённой ценой/гарантией отображают свои значения и количества; просмотр не сливает их.
- [ ] **RESHIST-VIEW-04** — Просмотр/раскрытие таймлайна не меняет статус или даты его наступления; дата открытия архива не заменяет дату выдачи.
- [ ] **RESHIST-LOCK-01** — Tap по товару с выбором гарантии не открывает редактор и не меняет гарантию/цену/количество, в том числе для позиции >1 шт.
- [ ] **RESHIST-LOCK-02** — Статус оплаты не открывает окно изменения и не меняется вручную из архива; доступного действия «Выдать» нет.
- [ ] **RESHIST-LOCK-03** — Из архива нельзя менять логиста, Cash/Online, гарантию или любые данные заказа; скачивание/просмотр не меняют баланс/лимит/выдачу.

## Документы

- [ ] **RESHIST-DOC-01** — Три точки открывают предусмотренное архивное меню с накладной, упаковочным листом и серийными номерами.
- [ ] **RESHIST-DOC-02** — Для каждого из трёх документов доступны Excel и PDF; все шесть вариантов открывают актуальный файл соответствующего заказа.
- [ ] **RESHIST-DOC-03** — При повторном скачивании/смене разрешённого режима данные файла соответствуют текущему архивному просмотру; чужой номер/устаревшая цена не подставлены.
- [ ] **RESHIST-DOC-04** — Документы не открывают редакторы и не меняют данные/оплату/выдачу заказа. Колонки, пустые серийные номера, Share/ошибки — вопросы активной деталки.

## Пустое состояние

- [ ] **RESHIST-EMPTY-01** — Без архивных данных во всех периодах: «Нет данных», текст «Похоже вы не совершили ни одного заказа, для отображения данных» и серая круглая иконка выданного заказа.
- [ ] **RESHIST-EMPTY-02** — В пустоте скрыты периоды, Qty/Amount и карточки; заголовок «История»/крестик остаются, старые суммы не видны.
- [ ] **RESHIST-EMPTY-03** — Только активные заказы/заказы, не выполнившие условия завершения, не устраняют пустое состояние Истории.
- [ ] **RESHIST-EMPTY-04** — Пустой период при наличии данных в другом не подменяет полную пустоту: выбран первый доступный, недоступные заблокированы.

## Загрузка и навигация

- [ ] **RESHIST-LOAD-01** — Во время загрузки показан скелетон, а не подтверждённое «Нет данных».
- [ ] **RESHIST-LOAD-02** — Pull-to-refresh на всплывающем экране Истории отсутствует; не ожидается механизм обновления статистики/активного списка.
- [ ] **RESHIST-LOAD-03** — Ошибка получения архива, retry/старые данные, real-time и загрузка при возврате: **Blocked, RESHIST-Q03**.
- [ ] **RESHIST-BACK-01** — Крестик архивного заказа возвращает Историю с прежним периодом; закрытие не изменяет заказ.
- [ ] **RESHIST-BACK-02** — Крестик Истории закрывает всплывающий экран; точные фильтры/секция исходного списка, свайп, прокрутка и исчезновение данных: **Blocked, RESHIST-Q04**.

## Особенности интерфейса

- [ ] **RESHIST-VIEW-05** — В деталке только собственные позиции/номер/гарантии; нет чужих владельцев, вкладок «Все» и других пользователей.
- [ ] **RESHIST-VIEW-06** — В обычном/горизонтальном виде и документах нет себестоимости, переключателя цены или процента клиентской наценки; итоговая цена с наценкой.
- [ ] **RESHIST-MENU-01** — Меню содержит только три документа; выбранный логист, его смена и Cash/Online не доступны.
- [ ] **RESHIST-DOC-05** — Документы сформированы по всем товарам собственного заказа с наценкой; данные чужого реселлера не попадают в файл.
- [ ] **RESHIST-FULL-01** — Горизонтальный полноэкранный просмотр содержит номер, товары, количество, итоговую цену единицы и текущую гарантию, без себестоимости/процента наценки.
- [ ] **RESHIST-FULL-02** — Точный возврат/ориентация/прокрутка собственной архивной деталки после full-screen: **Blocked, RESDET-Q04**; состав и запрет редактирования подтверждены.
