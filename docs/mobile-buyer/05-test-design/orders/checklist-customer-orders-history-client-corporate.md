# Чек-лист: История клиентских заказов — клиент и корп

## Область и статус

История, её периоды/показатели/карточки и просмотр архивного заказа. [Активная деталка](checklist-customer-order-detail-client-corporate.md) проверяется отдельно; её возможности редактирования не действуют в архиве.

Все пункты `[ ]` — **Not run**. Неуточнённые ожидания отмечены **Blocked**; приложение/админка не проверялись. [Правила и вопросы](../../04-business-rules/customer-orders-history-client-corporate.md), [экран](../../03-screens/orders/customer-orders-history-client-corporate.md).

## Данные и подготовка

- Разрешённые аккаунты каждой роли, связанная группа с несколькими реселлерами и отдельная чужая группа.
- Архивные заказы в разных доступных периодах, только активные/незавершённые, полная пустота; неравные даты заказа/выдачи и равные даты карточек.
- Несколько позиций, количества >1, одинаковое название с разной ценой/гарантией, товары с флагом/без флага, разные типы оплаты, положительная сохранённая наценка.
- Для арифметики сохранённые цены единицы/гарантии/количества, подтверждённый источник цены; неизвестное округление не выводить из экранных примеров. Нужный доступ к админке/файлам при отсутствии — Blocked.

## Вход и область

- [ ] **CUSTHIST-ENTRY-01** — Книга исходного списка открывает всплывающую «Историю» с заголовком и крестиком, не статистику или активный список.
- [ ] **CUSTHIST-ENTRY-02** — Показаны завершённые отдельные заказы всех связанных реселлеров; другой интерфейс/чужая группа не добавляют карточки.
- [ ] **CUSTHIST-ENTRY-03** — В исходном списке выбрать статус/доступный ID, открыть Историю: фильтры предыдущего экрана не ограничивают её архивный набор.
- [ ] **CUSTHIST-ENTRY-04** — Отсутствие активных заказов при наличии архивных данных не делает Историю пустой.

## Завершение заказа

- [ ] **CUSTHIST-ARCH-01** — Заказ становится доступен в клиентской Истории после ручного Paid и подтверждённой клиентом/корпом выдачи, в любом порядке. «Выдать» доступно только после админского Released. Один Released, Paid без подтверждённой выдачи или подтверждённая выдача при Not paid оставляют заказ активным.
- [ ] **CUSTHIST-ARCH-02** — В архив попадает только весь заказ со всеми его позициями/количествами; частично архивировать позицию или часть количества нельзя.
- [ ] **CUSTHIST-ARCH-03** — После завершения архив содержит соответствующий номер и товары; остальные незавершённые заказы не архивируются вместе с ним.

## Периоды и возврат

- [ ] **CUSTHIST-PERIOD-01** — Показаны 1M/3M/6M/12M; первое открытие выбирает первый доступный период, не обязательно 1M.
- [ ] **CUSTHIST-PERIOD-02** — Период без архивных данных заблокирован и не выбирается; наличие только активных данных не делает его доступным для Истории.
- [ ] **CUSTHIST-PERIOD-03** — При выборе доступного периода показатели и карточки относятся только к нему, данные прежнего периода не смешаны.
- [ ] **CUSTHIST-PERIOD-04** — Дата включения — дата заказа; взять заказ с отличающейся датой выдачи. Точные границы/поле: **Blocked, CUSTHIST-Q02**.
- [ ] **CUSTHIST-PERIOD-05** — Выбрать не первый доступный период, открыть заказ и закрыть его: выбранный период Истории сохранён.
- [ ] **CUSTHIST-PERIOD-06** — Закрыть Историю и открыть заново: первый доступный период, прежний выбор не восстановлен.
- [ ] **CUSTHIST-PERIOD-07** — Покупки на точной границе месяца/в другом часовом поясе/старше 12M: **Blocked, CUSTHIST-Q02**.

## Показатели и ячейки

- [ ] **CUSTHIST-SUM-01** — Кол-во соответствует сумме единиц во всех заказах периода; набор с несколькими позициями/количеством >1 отличает его от числа карточек.
- [ ] **CUSTHIST-SUM-02** — Сумма периода и суммы карточек с зафиксированной клиентской наценкой; итог совпадает с суммой включённых заказов, гарантия и применимый тип оплаты учтены.
- [ ] **CUSTHIST-SUM-03** — Сохранённые цены конкретных покупок используются при повторном просмотре после изменения прайса; нет переоценки архива.
- [ ] **CUSTHIST-SUM-04** — Общий Qty/Amount не включает активные/незавершённые, чужие области или заказы другого периода.
- [ ] **CUSTHIST-ROW-01** — Ячейка содержит иконку статуса, номер, дату, тип оплаты, сумму и статус оплаты; значения относятся к этому заказу.
- [ ] **CUSTHIST-ROW-02** — Порядок от новых к старым и дата ячейки: поле даты/равные даты **Blocked, CUSTHIST-Q01**; не подставлять автоматически дату выдачи.
- [ ] **CUSTHIST-ROW-03** — Tap по разным карточкам открывает правильный номер/состав/количество/суммы, не последнюю просмотренную карточку.

## Просмотр архива

- [ ] **CUSTHIST-VIEW-01** — Номер, текущий статус/цвет/иконка, статус оплаты, Qty/Amount, таймлайн и товары соответствуют правилам customer-order-detail-client-corporate, с архивными ограничениями.
- [ ] **CUSTHIST-VIEW-02** — Строка товара показывает флаг либо предусмотренную иконку, название, цену единицы, количество и сохранённую выбранную гарантию.
- [ ] **CUSTHIST-VIEW-03** — Одноимённые товары с разной сохранённой ценой/гарантией отображают свои значения и количества; просмотр не сливает их.
- [ ] **CUSTHIST-VIEW-04** — Просмотр/раскрытие таймлайна не меняет статус или даты его наступления; дата открытия архива не заменяет дату выдачи.
- [ ] **CUSTHIST-LOCK-01** — Tap по товару с выбором гарантии не открывает редактор и не меняет гарантию/цену/количество, в том числе для позиции >1 шт.
- [ ] **CUSTHIST-LOCK-02** — Статус оплаты не открывает окно изменения и не меняется вручную из архива; доступного действия «Выдать» нет.
- [ ] **CUSTHIST-LOCK-03** — Из архива нельзя менять логиста, Cash/Online, гарантию или любые данные заказа; скачивание/просмотр не меняют баланс/лимит/выдачу.

## Документы

- [ ] **CUSTHIST-DOC-01** — Три точки открывают предусмотренное архивное меню с накладной, упаковочным листом и серийными номерами.
- [ ] **CUSTHIST-DOC-02** — Для каждого из трёх документов доступны Excel и PDF; все шесть вариантов открывают актуальный файл соответствующего заказа.
- [ ] **CUSTHIST-DOC-03** — При повторном скачивании/смене разрешённого режима данные файла соответствуют текущему архивному просмотру; чужой номер/устаревшая цена не подставлены.
- [ ] **CUSTHIST-DOC-04** — Документы не открывают редакторы и не меняют данные/оплату/выдачу заказа. Колонки, пустые серийные номера, Share/ошибки — вопросы активной деталки.

## Пустое состояние

- [ ] **CUSTHIST-EMPTY-01** — Без архивных данных во всех периодах: «Нет данных», текст «Похоже, ваши клиенты еще не совершили ни одного заказа» и серая круглая иконка выданного заказа.
- [ ] **CUSTHIST-EMPTY-02** — В пустоте скрыты периоды, Qty/Amount и карточки; заголовок «История»/крестик остаются, старые суммы не видны.
- [ ] **CUSTHIST-EMPTY-03** — Только активные заказы/заказы, не выполнившие условия завершения, не устраняют пустое состояние Истории.
- [ ] **CUSTHIST-EMPTY-04** — Пустой период при наличии данных в другом не подменяет полную пустоту: выбран первый доступный, недоступные заблокированы.

## Загрузка и навигация

- [ ] **CUSTHIST-LOAD-01** — Во время загрузки показан скелетон, а не подтверждённое «Нет данных».
- [ ] **CUSTHIST-LOAD-02** — Pull-to-refresh на всплывающем экране Истории отсутствует; не ожидается механизм обновления статистики/активного списка.
- [ ] **CUSTHIST-LOAD-03** — Ошибка получения архива, retry/старые данные, real-time и загрузка при возврате: **Blocked, CUSTHIST-Q03**.
- [ ] **CUSTHIST-BACK-01** — Крестик архивного заказа возвращает Историю с прежним периодом; закрытие не изменяет заказ.
- [ ] **CUSTHIST-BACK-02** — Крестик Истории закрывает всплывающий экран; точные фильтры/секция исходного списка, свайп, прокрутка и исчезновение данных: **Blocked, CUSTHIST-Q04**.

## Особенности интерфейса

- [ ] **CUSTHIST-VIEW-05** — ID единственного реселлера показан под статусом; вкладок других владельцев/«Все» нет.
- [ ] **CUSTHIST-MODE-01** — Новое открытие архивной деталки выбирает «С наценкой»; предыдущий выбор «Себестоимость» не сохраняется для повторного открытия.
- [ ] **CUSTHIST-MODE-02** — Выбрать «Себестоимость»: цены единицы и Amount без клиентской наценки, процент рядом с гарантией скрыт; количество и гарантия прежние.
- [ ] **CUSTHIST-MODE-03** — Вернуться к «С наценкой»: сохранённые итоговые цены/Amount и процент рядом с гарантией восстановлены, без финансовой операции.
- [ ] **CUSTHIST-MODE-04** — Изменение текущей настройки наценки после покупки не переоценивает архивные позиции и не заменяет сохранённый процент.
- [ ] **CUSTHIST-MENU-01** — В меню только накладная, упаковочный лист, серийные номера; логист и смена Cash/Online отсутствуют.
- [ ] **CUSTHIST-DOC-05** — Документы включают товары только этого реселлера/заказа, цены соответствуют выбранному в деталке режиму; переключение не сохраняет устаревшие суммы файла.
- [ ] **CUSTHIST-FULL-01** — В горизонтальном виде номер, переключатель, товары, количество, цена, гарантия; процент показан только с наценкой, меняется основа цены при переключении.
- [ ] **CUSTHIST-FULL-02** — Закрыть горизонтальный вид: обычная архивная деталка сохраняет текущий режим отображения цены; её закрытие возвращает Историю с прежним периодом.
