# Чек-лист: История из «Моих заказов» — клиент и корп

## Область и статус

История, её периоды/показатели/карточки и просмотр архивного заказа. [Активная деталка](checklist-order-detail-client-corporate.md) проверяется отдельно; её возможности редактирования не действуют в архиве.

Все пункты `[ ]` — **Not run**. Неуточнённые ожидания отмечены **Blocked**; приложение/админка не проверялись. [Правила и вопросы](../../04-business-rules/my-orders-history-client-corporate.md), [экран](../../03-screens/orders/my-orders-history-client-corporate.md).

## Данные и подготовка

- Разрешённые аккаунты каждой роли, связанная группа с несколькими реселлерами и отдельная чужая группа.
- Архивные заказы в разных доступных периодах, только активные/незавершённые, полная пустота; неравные даты заказа/выдачи и равные даты карточек.
- Несколько позиций, количества >1, одинаковое название с разной ценой/гарантией, товары с флагом/без флага, разные типы оплаты, положительная сохранённая наценка.
- Для арифметики сохранённые цены единицы/гарантии/количества, подтверждённый источник цены; неизвестное округление не выводить из экранных примеров. Нужный доступ к админке/файлам при отсутствии — Blocked.

## Вход и область

- [ ] **ORDHIST-ENTRY-01** — Книга исходного списка открывает всплывающую «Историю» с заголовком и крестиком, не статистику или активный список.
- [ ] **ORDHIST-ENTRY-02** — Показаны выданные общие заказы связанной группы клиента, корпа и реселлеров; другой интерфейс/чужая группа не добавляют карточки.
- [ ] **ORDHIST-ENTRY-03** — В исходном списке выбрать статус/доступный ID, открыть Историю: фильтры предыдущего экрана не ограничивают её архивный набор.
- [ ] **ORDHIST-ENTRY-04** — Отсутствие активных заказов при наличии архивных данных не делает Историю пустой.

## Завершение заказа

- [ ] **ORDHIST-ARCH-01** — После админского Released / «Выдан» весь общий заказ становится доступен в Истории. Правило общего списка сохраняется: админская выдача Not paid запрещена; общая оплата автоматическая, не клиентская ручная отметка.
- [ ] **ORDHIST-ARCH-02** — В архив попадает только весь заказ со всеми его позициями/количествами; частично архивировать позицию или часть количества нельзя.
- [ ] **ORDHIST-ARCH-03** — После завершения архив содержит соответствующий номер и товары; остальные незавершённые заказы не архивируются вместе с ним.

## Периоды и возврат

- [ ] **ORDHIST-PERIOD-01** — Показаны 1M/3M/6M/12M; первое открытие выбирает первый доступный период, не обязательно 1M.
- [ ] **ORDHIST-PERIOD-02** — Период без архивных данных заблокирован и не выбирается; наличие только активных данных не делает его доступным для Истории.
- [ ] **ORDHIST-PERIOD-03** — При выборе доступного периода показатели и карточки относятся только к нему, данные прежнего периода не смешаны.
- [ ] **ORDHIST-PERIOD-04** — Дата включения — дата заказа; взять заказ с отличающейся датой выдачи. Точные границы/поле: **Blocked, ORDHIST-Q02**.
- [ ] **ORDHIST-PERIOD-05** — Выбрать не первый доступный период, открыть заказ и закрыть его: выбранный период Истории сохранён.
- [ ] **ORDHIST-PERIOD-06** — Закрыть Историю и открыть заново: первый доступный период, прежний выбор не восстановлен.
- [ ] **ORDHIST-PERIOD-07** — Покупки на точной границе месяца/в другом часовом поясе/старше 12M: **Blocked, ORDHIST-Q02**.

## Показатели и ячейки

- [ ] **ORDHIST-SUM-01** — Кол-во соответствует сумме единиц во всех заказах периода; набор с несколькими позициями/количеством >1 отличает его от числа карточек.
- [ ] **ORDHIST-SUM-02** — Сумма периода и суммы карточек без клиентской наценки реселлера; итог совпадает с суммой включённых заказов, гарантия и применимый тип оплаты учтены.
- [ ] **ORDHIST-SUM-03** — Сохранённые цены конкретных покупок используются при повторном просмотре после изменения прайса; нет переоценки архива.
- [ ] **ORDHIST-SUM-04** — Общий Qty/Amount не включает активные/незавершённые, чужие области или заказы другого периода.
- [ ] **ORDHIST-ROW-01** — Ячейка содержит иконку статуса, номер, дату, тип оплаты, сумму и статус оплаты; значения относятся к этому заказу.
- [ ] **ORDHIST-ROW-02** — Порядок от новых к старым и дата ячейки: поле даты/равные даты **Blocked, ORDHIST-Q01**; не подставлять автоматически дату выдачи.
- [ ] **ORDHIST-ROW-03** — Tap по разным карточкам открывает правильный номер/состав/количество/суммы, не последнюю просмотренную карточку.

## Просмотр архива

- [ ] **ORDHIST-VIEW-01** — Номер, текущий статус/цвет/иконка, статус оплаты, Qty/Amount, таймлайн и товары соответствуют правилам order-detail-client-corporate, с архивными ограничениями.
- [ ] **ORDHIST-VIEW-02** — Строка товара показывает флаг либо предусмотренную иконку, название, цену единицы, количество и сохранённую выбранную гарантию.
- [ ] **ORDHIST-VIEW-03** — Одноимённые товары с разной сохранённой ценой/гарантией отображают свои значения и количества; просмотр не сливает их.
- [ ] **ORDHIST-VIEW-04** — Просмотр/раскрытие таймлайна не меняет статус или даты его наступления; дата открытия архива не заменяет дату выдачи.
- [ ] **ORDHIST-LOCK-01** — Tap по товару с выбором гарантии не открывает редактор и не меняет гарантию/цену/количество, в том числе для позиции >1 шт.
- [ ] **ORDHIST-LOCK-02** — Статус оплаты не открывает окно изменения и не меняется вручную из архива; доступного действия «Выдать» нет.
- [ ] **ORDHIST-LOCK-03** — Из архива нельзя менять логиста, Cash/Online, гарантию или любые данные заказа; скачивание/просмотр не меняют баланс/лимит/выдачу.

## Документы

- [ ] **ORDHIST-DOC-01** — Три точки открывают предусмотренное архивное меню с накладной, упаковочным листом и серийными номерами.
- [ ] **ORDHIST-DOC-02** — Для каждого из трёх документов доступны Excel и PDF; все шесть вариантов открывают актуальный файл соответствующего заказа.
- [ ] **ORDHIST-DOC-03** — При повторном скачивании/смене разрешённого режима данные файла соответствуют текущему архивному просмотру; чужой номер/устаревшая цена не подставлены.
- [ ] **ORDHIST-DOC-04** — Документы не открывают редакторы и не меняют данные/оплату/выдачу заказа. Колонки, пустые серийные номера, Share/ошибки — вопросы активной деталки.

## Пустое состояние

- [ ] **ORDHIST-EMPTY-01** — Без архивных данных во всех периодах: «Нет данных», текст «Похоже вы не совершили ни одного заказа, для отображения данных» и серая круглая иконка выданного заказа.
- [ ] **ORDHIST-EMPTY-02** — В пустоте скрыты периоды, Qty/Amount и карточки; заголовок «История»/крестик остаются, старые суммы не видны.
- [ ] **ORDHIST-EMPTY-03** — Только активные заказы/заказы, не выполнившие условия завершения, не устраняют пустое состояние Истории.
- [ ] **ORDHIST-EMPTY-04** — Пустой период при наличии данных в другом не подменяет полную пустоту: выбран первый доступный, недоступные заблокированы.

## Загрузка и навигация

- [ ] **ORDHIST-LOAD-01** — Во время загрузки показан скелетон, а не подтверждённое «Нет данных».
- [ ] **ORDHIST-LOAD-02** — Pull-to-refresh на всплывающем экране Истории отсутствует; не ожидается механизм обновления статистики/активного списка.
- [ ] **ORDHIST-LOAD-03** — Ошибка получения архива, retry/старые данные, real-time и загрузка при возврате: **Blocked, ORDHIST-Q03**.
- [ ] **ORDHIST-BACK-01** — Крестик архивного заказа возвращает Историю с прежним периодом; закрытие не изменяет заказ.
- [ ] **ORDHIST-BACK-02** — Крестик Истории закрывает всплывающий экран; точные фильтры/секция исходного списка, свайп, прокрутка и исчезновение данных: **Blocked, ORDHIST-Q04**.

## Особенности интерфейса

- [ ] **ORDHIST-VIEW-05** — Вкладки владельцев/«Все» соответствуют составу общего заказа и правилам активной общей деталки; товары другого владельца не подменяют выбранный набор. Дефолтный выбор — ORDDET-Q04.
- [ ] **ORDHIST-VIEW-06** — При наличии вкладок владельцев показана «Все», в том числе при единственном корпе/реселлере; только основной клиент без вкладок — по правилам общей деталки.
- [ ] **ORDHIST-VIEW-07** — Смена вкладки меняет только отображаемый набор/показатели, не заказ или цены; цены реселлерских позиций без клиентской наценки.
- [ ] **ORDHIST-MENU-01** — Выбранный получатель/логист виден в меню как недоступная строка; tap не открывает смену логиста и не меняет получателя.
- [ ] **ORDHIST-DOC-05** — На вкладке владельца документы содержат его товары, на «Все» все товары заказа; цены без клиентской наценки даже для реселлеров.
- [ ] **ORDHIST-VIEW-08** — В обычном и горизонтальном виде нет переключателя себестоимость/наценка и клиентских процентов; гарантия остаётся видимой.
- [ ] **ORDHIST-FULL-01** — Полноэкранный горизонтальный вид показывает номер, вкладки владельцев, товары, количество, цену без клиентской наценки и гарантию; закрытие возвращает обычный вид с прежней вкладкой.
