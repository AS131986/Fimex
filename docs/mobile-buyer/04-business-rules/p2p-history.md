# Правила: История P2P — все роли

## Доступ и успешная сделка

- Клиент/связанный корп видят общую историю, реселлер только собственную; чужие реселлеры и группа исключены. Клиент/корп не получают историю П2П реселлера из права просмотра его обычных заказов.
- Только успешно завершённые покупки по заявкам, независимо от того, принял поставщик собственное предложение пользователя или пользователь встречную цену. Удаление, КТ/изменение товара без покупки не добавляют Историю.
- Не ждать выдачи/Paid обычного заказа: событие успешной покупки по П2П отличается от архивирования обычных заказов. Отдельные документы описывают оба процесса.

## Даты и период

- Доступные периоды 1M/3M/6M/12M, по умолчанию ближайший с успешной историей. Пример: нет данных 1M/3M, есть 6M/12M — выбирается 6M.
- **Отбор в период по дате создания заявки.** Дата покупки не заменяет её для отбора, даже если сделка закрылась позже.
- **Дата в строке/информации — дата покупки; сортировка по дате покупки, новые первыми.** Равные даты/вторичный ключ — P2PHIST-Q02.
- Фильтр «Все чаты / Поставщик» исходного списка не влияет на Историю. Закрытие информации о сделке сохраняет период; новое открытие самой Истории выбирает ближайший доступный, а не прежний выбранный. Прокрутка/способы закрытия самой Истории — P2PHIST-Q03. Возврат из fullscreen также сохраняет период.
- Границы периодов/поле создания/покупки/часовой пояс — P2PHIST-Q01. Книга активного списка «за год» сохраняет P2PLIST-Q02, не считать 12M доказательством календарного или скользящего года.

## Цены, количество и сумма

- Цена строки/«Моя цена» информации — **успешная цена покупки без дополнительной гарантии**, не исходная цена несогласованной заявки и не текущий прайс.
- Клиент/корп без клиентской наценки, реселлер с наценкой клиента, при этом гарантия исключена также у реселлера.
- Количество строки — купленные единицы, общее количество — сумма единиц всех включённых сделок, не число заявок/строк.
- Сумма периода = сумма цен покупки без гарантии × количество для каждого включённого товара. Нельзя использовать итог обычного заказа с гарантией для этого блока.
- Экранный пример: 50 × 869 + 51 × 1400 + 50 × 581 = 143900, количество 151. Подтверждает арифметику образца, не задаёт округление дробных цен — P2PHIST-Q05.
- Цена относится к фактической покупке; фиксация процента наценки во время активной заявки до покупки остаётся P2PACT-Q03. Новое описание не подтверждает произвольный момент фиксации или изменение исторической цены при смене настроек.

## Информация и инициатор

- Строка/окно содержат флаг либо иконку/название, цену без гарантии и количество. Окно дополняется данными покупки: на образце код номера, страна, модель, дата/время, «Сделка закрыта».
- «Сделка закрыта» — тот, кто завершил сделку, поставщик либо принявший пользователь; это не текущий зритель и не автоматически основной клиент. Подпись поставщика «Поставщик», точная локализованная подпись пользователя — P2PHIST-Q05.
- Состав таблицы по категориям/поведение отсутствующих полей — P2PHIST-Q05. Ответ «Только просмотр» не подтверждает скрытие таких полей.
- Только просмотр: нельзя менять количество/цену/гарантию, подтвердить сделку заново или удалить её как активную. Просмотр/поворот/возврат не создают заявку/покупку и не занимают средства повторно.

## Полноэкранный режим и обновление

- Горизонтальный список сохраняет набор периода и строки/цены; сверху периоды/крестик. На примере блок общих показателей и заголовок не отображены.
- Tap открывает информацию о выбранной сделке в горизонтальном режиме; её крестик возвращает горизонтальный список.
- Крестик fullscreen возвращает обычную Историю с прежним выбранным периодом.
- Скелетон при загрузке, ручного refresh нет. Real-time открытой Истории/ошибки/пустота не подтверждены, отдельно P2PHIST-Q04.

## Открытые вопросы

- **P2PHIST-Q01:** скользящие или календарные 1/3/6/12 месяцев, точные поля создания заявки/покупки, часовой пояс, включение границ/данных старше 12M. Отбор по созданию заявки, показ/сортировка по покупке подтверждены; дата создания не заменяется датой покупки.
- **P2PHIST-Q02:** частично закрыт — сортировка по дате покупки, новые первыми подтверждена отдельным ответом. Остались порядок при равных датах/вторичный ключ. ID сохранён.
- **P2PHIST-Q03:** частично закрыт — отдельными ответами подтверждены отсутствие влияния «Все чаты / Поставщик», сохранение периода при закрытии информации о сделке и ближайший доступный при новом открытии Истории. Возврат из fullscreen также сохраняет период. Остались прокрутка/способы закрытия самой Истории; ID сохранён.
- **P2PHIST-Q04:** real-time Истории/появление новой сделки в открытом окне, ошибки/старые данные/восстановление из фона; пустое состояние при потере всех данных, его текст/скрытие блоков. Скелетон и отсутствие ручного refresh подтверждены; не переносить обновления активных заявок.
- **P2PHIST-Q05:** точная подпись пользовательского инициатора/локализация, таблица по категориям/пустые поля, точность дробных цен/сумм и историческая фиксация после покупки. Цена без гарантии, роли/наценка, арифметика образца и только просмотр подтверждены; момент процента до покупки отдельно P2PACT-Q03.
