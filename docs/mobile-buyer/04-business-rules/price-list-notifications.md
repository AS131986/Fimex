# Price List Notifications

## Согласованность

Этот документ содержит прежние формулировки. Более поздние [согласованные правила Price List и известные расхождения](price-list.md) вынесены отдельно: Undo отсутствует, редактирование ценовой подписки через long press, переключение in-stock → price требует Q22. Перенос не меняет требования; прежние формулировки ниже требуют синхронизации с согласованными правилами.

## Purpose
- Зафиксировать новую механику уведомлений, которая ставится прямо из Price List.
- Отделить новую механику от старого раздела уведомлений из профиля.

## Scope
- Только уведомления, создаваемые с экрана Price List.
- iOS app.
- В документ входят создание, редактирование, удаление и ожидаемый результат в виде пользовательского уведомления.

## Main concept
Пользователь может поставить уведомление не в отдельном разделе профиля, а прямо из прайс-листа — на конкретную товарную позицию и конкретную страну.

## Notification types
### 1. In-stock notification
- Сценарий: сообщить, когда товар появится в продаже.
- Хранится как уведомление без цены.
- Актуально для отсутствующих, но ранее продававшихся позиций, которые все еще отображаются в прайсе.
- В UI визуально отличается строкой с колокольчиком, страной и check вместо цены.

### 2. Price-target notification
- Сценарий: сообщить, когда цена станет равной или ниже выбранного порога.
- Хранится как уведомление с ценой.
- Актуально для доступных строк через long press, а также для отсутствующих строк через модалку настройки цены.
- В UI визуально отличается строкой с колокольчиком, страной и целевой ценой.
- Это строка подписки в Price List: она показывает сохранённый target. Событие достижения цены в [Notifications](notifications.md) показывает фактическую цену товара, которая может быть ниже target; target не подменяется этой ценой.

## Mutual exclusivity
- Для одной и той же товарной позиции и страны одновременно не должно существовать два типа уведомления.
- Если пользователь сначала поставил in-stock notification, а затем настроил price-target notification, остается только ценовое уведомление.
- Если обновляется ценовое уведомление по той же стране, существующая notification row переиспользуется и обновляется.

## Entry mechanics
### Available товар
- Tap по строке: переход на экран покупки.
- Long press по строке: открытие модалки настройки price-target notification.

### Unavailable товар
- Tap по строке: поставить/снять in-stock notification.
- Long press по строке: открыть модалку price-target notification.

## Visual behavior
- После успешного добавления in-stock notification у исходной строки появляется check, сортировка строки не меняется, показывается toast, а внизу раскрытой группы появляется notification row.
- После успешного добавления price-target notification появляется колокольчик и внизу раскрытой группы добавляется notification row с выбранной ценой.
- Если уведомление было добавлено из свернутой группы, группа автоматически раскрывается после успешного добавления.
- Если уведомление было добавлено в уже раскрытой группе, она остается раскрытой.
- Notification rows показываются только внутри раскрытой группы.
- В свернутой группе специальный индикатор наличия уведомлений не отображается.
- Порядок notification rows должен соответствовать порядку стран, заданному в админке.

## Edit and delete behavior
### In-stock notification
- Повторный tap по notification row удаляет уведомление.
- После удаления check скрывается.
- Пользователь получает toast/snackbar с возможностью undo.
- Confirm dialog не нужен.

### Price-target notification
- Tap по notification row открывает редактирование.
- Long press по обычной продаваемой строке также открывает создание/редактирование price notification.
- В модалке пользователь может изменить порог.
- Если ползунок довести до крайнего правого значения удаления, уведомление удаляется.
- После удаления notification row скрывается.
- Confirm dialog не нужен.

## Price selection rules
- Верхняя граница = текущая / максимальная цена товара.
- Нижняя граница = верхняя граница минус 50 USD.
- Шаг = 1 USD.
- Валюта = USD.
- Сохранение происходит автоматически после отпускания ползунка.
- После отпускания ползунка ожидается небольшая задержка, ориентировочно 0.5 секунды.
- Если уведомление уже существовало, модалка должна открываться с ранее выбранным значением.
- Для очень дешевых товаров нужен отдельный тест на нижнюю границу диапазона.

## Dependencies on price list data
- Уведомление можно поставить только на позиции, которые реально выводятся в прайсе.
- Если характеристика не имеет ни одной видимой строки, таб скрывается полностью.
- Если товар никогда не продавался, он в прайс не выводится и уведомление с экрана поставить нельзя.
- Если товар ранее продавался, но сейчас отсутствует, он может отображаться в раскрытом списке как кандидат на уведомление.

## Push result
- Срабатывание при `price <= target`, не только при точном равенстве. Падение сразу ниже порога также вызывает событие.
- В списке Notifications цена события фактическая; например, при target 550 USD и цене 520 USD событие содержит 520. Если подписка остаётся активной, её строка в Price List показывает target 550; состояние подписки после срабатывания — Q28 чек-листа прайса.
- Тексты системного push ниже не являются обязательными текстами строк списка Notifications.
- Для in-stock notification ожидаемый текст: `Now in stock`.
- Для price-target notification ожидаемый текст: `The price has reached your target`.
- Проверку локализации стоит выполнить хотя бы один раз.

## Known implementation gaps / points to verify
- Было замечено потенциальное упущение: long press по товару, который фактически доступен только для in-stock уведомления, открывает модалку price notification. Это нужно явно проверить.
- Нужно проверить нижнюю границу диапазона для дешевых товаров.
- Для reseller остается открытый вопрос: порог должен считаться по финальной цене на экране или по базовой цене без reseller markup.

## Out of scope
- Старый экран/раздел уведомлений в профиле.
- Проверка недоступности старого route `preorder-notifications`.
- Полное покрытие соседних экранов.
