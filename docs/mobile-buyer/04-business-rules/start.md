# Стартовый экран — Fimex Buyer, iOS


## Подтверждённые правила

- При первом запуске русский язык выбирается только для русского языка устройства; для любого другого — английский.
- Доступны русский и английский. Язык можно изменить кнопкой.
- Первоначальная тема берётся с устройства; её можно изменить кнопкой.
- После авторизации язык и тема берутся из аккаунта; настройки хранятся на backend.
- [Профиль](profile.md): настройки отдельные для каждого аккаунта; при первом старте корпа/реселлера язык и тема наследуются из профиля клиента, затем используются собственные сохранённые значения. Это не правило неавторизованного первого запуска выше.
- `Join Fimex` открывает [регистрацию](registration.md#registration).
- `Already registered` открывает [авторизацию](authentication.md#login).
