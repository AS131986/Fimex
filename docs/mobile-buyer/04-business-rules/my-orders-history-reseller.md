# Правила: История из «Моих заказов» — реселлер

## Область и завершение

- История включает только завершённые собственные заказы текущего реселлера; входящие фильтры активного списка не передаются.
- Собственный заказ становится доступен в Истории после ручного Paid и подтверждённой выдачи клиентом/корпом, в любом порядке. «Выдать» доступно клиенту/корпу только после админского Released. Один Released или только одно из двух действий не завершают заказ. Реселлер сам оплату/выдачу не меняет.
- Заказ архивируется только целиком, без выделения отдельных позиций/части количества.
- Архивирование не переоценивает сохранённую покупку. Освобождение лимита/денежные операции при выдаче отдельно не уточнены в правилах активной деталки; не выводить их из появления в Истории.

## Периоды и навигация

- 1M / 3M / 6M / 12M; при новом открытии первый период с архивными данными, без данных заблокирован.
- Период по дате заказа; это не подтверждение даты ячейки/порядка. Точные границы — RESHIST-Q02.
- Карточки от новых к старым. Сортировочное поле, дата на карточке и равные даты — RESHIST-Q01.
- Возврат из архивного заказа сохраняет период; закрыть Историю и открыть снова — первый доступный период, не прежний выбранный.
- При загрузке скелетон. Pull-to-refresh нет. Ошибки/real-time/обновление при возврате — RESHIST-Q03.

## Стоимость и карточки

- Количество — сумма единиц товара всех архивных заказов выбранного периода. Сумма — стоимость этих товаров с зафиксированной клиентской наценкой; число карточек не является количеством товара.
- Стоимость заказа = сумма сохранённых цен единицы с выбранной гарантией/применимым типом оплаты × количество. Сумма периода = сумма стоимостей включённых заказов. Точность/округление и конфигурация цены остаются в вопросах активной деталки; не пересчитывать старые покупки по текущему прайсу.
- Ячейка показывает статус/иконку, номер, дату, тип оплаты, сумму и статус оплаты; tap открывает именно этот заказ.
- Состояние не редактируется из Истории. Условия допуска в архив не заменяются простым визуальным Released для клиентских/собственных реселлерских заказов.

## Архивная деталка и документы

В архивной деталке собственный номер, зелёный Released, статус оплаты, Qty/Amount, таймлайн и товары/гарантия соответствуют собственной деталке реселлера. Все суммы/цены с зафиксированной клиентской наценкой. Себестоимость и процент наценки не раскрываются; переключателя «Себестоимость» / «С наценкой», вкладок других владельцев/«Все» нет.

Меню содержит только три документа по всем товарам собственного заказа с наценкой, без логиста. Гарантию менять нельзя также для товара, который позволял её менять до КТ. Реселлер не меняет оплату/выдачу. Полноэкранный горизонтальный просмотр показывает номер, товары, количество, итоговую цену и гарантию; точные действия возврата/поворота остаются RESDET-Q04.

- Общие поля/таймлайн/цвета наследуются из [активной деталки](order-detail-reseller.md). Даты наступивших статусов сохраняются, новый вход в Историю не становится датой статуса. Неуточнённые источники дат активной деталки сохраняют свои вопросы.
- Гарантия/логист/тип оплаты/оплата/выдача не редактируются. Просмотр вкладок/таймлайна/режима цены/full-screen не изменяет заказ, баланс или лимит.
- Три документа × Excel/PDF = шесть вариантов; каждый по актуальному состоянию и допустимому набору/основе цены, как в активной деталке. Вопросы формата/серийных номеров/Share не закрыты фактом наличия скачивания.

## Пустота и открытые вопросы

- Нет архивных данных во всех периодах: серая иконка выданного заказа, «Нет данных», «Похоже вы не совершили ни одного заказа, для отображения данных»; периоды/показатели/карточки скрыты, заголовок/крестик видны. Ошибку загрузки не считать подтверждённой пустотой данных.
- **RESHIST-Q01:** дата на ячейке и поле сортировки: дата заказа/поставщика без дней доставки или фактическая дата выдачи? Ответ «Верно» на альтернативный вопрос не выбрал вариант. Порядок новых к старым подтверждён; равные даты/вторичный ключ также не заданы.
- **RESHIST-Q02:** точное поле даты заказа, календарные/скользящие месяцы, часовой пояс, включение границ, заказы старше 12M. Дата заказа и первый доступный период подтверждены.
- **RESHIST-Q03:** ошибки/повтор загрузки/старые данные, real-time, новое получение данных при возврате из архивной деталки, загрузка самой архивной деталки. Скелетон и отсутствие pull-to-refresh Истории подтверждены; не наследовать refresh статистики.
- **RESHIST-Q04:** закрытие Истории свайпом, сохранение фильтров/секции исходного списка после закрытия, прокрутка Истории при возврате, изменения/исчезновение архива в другой сессии. Возврат из заказа сохраняет период; новое открытие сбрасывает его. Параметры возврата full-screen наследуют известные/открытые правила активной деталки.
