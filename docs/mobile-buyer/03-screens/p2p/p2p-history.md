# История P2P — все роли, Fimex Buyer, iOS

## Назначение, вход и доступ

Открывается книгой из [раздела П2П](p2p-active-requests.md). Всплывающий экран «История» / «History» содержит только успешные покупки по П2П, подтверждённые пользователем или поставщиком. Активные, удалённые, истёкшие по КТ и снятые без успешной покупки не входят.

Клиент и связанный корп видят общую историю друг друга; реселлер — только свою. История П2П реселлера не открывается клиенту/корпу по аналогии с клиентскими заказами. Цены клиента/корпа без клиентской наценки, реселлера с наценкой. **Во всех ролях цена в Истории без стоимости дополнительной гарантии.** Это отдельный способ представления сделки, не общая История заказов с итоговой гарантией.

## Периоды, показатели и строки

- Заголовок/крестик, периоды 1M / 3M / 6M / 12M. При открытии выбирается ближайший доступный с историей в этом порядке. На светлом примере 1M/3M недоступны, выбран 6M, 12M доступен. Точный календарный/скользящий расчёт периода — P2PHIST-Q01.
- **В период сделка включается по дате создания заявки**, не по дате покупки. Применяется к успешным сделкам, даже если их даты создания и покупки различаются.
- «Кол-во» — сумма купленных единиц в сделках периода. «Сумма» — сумма их цен покупки без дополнительной гарантии × количество, с клиентской наценкой только для реселлера.
- Строка: флаг либо иконка, название товара, цена покупки **за единицу без гарантии**, дата покупки, купленное количество. Это успешная цена сделки, не обязательно первоначальная предложенная пользователем цена.
- Сортировка по **дате покупки, новые первыми**, отдельно от даты отбора периода. Равные даты/вторичный ключ — P2PHIST-Q02.
- Tap открывает информацию именно об этой покупке. Фильтр «Все чаты / Поставщик» исходного списка не влияет на состав Истории. Закрытие информации о сделке сохраняет выбранный период; новое открытие Истории снова выбирает ближайший доступный. Прокрутка/способы закрытия самой Истории — P2PHIST-Q03.

На тёмном примере количество 151 = 50 + 51 + 50; сумма 143900 = 869 × 50 + 1400 × 51 + 581 × 50. Это пример проверки цены единицы и всех количеств, не постоянные значения для экрана. Цена 581 отражает успешную встречную сделку, а не прежнее собственное предложение 580.

## Информация о покупке

Отдельное окно поверх Истории с крестиком; только просмотр. Название/флаг либо иконка; «Моя цена» — цена успешной покупки без гарантии в представлении роли, «Кол-во» — купленное количество.

На примере таблица содержит «Код номер», «Страна», «Модель», «Дата», «Время», «Сделка закрыта». Дата/время относятся к покупке; источник/часовой пояс остаются P2PHIST-Q01. В «Сделка закрыта» отображается инициатор завершения: поставщик принял предложение пользователя либо пользователь принял встречное предложение поставщика. На образце поставщика точная подпись **«Поставщик»**; подпись второго варианта ещё не дана — P2PHIST-Q05.

Не путать инициатора с владельцем заявки/текущим открывшим аккаунтом. Клиент может посмотреть завершённую корпом сделку, но просмотр не меняет её инициатора. Поля без данных и состав по категориям — P2PHIST-Q05; нельзя объявлять скрытие пустых полей подтверждённым ответом «Только просмотр».

Редактирование цены/количества/гарантии, повторное принятие, удаление/повторная покупка в этом окне недоступны. Просмотр не занимает лимит, не меняет депозит/баланс или обычный заказ, созданный по сделке. Здесь нет подтверждённого скачивания документов; не переносить меню архива обычных заказов.

## Полноэкранный просмотр

Кнопка «Полноэкранный режим» открывает горизонтальный список: периоды и крестик сверху, ниже те же строки с названием/флагом либо иконкой, датой покупки, ценой без гарантии и количеством. На предоставленном горизонтальном образце заголовок и блок общих показателей не показаны.

Tap по строке открывает горизонтальную информацию о той же сделке: слева название/цена/количество, справа таблица данных и инициатор. Закрытие информации возвращает горизонтальный список. Крестик fullscreen возвращает обычную Историю с прежним периодом; не закрывает её целиком. Никакой режим просмотра не редактирует сделку.

## Загрузка и ограничения

При загрузке скелетон, **ручного refresh нет**. Real-time Истории, появление новых сделок в уже открытом экране, ошибки/возврат из фона не уточнены — P2PHIST-Q04; не наследовать подписку активной заявки автоматически.

Книга скрывается без успешных сделок за год по [правилам списка](../../04-business-rules/p2p-active-requests.md). Точное значение года не закрыто описанием периодов. Пустота уже открытой Истории/её текст отдельно P2PHIST-Q04; не копировать пустоту обычных заказов или информационный блок активного П2П без подтверждения.
