# История из «Моих заказов» — реселлер, Fimex Buyer, iOS

## Назначение и вход

Всплывающий экран «История» открывается кнопкой книги из [my-orders-reseller](my-orders-reseller.md). Область — только завершённые собственные заказы текущего реселлера. Фильтры ID/статуса предыдущего списка никак не влияют на Историю. Это архив заказов, не статистика всех покупок.

Собственный заказ становится доступен в Истории после ручного Paid и подтверждённой выдачи клиентом/корпом, в любом порядке. «Выдать» доступно клиенту/корпу только после админского Released. Один Released или только одно из двух действий не завершают заказ. Реселлер сам оплату/выдачу не меняет. Архивирование только целиком, вместе со всеми товарами заказа; частичная выдача/архивирование не предусмотрены.

## Период, показатели и список

- Заголовок «История» и крестик закрытия; при загрузке скелетон.
- Периоды 1M / 3M / 6M / 12M. При новом открытии первый доступный период в этом порядке; без данных период заблокирован. Если данных нет во всех периодах — пустое состояние.
- Включение в период **по дате заказа**. Точное поле/границы/часовой пояс — RESHIST-Q02.
- Qty / «Кол-во» — суммарное количество единиц товара в заказах выбранного периода, не число заказов/строк. Amount / «Сумма» — стоимость этих товаров с зафиксированной клиентской наценкой, включая выбранную гарантию и применимый тип оплаты по правилам заказа.
- Ячейка: иконка статуса, номер заказа, дата, тип оплаты, сумма с зафиксированной клиентской наценкой, статус оплаты. Порядок от новых к старым; источник даты ячейки/сортировки — RESHIST-Q01.
- Tap открывает соответствующий архивный заказ; закрытие заказа возвращает выбранный период Истории. После закрытия и нового открытия самой Истории снова первый доступный период.
- **Pull-to-refresh отсутствует**, так как экран всплывающий. Ошибки/real-time отдельно не уточнены — RESHIST-Q03; поведение статистики или активного списка не переносить автоматически.

## Архивный заказ

Состав просмотра наследует [order-detail-reseller](order-detail-reseller.md), с обязательным запретом изменения данных. Разрешены просмотр, раскрытие таймлайна, предусмотренные вкладки/режим цены и полноэкранный просмотр; из меню — скачивание документов. Tap по товару не открывает редактор гарантии/логиста. Статус оплаты не открывает подтверждение, «Выдать» отсутствует как доступное действие. Любой просмотр не изменяет цены, гарантии, логиста, тип оплаты, оплату, выдачу, баланс или лимит.

В архивной деталке собственный номер, зелёный Released, статус оплаты, Qty/Amount, таймлайн и товары/гарантия соответствуют собственной деталке реселлера. Все суммы/цены с зафиксированной клиентской наценкой. Себестоимость и процент наценки не раскрываются; переключателя «Себестоимость» / «С наценкой», вкладок других владельцев/«Все» нет.

Меню содержит только три документа по всем товарам собственного заказа с наценкой, без логиста. Гарантию менять нельзя также для товара, который позволял её менять до КТ. Реселлер не меняет оплату/выдачу. Полноэкранный горизонтальный просмотр показывает номер, товары, количество, итоговую цену и гарантию; точные действия возврата/поворота остаются RESDET-Q04.

Накладная / упаковочный лист / серийный номер — каждый в Excel и PDF, по той же логике, что активный заказ. Файл формируется в актуальном состоянии архивного заказа/разрешённого режима, не из старого кэша. Неуточнённые колонки, пустые серийные номера и Share остаются в вопросах соответствующей активной деталки.

## Пустое состояние

При отсутствии архивных заказов во всех доступных периодах карточка: серая круглая иконка выданного заказа, **«Нет данных»**, текст **«Похоже вы не совершили ни одного заказа, для отображения данных»**. Периоды, Qty/Amount и список скрыты; заголовок и крестик остаются. Активные/незавершённые заказы не устраняют пустоту Истории. Примеры количеств/сумм/номеров на скриншотах не константы.
