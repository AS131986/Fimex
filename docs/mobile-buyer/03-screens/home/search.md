# Поиск — Fimex Buyer, iOS

## Назначение и область

Поиск товаров из строки поиска [Главной](home.md). На предоставленных скриншотах экран открыт как sheet с заголовком Search и кнопкой закрытия. Здесь описываются ввод запроса, результаты, история и переход в прайс/покупку; сам процесс покупки не входит в область.

## Элементы

- Заголовок Search и крестик закрытия экрана сверху.
- Поле Search in Fimex над клавиатурой, иконка поиска и отдельный крестик очистки непустого поля.
- Первоначальная подсказка Search the catalog с описанием поиска по названию модели, категории или коду.
- Строки результатов с иконками товаров; совпадения запроса выделяются жирным.
- History: выбранные ранее результаты с иконками, кнопка Clear all.
- Скелетон во время загрузки.
- No result с иконкой поиска и сообщением, содержащим текущий запрос.

Крестик закрытия экрана, очистка поля и Clear all — три разных элемента. Не считать их взаимозаменяемыми. На примерах встречается NEW; правила этой метки не предоставлены.

## Состояния

- Пустой запрос без истории: подсказка поиска.
- Пустой запрос с историей: список выбранных результатов.
- Введён запрос, идёт загрузка: скелетон.
- Совпадения найдены: результаты с иконками и жирным выделением.
- Совпадений нет: No result; текст сообщает об отсутствии результатов для текущего запроса.
- После выбора результата: прайс по категории/модели либо сразу покупка, если в соответствующем прайсе только один товар.

## Переходы

Выбор найденной категории/модели ведёт к соответствующей области прайса. Для ветвления учитывается число товаров в прайсе выбранного результата, а не только число строк на экране поиска. Точная единица подсчёта товара ещё требует уточнения.
