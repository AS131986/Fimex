# Главная и нижнее меню — Fimex Buyer, iOS

## Область

Главный раздел приложения: хедер, выбор товара по бренду/категории/модели, Top sellers и нижнее меню. Для соседних разделов документируется только переход. Полное поведение настроек, поиска, уведомлений, заказов, P2P и профиля будет описываться отдельно.

## Хедер

- Бургер для перехода в настройки.
- Строка поиска для перехода на экран поиска.
- Обозначение USD с флагом на предоставленном скриншоте.
- Кнопка уведомлений с красной точкой при наличии новых уведомлений.

## Выбор товара

- Сетка логотипов брендов; выбранный бренд подсвечивается.
- Блок Choose device: кнопка Price-list для бренда, категории с названием и иконкой; выбранная иконка категории подсвечивается.
- Блок Choose a model: кнопка Price-list для категории и список моделей.
- Price List открывается по бренду, категории или модели в зависимости от выбранного элемента. При отсутствии соответствующего уровня вложенности возможен прямой переход в прайс.
- Пример без категорий на предоставленном скриншоте: переход к прайсу Whoop. Название и конкретный товар примера не являются постоянными требованиями.

## Top sellers

- Заголовок блока, вкладки брендов и список моделей.
- Модели отображаются с названием и иконкой.
- Вкладки переключаются тапом и свайпом вправо/влево.

## Нижнее меню

Разделы в порядке предоставленного экрана: Главная, Мои заказы, P2P, Профиль. Меню закреплено при прокрутке, выбранный раздел подсвечивается. У Моих заказов — счётчик активных заказов, у P2P — счётчик ответов поставщиков на заявку пользователя.

Иконки, похожие на корзину и чат, обозначают Мои заказы и P2P. Не называть их корзиной и чатами.

## Состояния

- Дефолтная Главная без выбранного бренда и категории.
- Выбран бренд, показаны категории.
- Выбрана категория, показаны модели.
- Выбран бренд Top sellers.
- Первоначальная загрузка или обновление со скелетоном.
- Ошибка соединения либо сервера с alert.
- Элемент каталога был показан, но снят с продажи до выбора: alert недоступности.
- Новое уведомление: красная точка.
- Заблокированный реселлер: Главная скрыта; точная компоновка меню этого состояния не предоставлена.

Нулевое количество товаров в продаже не является штатным состоянием по сообщению пользователя. Дополнительное поведение полностью пустой Главной не задано.
