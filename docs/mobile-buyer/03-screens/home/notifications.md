# Уведомления — Fimex Buyer, iOS

## Назначение и элементы

Экран открывается по кнопке уведомлений [Главной](home.md). На скриншотах: sheet Notifications, Clear слева, закрытие крестиком справа, строки событий с иконкой, основным текстом и дополнительными данными.

Предоставлены примеры ответа поставщика с суммой/товаром, оплаты и смены статуса с номером заказа, поступления товара, достижения цены и пополнения баланса. Событие с мегафоном и текстом `11` пользователь определил как ответ поддержки; `11` не является фиксированным текстом всех ответов.

## Состояния

- Загрузка списка со скелетоном.
- Список событий, новые сверху.
- Событие удалено после tap для подтверждённых типов; обычно открывается соответствующий экран, для ответа P2P только скрывается строка. Удаление компенсации отдельно не подтверждено.
- Пустой список: иконка колокольчика, `No notifications`, `There are no new incoming notifications for you`.
- Ошибка соединения/сервера со стандартным alert.
- Товар по уведомлению уже недоступен: alert при попытке перехода в покупку.

На предоставленном пустом состоянии кнопка Clear отсутствует. Русские тексты, точная иконка компенсации и экран назначения компенсации не предоставлены.

## Типы и назначения

| Событие | Tap |
|---|---|
| Смена статуса заказа | Детали соответствующего заказа |
| Оплата заказа | Детали соответствующего заказа |
| Появление товара в продаже | Покупка соответствующего товара |
| Достижение целевой цены | Покупка соответствующего товара |
| Ответ поставщика на заявку P2P | Только скрытие события |
| Пополнение баланса | Баланс |
| Ответ поддержки | Поддержка |
| Компенсация за отменённый товар в заказе | Экран компенсации |

Экран компенсации отдельно не описан. Назначение уведомления пополнения депозита реселлера требует уточнения, не подменяется экраном баланса клиента.
