# Настройки → Логистика

[Чек-лист](CHECKLIST.md). Требования по скриншотам и уточнениям от 25 ноября 2026 года.

## LG-R01. Список по стране реализации

У каждой страны реализации своя папка в меню «Настройки → Логистика» и свой список логистов. На скриншотах показаны Deira и Free zone. Добавление и редактирование выполняются для записи выбранной страны.

В таблице показаны №, наименование, лицензия, адрес, телефон, дата окончания лицензии и действия. Для пустых реквизитов отображается прочерк. Если файл лицензии загружен, в колонке появляется иконка, по нажатию на которую открывается файл этой записи. У назначенного логиста отображается метка «По умолчанию».

## LG-R02. Поиск

Поиск работает по наименованию, адресу и номеру телефона в списке открытой страны реализации. Правила частичного совпадения, регистра и обработки форматирования телефона нужно уточнить на стенде.

## LG-R03. Добавление и редактирование

Кнопка «Добавить логиста» открывает форму создания. Нажатие на карандаш открывает модальное окно редактирования выбранного логиста с сохранёнными данными.

| Поле | Правило |
| --- | --- |
| Наименование | Единственное обязательное поле при добавлении, до 150 символов. |
| Адрес | Необязательное поле, до 150 символов. |
| Телефон | Необязательное поле, до 20 символов. Ввод букв запрещён. |
| Дата окончания лицензии | Необязательное поле. Прошедшая, текущая и будущая даты допустимы. |
| Лицензия | Необязательный файл. В интерфейсе указаны JPG, PNG, GIF, SVG, PDF. Максимальный размер — 10 МБ. |
| По умолчанию | Переключатель назначения логиста по умолчанию для своей страны реализации. |

## LG-R04. Отображение срока лицензии

Дата окончания отображается красным, если она наступила или прошла. Например, если сегодня 25.11.2026, даты 24.11.2026 и 25.11.2026 красные, 26.11.2026 отображается обычным цветом. Дата и файл отображаются независимо. Часовой пояс для определения «сегодня» и влияние просрочки на назначение и заказы требуют уточнения.

## LG-R05. Логист по умолчанию и заказы

- Для каждой страны реализации может быть назначен максимум один логист по умолчанию. При назначении другого прежний автоматически теряет этот статус. Назначение в другой стране сохраняется.
- Для клиента без персонального логиста новые заказы направляются логисту по умолчанию его страны. При смене логиста по умолчанию новый выбор применяется к новым заказам. У уже созданных заказов логист сохраняется.

## LG-R06. Подтверждение удаления и переназначение клиентов

Удаление требует подтверждения. При отмене запись и клиентские назначения сохраняются.

| Условие | Результат |
| --- | --- |
| Удаляемый логист назначен по умолчанию | Удаление заблокировано. Показывается ошибка с просьбой сначала выбрать другого логиста по умолчанию. |
| У обычного логиста есть привязанные клиенты, и в этой стране назначен логист по умолчанию | После подтверждения запись исчезает из активного списка, все привязанные клиенты автоматически переходят к логисту по умолчанию этой страны. |
| У обычного логиста есть привязанные клиенты, а в этой стране логист по умолчанию отсутствует | Удаление заблокировано, запись и привязки сохраняются. Логист по умолчанию другой страны не подходит для переназначения. |
| У обычного логиста нет привязанных клиентов | После подтверждения его можно удалить, даже если логист по умолчанию отсутствует. |

## LG-R07. Архив

Архив запланировано перенести в «Управление». Его список и восстановление будут проверяться в рамках соответствующей страницы.

## Вопросы для стенда

| ID | Что уточнить |
| --- | --- |
| LG-Q01 | Частичный поиск, регистр, пробелы по краям и совпадение телефона с разделителями и без них. |
| LG-Q02 | Допустимые разделители и минимальная длина телефона, обработка пробелов в наименовании, одноимённые логисты в одной стране. |
| LG-Q03 | Точный лимит файла в байтах. Можно ли при редактировании отдельно заменить или удалить файл и очистить дату? |
| LG-Q04 | По какому часовому поясу наступает просрочка и влияет ли она на назначение логиста и маршрутизацию заказов? |
| LG-Q05 | Можно ли снять отметку «По умолчанию» без назначения другого логиста? Куда направляются новые заказы клиентов без своего логиста, если в стране нет назначения по умолчанию? |
| LG-Q06 | Как переназначение после удаления отражается в карточке клиента и что происходит с уже созданными заказами удалённого логиста? Правило о сохранении логиста при смене значения по умолчанию подтверждено отдельно. |
