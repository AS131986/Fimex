# Чек-лист: Настройки → Валюты (Currency)

[Требования и вопросы](README.md). Все проверки Not run. P1 — финансовая корректность и ключевые ограничения; P2 — основной функционал; P3 — UI/UX. Выполнять на тестовых данных. Не менять рабочие курсы.

## Подготовка

- USD — главная, курс 1; UZS — непривязанная обычная, курс 88; DRH — обычная, привязанная к стране реализации, курс 3.33.
- Подготовить ещё одну обычную валюту без курса, отдельную реализацию и тестовые покупки, для которых известны исходные цена и курс.
- Сохранить исходные данные справочника, привязок, истории и покупок. После сохранения изменений проверять повторное открытие страницы и перезагрузку.
