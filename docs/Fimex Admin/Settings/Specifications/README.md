# Настройки → Характеристики

[Чек-лист проверок](CHECKLIST.md).

## 1. Назначение и область действия

Страница управляет общим справочником характеристик товаров и их допустимых значений. Характеристика задаёт параметр, например Memory, Country или Colour; её значения — варианты этого параметра, например 128Gb, Australia или White.

Справочник единый для всех стран поставки и реализаций, включая UAE, USA, Deira (Mabetex) и Free zone (Fimex). Отдельные копии одной характеристики для этих связок не создаются. Характеристика Country описывает признак товара и не заменяет справочник стран поставки.

Изменения характеристик и значений сразу применяются к связанным товарам. При этом одинаковые названия допустимы: совпадение текста не объединяет разные записи.

## 2. Список характеристик и создание

- Слева отображается список характеристик. Выбор строки открывает её карточку справа; выбранная строка подсвечивается.
- Для создания нужно ввести название в поле «Новый элемент» и нажать **Enter** либо **«+»**.
- Новая характеристика может быть создана только с названием: переводы, изображение и значения при создании не обязательны.
- У новой характеристики тумблеры «Цвет» и «Иконка» по умолчанию выключены; список значений пуст.
- При пустом справочнике доступно добавление первой характеристики.
- Контекстное меню по правому клику содержит переименование и удаление. Переименование выполняется в строке списка.
- Основное название в карточке и название той же характеристики в списке относятся к одной записи.

Подтверждены Enter и «+» для создания. Момент сохранения и способ отмены редактирования уже существующих полей отдельно не определены — раздел 10.

## 3. Карточка характеристики

| Элемент | Правило |
| --- | --- |
| Название характеристики | Обязательно, не более 100 символов. |
| Изображение / иконка характеристики | Необязательно; загрузчик с превью рядом с основным названием. |
| Название характеристики в инфо, RU | Необязательно, не более 100 символов. Подпись для карточки товара на русском. |
| Название характеристики в инфо, ENG | Необязательно, не более 100 символов. Подпись для карточки товара на английском. |
| Значения | Список допустимых значений; сама характеристика может существовать без значений. |
| «Цвет» и «Иконка» | Взаимоисключающие настройки дополнительного атрибута значений; включение одной выключает другую. |
| Удаление характеристики | Доступно из контекстного меню списка и через корзину в карточке; требуется подтверждение. |

Обязательность изображения самой характеристики не следует из обязательности иконки отдельного значения при включённом режиме «Иконка»: это разные поля.

## 4. Текстовые поля и валидация

- Для основного названия, названий RU/ENG и названия значения действует максимум **100 символов**.
- Разрешены буквы, цифры, символы и эмодзи. Допускаются ручной ввод и вставка.
- Основное название характеристики и название добавляемого значения не могут быть пустыми или состоять только из пробелов. Начальные и конечные пробелы обрезаются.
- Пустые RU/ENG разрешены. Логика подстановки названия при отсутствии перевода не входит в согласованные проверки этой страницы.
- Проверок уникальности нет ни у характеристик, ни у их значений. Допускаются одинаковые названия, в том числе внутри одной характеристики для её значений.
- Повторное создание записи с названием ранее удалённой характеристики или значения разрешено; оно не является восстановлением прежней записи.
- Ограничение длины применяется и при создании, и при переименовании. Текст длиннее 100 символов не должен сохраняться целиком как допустимое значение; конкретное поведение интерфейса на границе длины отдельно не задано.

## 5. Значения характеристики

Каждая строка содержит название значения, элемент перетаскивания слева и корзину справа. Дополнительные поля определяются тумблерами выбранной характеристики.

Для добавления вводится название значения и заполняется обязательный атрибут выбранного режима: цвет либо иконка. Если оба режима выключены, достаточно названия. Добавление выполняется через **«+»** или **Enter**. Пока обязательных данных не хватает, кнопка «+» неактивна и Enter не добавляет строку.

Значение всегда относится к выбранной характеристике. Совпадение его названия со значением другой характеристики или соседней строки не делает их одной записью. Изменение или удаление должно относиться к выбранной записи и её связям с товарами.

Перетаскивание значений предусмотрено для ручного изменения порядка. Правила сортировки списка характеристик и применения порядка значений в других разделах пока остаются открытыми — раздел 10.

## 6. Тумблеры «Цвет / Иконка»

Тумблеры **взаимоисключающие**: у значения не могут одновременно использоваться цвет и иконка. Включение «Цвет» автоматически выключает «Иконка», включение «Иконка» автоматически выключает «Цвет».

Доступны три состояния: оба тумблера выключены, включён только «Цвет» либо включена только «Иконка». Выключение активного тумблера оставляет оба выключенными. Выбранное состояние сохраняется при повторном открытии карточки и перезагрузке страницы; одновременное включение двух режимов недопустимо.

| Цвет | Иконка | Атрибуты добавляемого значения |
| --- | --- | --- |
| Выключен | Выключена | Обязательно только название значения. |
| Включён | Выключена | Название и цвет. |
| Выключен | Включена | Название и иконка. |

Тумблеры относятся к атрибутам значений характеристики. Они не являются переключателями закупки, продаж или активности товара.

Изображение самой характеристики — отдельное поле: оно может быть загружено и при режиме «Цвет» у значений.

### 6.1. Цвет

- При включённом режиме у значений доступно поле HEX-кода и цветовой образец.
- Подтверждённый пример ввода — **шесть шестнадцатеричных символов без `#`**: `2B2B2B`, `CC8080`, `788977`.
- Для добавления значения при включённом «Цвет» цвет обязателен.
- Поддержка короткого HEX, прозрачности, префикса `#` и цвет по умолчанию отдельно не определены. Не следует считать эти варианты разрешёнными только на основании примера.

### 6.2. Иконка

- При включённом режиме для каждого значения доступна загрузка изображения с превью и заменой файла.
- Для добавления значения при включённой «Иконка» изображение обязательно.
- Загруженное изображение можно заменить. Отдельное удаление изображения с сохранением самой записи не предусмотрено.
- Это же ограничение на отдельное удаление применяется к изображению самой характеристики, если оно было загружено; первоначальная загрузка для неё необязательна.

Сохранение ранее введённых цветов и изображений при выключении, повторном включении или переключении между режимами требует отдельного уточнения. При смене режима обязательность добавляемого значения определяется новым активным режимом.

## 7. Загрузка изображений

Для изображения характеристики и иконок значений:

- Разрешены **SVG, PNG, WEBP, JPG/JPEG**.
- Максимальный размер файла — **2 МБ**.
- При загрузке выполняется оптимизация изображения; конкретные размеры и параметры оптимизации не заданы.
- Неподдерживаемый формат не принимается. Сообщение: «Формат файла не поддерживается. Разрешены: SVG, PNG, WEBP, JPG/JPEG».
- Файл больше допустимого размера не принимается. Сообщение: «Файл слишком большой. Максимум 2 МБ».
- Замена изображения относится к той же характеристике или значению; отдельная запись справочника из-за замены файла не создаётся.

## 8. Удаление

### 8.1. Характеристика

- Удаление из контекстного меню и корзины карточки выполняет одну операцию над выбранной характеристикой.
- Перед удалением показывается подтверждение; отказ от подтверждения сохраняет запись.
- Характеристика удаляется **мягко**.
- Использование характеристики в товарах не запрещает удаление. Администратору нужно показать предупреждение о влиянии на связанные товары.
- После удаления связанные товары сразу синхронизируются: из них убирается удалённая характеристика и относящаяся к ней часть данных. Остальные характеристики и их значения сохраняются.

### 8.2. Отдельное значение

- Корзина строки удаляет выбранное значение, а не характеристику целиком.
- Значение также удаляется **мягко**.
- Если значение используется в товарах, перед удалением необходимо предупреждение о влиянии на них.
- У связанных товаров убирается только удалённое значение соответствующей характеристики. Соседние значения и другие характеристики не удаляются.
- Необходимость отдельного подтверждения для значения, которое не используется в товарах, не определена.

Удаление атрибута само по себе не является удалением товара или переключением его доступности продажи: убирается только удалённая часть характеристик.

Мягкое удаление не означает наличие восстановления в интерфейсе. Восстановление характеристик и значений пока не входит в согласованный функционал страницы.

## 9. Связь с товарами

- Изменения названий, переводов, цветов и иконок сразу отражаются у товаров, связанных с изменённой записью.
- Удаление характеристики или значения сразу убирает соответствующую часть у связанных товаров.
- Так как справочник общий, изменение не ограничивается одной страной поставки или одной реализацией.
- Связь определяется конкретной записью справочника, а не совпадением её названия с другой записью.
- Синхронизация не должна менять остальные характеристики товара или затрагивать товары, не связанные с изменённой записью.

Эти правила описывают актуальные данные товаров. Поведение исторических данных уже оформленных заказов отдельно не согласовано.

## 10. Открытые вопросы

1. **Порядок.** Как сортируется список характеристик? Как сохраняется и применяется порядок значений после перетаскивания в номенклатуре и клиентских приложениях? Вопрос оставлен открытым.
2. **Редактирование.** В какой момент сохраняются изменения существующих полей и переименование в списке? Как отменяется несохранённый ввод?
3. **Смена режимов.** Сохраняются ли ранее заданные цвета и изображения при выключении и повторном включении, в том числе при переключении «Цвет → Иконка → Цвет» и обратно? Что происходит с уже существующими значениями без атрибута нового режима? Взаимоисключение тумблеров при этом является согласованным правилом.
4. **HEX.** Какие форматы разрешены кроме подтверждённого шестизначного ввода без `#` и есть ли цвет по умолчанию?
5. **Подтверждение удаления значения.** Нужно ли отдельное подтверждение при отсутствии связанных товаров? Для используемого значения предупреждение обязательно.
6. **Оформленные заказы.** Обновляются ли в истории заказов названия и оформление характеристик либо остаются данные, зафиксированные при оформлении?
