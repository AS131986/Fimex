# Номенклатура → Копирование

[Все блоки](../README.md) · [Чек-лист](CHECKLIST.md)

Основание: ТЗ «Номенклатура», PDF от 14.11.2026, и ранее согласованные правила проекта. Лимит изображений 2 МБ на файл имеет приоритет над отсутствием лимита в PDF. Функциональный прогон ещё не выполнялся.

## Объекты и входы

Копирование категории/модели вызывается через Duplicate в контекстном меню, товара — иконкой строки. Копирование бренда или отдельной конфигурации в ТЗ явно не задано; наличие таких действий исследуется, а не объявляется обязательным.

Для категории и модели PDF от 14.11 описывает появление копии под оригиналом с названием «<Название> copy» сразу в Rename. Переданная ранее справка описывала заполненную форму копирования. **NOM-C-Q01:** нужно сверить маршруты старой и новой реализации и согласовать расхождение; прежний сценарий формы не считается отменённым лишь из-за нового текста. Предполагаемые проверки расположения и Rename до сверки исследовательские.

Для папки копируются характеристики, иконки, вывод, вложенные модели и настройки процентов, карго, гарантий, привилегии поставщика. Объём копирования товаров и их идентификаторов внутри папки явно не раскрыт — **NOM-C-Q02**. При наследуемом наборе нужно исследовать, остаётся ли ссылка на родителя или появляется собственный набор. Настройки копии и исходника должны принадлежать соответствующим независимым сущностям.

## Копирование товара

Открывается добавление с данными исходного товара, включая фото; поля доступны для изменения. Код новый, автоматический, для единственного создаваемого товара может вводиться вручную. Допускается несколько значений характеристик и создание комбинаций. Если хотя бы одна комбинация уже существует в группе, сохранение запрещено. Неизменённая копия исходной комбинации не является допустимым дублем только потому, что ей выдан новый код.

После Save создаются независимые товары. Применяются обязательность кода, положительного исходного веса и характеристик, правила глобальной уникальности «код + RC», фото/WEBP и лимит 2 МБ из блока 4. Копирование не отменяет валидацию. RC в обычном добавлении назначается после создания; способ его переноса при копировании требует проверки — **NOM-C-Q03**. Копирование настройки сканирования, уникальных кодов производства, исходного/итогового веса и связанных настроек товара нужно сверить: раздел «Что переносится» в PDF не содержит отдельного полного перечня. Не выводить из общей фразы «все поля» разрешение дублировать уникальный код производства.

По правилам привилегий поставщика скопированный товар наследует галочку исходного товара. Проверка зависит от готовности каталога поставщика.

## Исследования и зависимости

Повторное копирование, коллизия суффикса copy, название длиннее 100 символов после суффикса, ошибки/отмена, права, перенос связанных настроек во всех связках и оформление результата проверяются отдельно. Для стока, заказов и финансов перенос не задан: не предполагать клонирование предложений, остатков или заказов — **NOM-C-Q04**. Для названий папок сохраняются область уникальности и ограничение длины блока 2; механизм разрешения коллизии ещё не определён.
