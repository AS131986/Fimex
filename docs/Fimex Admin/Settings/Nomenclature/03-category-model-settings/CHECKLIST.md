# Чек-лист. Номенклатура → Настройки категорий и моделей

[Правила блока](README.md) · [Раздел номенклатуры](../README.md)

В первом разделе проверяются согласованные правила формы. Второй раздел предназначен для сверки реализации и сравнения со старым проектом. Третий выполняется на стенде с нужными зависимостями.

## Подготовка

- Подготовить две категории и несколько моделей. У родительской категории настроить характеристики и вывод. Для сравнения использовать модель без своего набора и модель с собственным набором.
- В справочнике подготовить характеристики с однозначным алфавитным порядком. Для превью нужны минимум две характеристики с несколькими значениями и известным порядком значений. Для проверки добавления товара подготовить отдельную обязательную характеристику без значений.
- Для сценариев с существующими товарами зафиксировать до изменения их коды, значения характеристик, названия и группы. Для сценариев с продажей и стоком использовать тестовые записи с известным состоянием у поставщика.
- Согласованные проверки выполнять для категории и модели, где действие доступно. После сохранения сверять результат при повторном открытии формы и после перезагрузки.
- Для исследования указывать версию проекта, окружение, исходные данные, действие и результат. Если зависимость отсутствует, зафиксировать, какой шаг заблокирован. Результат старого проекта используется при согласовании правила нового.

## 1. Согласованные правила

### 1.1. Главные

- [ ] **NOM-MAIN-01 — Алфавитный порядок в окне выбора**

  <details>
  <summary>Подробности проверки</summary>

  - На вкладке «Главные» открыть «+» с подготовленным набором характеристик.
  - Характеристики берутся из справочника и показаны по алфавиту.

  </details>

- [ ] **NOM-MAIN-02 — Добавление характеристик в порядке выбора**

  <details>
  <summary>Подробности проверки</summary>

  - Из алфавитного списка выбрать три характеристики в обратной последовательности. Добавить ещё одну.
  - Список в форме сохраняет последовательность выбора. Последняя выбранная характеристика добавляется в конец.

  </details>

- [ ] **NOM-MAIN-03 — Сохранение ручного порядка характеристик**

  <details>
  <summary>Подробности проверки</summary>

  - Перетащить добавленную характеристику из конца в начало. Сохранить и открыть форму повторно.
  - Восстановлен ручной порядок. Окно «+» сохраняет алфавитный порядок справочника. Следующая выбранная характеристика добавляется в конец.

  </details>

- [ ] **NOM-MAIN-04 — Защита от повторного выбора характеристики**

  <details>
  <summary>Подробности проверки</summary>

  - Добавить характеристику, затем снова открыть «+» и проверить возможность выбрать ту же запись.
  - В наборе остаётся одна запись этой характеристики.

  </details>

- [ ] **NOM-MAIN-05 — Защита характеристики, используемой в выводе**

  <details>
  <summary>Подробности проверки</summary>

  - Добавить характеристику в «Главные» и «Вывод данных». Попытаться убрать её из «Главных».
  - Используемая характеристика остаётся в наборе. После удаления из вывода при соблюдении его обязательности характеристику можно убрать из «Главных».

  </details>

- [ ] **NOM-MAIN-06 — Удаление неиспользуемой характеристики из набора**

  <details>
  <summary>Подробности проверки</summary>

  - Убрать из «Главных» характеристику, которая отсутствует в выводе и настройке группы. Сохранить и открыть форму повторно.
  - Из выбранного набора убрана указанная характеристика. Остальные остаются на своих местах относительно друг друга.

  </details>

- [ ] **NOM-MAIN-07 — Наследование настроек модели без своего набора**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть модель без собственного набора у категории с сохранёнными характеристиками и выводом.
  - Для модели используется набор и вывод категории. Собственная вкладка «Вывод данных» неактивна.

  </details>

- [ ] **NOM-MAIN-08 — Собственный набор характеристик модели**

  <details>
  <summary>Подробности проверки</summary>

  - В модели выбрать собственную характеристику, отличную от характеристик категории. Настроить собственный вывод и сохранить.
  - Применяется собственный набор модели. «Вывод данных» доступен и использует выбранные в этой модели характеристики.

  </details>

### 1.2. Вывод данных

- [ ] **NOM-OUT-01 — Доступные характеристики для названия**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть блок «По умолчанию» и нажать «+». В справочнике должны быть выбранные и не выбранные в «Главных» характеристики.
  - В окне доступны характеристики из «Главных». Выбранную характеристику можно включить в вывод.

  </details>

- [ ] **NOM-OUT-02 — Обязательность хотя бы одной части вывода**

  <details>
  <summary>Подробности проверки</summary>

  - Для собственного набора оставить блок «По умолчанию» пустым либо убрать из него последнюю характеристику. Попытаться сохранить.
  - Пустой собственный вывод не сохраняется как допустимая настройка. Добавление одной характеристики позволяет сохранить корректно заполненную форму.

  </details>

- [ ] **NOM-OUT-03 — Первое значение каждой характеристики в превью**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать для вывода характеристики с несколькими значениями. Подготовить порядок значений, при котором первое значение отличается от первого по алфавиту.
  - Превью использует первые значения из справочника в порядке характеристик в блоке «По умолчанию».

  </details>

- [ ] **NOM-OUT-04 — Перестановка частей названия**

  <details>
  <summary>Подробности проверки</summary>

  - Перетащить часть названия в «Выводе данных». Сверить превью и повторно открыть сохранённые настройки.
  - Превью и сохранённый вывод отражают новый порядок. Состав и ручной порядок «Главных» сохраняются.

  </details>

- [ ] **NOM-OUT-05 — Удаление части названия**

  <details>
  <summary>Подробности проверки</summary>

  - Убрать крестиком одну из нескольких характеристик в блоке «По умолчанию». Сохранить.
  - Значение убранной характеристики исчезает из превью и вывода. Характеристика остаётся в «Главных».

  </details>

- [ ] **NOM-OUT-06 — Страницы использования названия в Info**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть Info в блоке «По умолчанию».
  - Отображается список страниц, где используется сформированное название товара. Зафиксировать фактический список для сверки при проверке связей.

  </details>

### 1.3. Группы товаров

- [ ] **NOM-GRP-01 — Источник характеристик для настройки группы**

  <details>
  <summary>Подробности проверки</summary>

  - В «Главных» выбрать часть характеристик из справочника, затем открыть выбор во вкладке «Группы товаров».
  - Доступны характеристики, выбранные в «Главных» этой формы.

  </details>

- [ ] **NOM-GRP-02 — Сохранение выбранных характеристик группы**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать доступные характеристики для группы и сохранить общей кнопкой формы. Открыть ту же запись повторно.
  - Выбор во вкладке «Группы товаров» сохранён. Способ формирования узлов дерева сверяется в исследовательском разделе.

  </details>

### 1.4. Общая форма

- [ ] **NOM-SET-01 — Сохранность черновика при смене вкладок**

  <details>
  <summary>Подробности проверки</summary>

  - Изменить набор и порядок в «Главных», настроить вывод и группу, затем вернуться на каждую вкладку до сохранения.
  - Текущие правки всех вкладок остаются в открытой форме.

  </details>

- [ ] **NOM-SET-02 — Общее сохранение трёх вкладок**

  <details>
  <summary>Подробности проверки</summary>

  - Подготовить допустимые изменения на всех трёх вкладках. Нажать «Сохранить» один раз и повторно открыть запись.
  - В форме отображаются новые набор и порядок характеристик, вывод и настройки группы. Повторить для добавления и редактирования.

  </details>

- [ ] **NOM-SET-03 — Сброс несохранённых настроек**

  <details>
  <summary>Подробности проверки</summary>

  - Изменить настройки на всех вкладках и закрыть окно крестиком. Повторить закрытием по клику вне окна.
  - После повторного открытия показаны ранее сохранённые настройки. При закрытии формы добавления черновик не создаёт запись.

  </details>

- [ ] **NOM-SET-04 — Изоляция сохранения между категориями и моделями**

  <details>
  <summary>Подробности проверки</summary>

  - Сохранить новые настройки одной модели с собственным набором. Открыть другую модель той же категории со своим набором и модель другой категории.
  - Набор, порядок, вывод и настройки групп других выбранных записей сохранены.

  </details>

### 1.5. Связь с добавлением товара

- [ ] **NOM-SET-05 — Блокировка добавления без характеристик модели**

  <details>
  <summary>Подробности проверки</summary>

  - У модели нет собственных или наследуемых характеристик. Открыть «Добавить товар».
  - Показано предупреждение о необходимости задать характеристики на вкладке «Главные». В области названия отображается «Название соберётся из выбранных характеристик». Кнопка «Сохранить» недоступна даже при заполнении остальных доступных обязательных полей.

  </details>

- [ ] **NOM-SET-06 — Блокировка добавления без значения обязательной характеристики**

  <details>
  <summary>Подробности проверки</summary>

  - Настроить модель с обязательной характеристикой без значений в справочнике. Заполнить остальные обязательные поля товара.
  - Товар нельзя сохранить без значения этой характеристики. Отдельно зафиксировать фактическое сообщение и отображение пустого выбора.

  </details>

- [ ] **NOM-SET-07 — Поля добавления после настройки характеристик**

  <details>
  <summary>Подробности проверки</summary>

  - Настроить и сохранить набор характеристик модели, у которых есть значения. Повторно открыть добавление товара.
  - В форме доступны поля и значения актуального набора. По ТЗ поля характеристик в окне добавления идут по алфавиту.

  </details>

## 2. Исследовательские проверки

Для пунктов сравнения сначала записать результат на старом тестовом стенде, затем повторить на новом с тем же исходным набором. Согласовать правило для нового проекта по наблюдениям.

- [ ] **NOM-OBS-SET-01 — Обновление наследованных настроек модели**

  <details>
  <summary>Подробности проверки</summary>

  - У категории изменить характеристики и вывод. Открыть её модель без своего набора, включая повторное открытие после перезагрузки.
  - Зафиксировать, когда и какие изменения родителя стали доступны модели и её товарам. Сверить, как это влияет на список выбора в «Группах товаров».

  </details>

- [ ] **NOM-OBS-SET-02 — Возврат к наследованию после удаления своего набора**

  <details>
  <summary>Подробности проверки</summary>

  - В модели с одной собственной характеристикой убрать её из вывода и до сохранения попытаться убрать её из «Главных». Зафиксировать возможность завершить переход и сохранить форму.
  - Записать, возвращаются ли набор и вывод категории, что происходит с прежним выводом модели и её настройкой группы.

  </details>

- [ ] **NOM-OBS-SET-03 — Сверка добавления характеристики к существующим товарам**

  <details>
  <summary>Подробности проверки</summary>

  - На старом стенде взять модель с товарами и добавить характеристику, для которой у них ещё нет сохранённого значения. Повторить на новом стенде.
  - Сравнить значения, название, конфигурацию и возможность открыть и сохранить товар. Зафиксировать, заполняется ли новое поле и требуется ли действие администратора.

  </details>

- [ ] **NOM-OBS-SET-04 — Сверка удаления характеристики существующих товаров**

  <details>
  <summary>Подробности проверки</summary>

  - На старом стенде убрать из модели характеристику, использованную её товарами. Перед удалением выполнить условия вкладки «Вывод данных». Повторить на новом стенде.
  - Сравнить сохранённые значения, название, конфигурацию и возможность редактировать товар. Зафиксировать результат для согласования правила.

  </details>

- [ ] **NOM-OBS-SET-05 — Оформление названия и пустое превью**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть превью со значениями, у которых в справочнике заданы иконки и смайлики. Затем проверить характеристику без значений.
  - Записать разделители, места отображения иконок и смайликов и вид превью при пустом списке значений. Сверить с названием существующего товара, если связь доступна.

  </details>

- [ ] **NOM-OBS-SET-06 — Формирование и название конфигурации**

  <details>
  <summary>Подробности проверки</summary>

  - Выбрать характеристики для группы из «Главных», сохранить форму и открыть модель с тестовыми товарами.
  - Установить, когда создаются конфигурации, как строится название узла и по каким значениям товары относятся к нему.

  </details>

- [ ] **NOM-OBS-SET-07 — Доступные операции и изменение состава группы**

  <details>
  <summary>Подробности проверки</summary>

  - Открыть настройки существующей тестовой конфигурации и проверить доступные действия. Если состав редактируется, изменить его на тестовых данных.
  - Зафиксировать доступные поля и действия. Сравнить прежнюю и новую конфигурации, их состав и названия товаров после сохранения. Проверить, как форма обрабатывает удаление из «Главных» характеристики, используемой в настройке группы.

  </details>

- [ ] **NOM-OBS-SET-08 — Вход в удаление конфигурации**

  <details>
  <summary>Подробности проверки</summary>

  - На тестовой группе проверить, где доступно удаление и какие подтверждения оно запрашивает. Использовать группу без стока и товаров в продаже.
  - Зафиксировать путь, элементы диалога и результат для группы и её товаров. Каскад архивации сверяется при наличии архива и связанных настроек.

  </details>

- [ ] **NOM-OBS-SET-09 — Готовность обновления существующих товаров**

  <details>
  <summary>Подробности проверки</summary>

  - Сохранить изменение вывода и настройки группы на модели с существующими товарами. Повторно открыть дерево и таблицу.
  - Отдельно зафиксировать, работает ли обновление названий и группировки. Для доступного обновления названия выполнить проверку применения сохранённого вывода.

  </details>

## 3. Проверки при наличии зависимостей

- [ ] **NOM-DEF-SET-01 — Обновление названия существующего товара**

  <details>
  <summary>Подробности проверки</summary>

  - Когда изменение вывода применяется к существующим товарам, изменить порядок частей и состав блока «По умолчанию» у категории с товарами.
  - После сохранения название ранее добавленного товара отражает новое правило вывода и его собственные значения.

  </details>

- [ ] **NOM-DEF-SET-02 — Предупреждение при изменении вывода для товаров в продаже**

  <details>
  <summary>Подробности проверки</summary>

  - В категории с товаром, выставленным поставщиком на продажу, отдельно добавить, удалить и переставить часть вывода.
  - В каждом сценарии появляется предупреждение о смене названий. Зафиксировать точный момент показа, результат подтверждения, результат отмены и сохранность черновика.

  </details>

- [ ] **NOM-DEF-SET-03 — Сценарии ограничения удаления конфигурации**

  <details>
  <summary>Подробности проверки</summary>

  - Сравнить доступность удаления группы без стока, со стоком без опубликованной цены и с товаром в продаже. Использовать отдельные тестовые группы.
  - Зафиксировать, какие состояния блокируют удаление, и текст причины. Точное правило ограничения для группы согласовать по результату.

  </details>

- [ ] **NOM-DEF-SET-04 — Архивация удалённой конфигурации**

  <details>
  <summary>Подробности проверки</summary>

  - После разрешённого удаления группы с товарами и связанными настройками открыть архив.
  - В архиве доступны удалённая группа и вложенные записи. По доступным данным сверить, что связанные настройки архивированы вместе с группой. Детальные проверки восстановления выполняются в блоке архива.

  </details>

- [ ] **NOM-DEF-SET-05 — Применение настроек названия в связанных разделах**

  <details>
  <summary>Подробности проверки</summary>

  - После реализации связей изменить вывод и проверить названия товара на страницах, перечисленных в Info.
  - Страницы используют сохранённый состав и порядок вывода. Открытые вопросы по форматированию сверяются с согласованным примером.

  </details>

- [ ] **NOM-DEF-SET-06 — Доступ к настройкам по правам**
