# Номенклатура → Настройки категорий и моделей

[Раздел номенклатуры](../README.md) · [Чек-лист блока](CHECKLIST.md)

Категория и модель настраиваются на вкладках «Главные», «Вывод данных» и «Группы товаров». Модель в части интерфейса называется подкатегорией. Группа товаров в дереве отображается как конфигурация.

## Тестовые данные LADA

Для прогона используются созданные бренд LADA, категории Granta, Vesta и Largus. Значения составляют синтетический набор для QA. Проверки начинаются с фиксации фактических настроек. Описанное ниже распределение ролей моделей и порядки H, O и G задаются как воспроизводимый исходный набор для прогона.

### Справочник характеристик

Значения внутри характеристики расположить в указанном порядке. Он нужен для проверки первых значений в превью.

| Характеристика | Значения в порядке справочника |
| --- | --- |
| Модель автомобиля | Granta, Vesta, Largus |
| Тип кузова | Седан, Лифтбек, Универсал, Фургон |
| Двигатель | 1.6 8V, 1.6 16V |
| Коробка передач | Механика, Автомат |
| Комплектация | Базовая, Комфорт |
| Цвет кузова | Белый, Чёрный, Красный |
| QA Пустая | Пустой список значений |

Если у «Цвет кузова» включено дополнительное поле цвета, значениям соответствуют HEX FFFFFF, 000000 и FF0000. Сохранить фактические состояния дополнительных полей иконки и смайлика перед проверкой оформления названия.

### Порядки для проверки

| Обозначение | Настройка | Последовательность |
| --- | --- | --- |
| H | Полный набор «Главных» | Модель автомобиля → Тип кузова → Двигатель → Коробка передач → Комплектация → Цвет кузова |
| O | Вывод «По умолчанию» | Модель автомобиля → Тип кузова → Комплектация → Двигатель → Коробка передач → Цвет кузова |
| G | Группы товаров | Двигатель → Коробка передач |

По ТЗ превью использует первые значения справочника. При порядке O ожидается последовательность «Granta Седан Базовая 1.6 8V Механика Белый». Это эталон состава и порядка значений. Разделители и оформление иконок и смайликов фиксируются в исследовательской проверке. Первые значения справочника используются и при просмотре настроек других моделей LADA. Название существующего товара проверяется по его собственным выбранным значениям.

### Роли категорий и моделей

| Узел дерева | Исходные настройки | Назначение |
| --- | --- | --- |
| Granta | Набор A, вывод A и группа G | Различимый родительский набор для наследования |
| Granta → Granta седан | Собственные H, O и G | Основные проверки формы и товаров |
| Granta → Granta лифтбек | Без собственного набора и вывода | Проверка наследования от Granta |
| Vesta | Собственные H, O и G | Контроль другой категории |
| Vesta → Vesta седан и Vesta SW | Собственные H, O и G | Контроль независимости настроек |
| Largus | Без собственных характеристик и вывода | Родитель для проверки пустого набора |
| Largus → Largus универсал | Собственные H, O и G | Сравнение изменения характеристик в старом и новом проектах |
| Largus → Largus фургон | Без собственного набора и вывода | Блокировка добавления без характеристик |

Для проверки локального набора, возврата к наследованию и пустых значений параметры временно меняются по шагам пункта. После каждого такого сценария восстановить исходные настройки затронутых узлов. Для Granta исходное состояние — A и его вывод, для Granta лифтбек — пустой собственный набор. Исследования, меняющие состав существующих товаров, выполнять на отдельных воспроизводимых наборах Largus универсал.

### Различимые наборы для наследования

| Профиль | Главные | Вывод данных |
| --- | --- | --- |
| A у категории Granta | Модель автомобиля, Тип кузова, Двигатель, Коробка передач | Модель автомобиля → Тип кузова → Двигатель → Коробка передач |
| B у модели Granta лифтбек для проверки своего набора | Модель автомобиля, Тип кузова, Комплектация, Цвет кузова | Тип кузова → Модель автомобиля → Цвет кузова → Комплектация |

У A есть собственные признаки Двигатель и Коробка передач. У B есть собственные признаки Комплектация и Цвет кузова. Два общих признака позволяют проверить, заменяет ли собственный набор родительский целиком, и отличить это от объединения наборов.

Сначала у Granta лифтбек оставить собственный набор пустым и проверить получение A и его вывода. Затем назначить B и собственный вывод B. В этом состоянии модель должна использовать четыре характеристики B. Для настройки собственной группы доступны характеристики B, например Комплектация.

После изменения A отдельно сравнить модель с пустым собственным набором и модель с B. Применение изменений к наследуемому набору и возврат к наследованию после очистки собственного набора фиксируются как исследования. Для повторения обычных проверок на категории назначать профиль из предусловий конкретного пункта, затем возвращать Granta к A. Granta седан сохраняет собственные H, O и G.

### Товары для проверки существующих записей

Подготовить товары, когда добавление доступно. Обозначения S1–S3 и V1 служат для записи результатов. Фактические коды и RC зафиксировать в начале прогона.

| Обозначение | Модель автомобиля | Тип кузова | Двигатель | Коробка передач | Комплектация | Цвет кузова |
| --- | --- | --- | --- | --- | --- | --- |
| S1 в Granta седан | Granta | Седан | 1.6 8V | Механика | Базовая | Белый |
| S2 в Granta седан | Granta | Седан | 1.6 8V | Механика | Комфорт | Красный |
| S3 в Granta седан | Granta | Седан | 1.6 16V | Автомат | Комфорт | Чёрный |
| V1 в Vesta седан | Vesta | Седан | 1.6 16V | Механика | Комфорт | Белый |

В исследованиях групп проверить, объединяются ли S1 и S2 по одинаковым двигателю и коробке, и как отображается конфигурация S3. Это наблюдение для согласования результата настройки G.

Для основных проверок использовать товары без предложений поставщиков. Сценарии предупреждений и ограничений удаления требуют отдельного тестового стока. При невозможности подготовить товары зафиксировать блокирующий шаг, затем выполнить доступные проверки сохранения формы.

## Путь добавления характеристики в «Главные»

Проверка проходит от открытия «+» и просмотра справочника до выбора, отображения выбранной характеристики в форме, сохранения и повторного открытия. Отдельно проверяются повторный выбор уже добавленной записи и возврат удалённой характеристики. После выбора новая характеристика располагается в конце списка.

Для первого просмотра полного списка используется Largus фургон с пустым набором. При проверке выбора частей вывода и группы нужные характеристики предварительно освобождаются от текущего назначения в соответствующей вкладке.

Момент применения выбора и способы закрытия вложенного окна фиксируются в исследовательском пункте NOM-OBS-SET-10.

## Главные

- Через «+» открывается выбор характеристик из справочника. В окне выбора список идёт по алфавиту. Одну характеристику можно добавить один раз.
- В форме выбранные характеристики появляются в порядке выбора. Каждая новая добавляется в конец списка. Перетаскивание задаёт ручной порядок, который сохраняется вместе с настройками.
- Характеристику, используемую в «Выводе данных», можно убрать из «Главных» после того, как её убрали из вывода. Ограничение при использовании характеристики в настройке группы проверяется при прогоне.
- При отсутствии собственного набора модель использует характеристики родителя. Если задать собственный набор, применяется он целиком. При наследовании вкладка «Вывод данных» неактивна, используется настройка вывода родителя.
- Обновление наследованных настроек после изменения категории и переключение обратно на наследование после удаления последней собственной характеристики проверяются при прогоне.

Правила названий и загрузки иконок описаны во втором блоке. [Бренды, категории и модели](../02-brands-categories-models/README.md)

## Вывод данных

- В блоке «По умолчанию» выбираются характеристики, которые используются в названии товара. Через «+» доступны характеристики из «Главных». Для собственного вывода нужна хотя бы одна характеристика.
- Порядок частей названия задаётся перетаскиванием в этом блоке. Крестик убирает характеристику из вывода. Она остаётся в наборе «Главных».
- Для превью берутся первые значения выбранных характеристик из справочника в порядке вывода. Для набора LADA порядок O даёт последовательность «Granta Седан Базовая 1.6 8V Механика Белый». Кнопка Info показывает страницы, на которых используется это название.
- Изменение сохранённого вывода должно применяться к названиям уже добавленных товаров. Доступность этой связи и фактическое обновление в таблице проверяются при прогоне.
- При добавлении, удалении или перестановке частей названия для категории с товарами в продаже требуется предупреждение «Есть товар в продаже. Изменение поменяет названия товаров. Продолжить?». Момент показа предупреждения и сохранение черновика после отмены нужно проверить.

Формат разделителей, правила отображения иконок и смайликов и вид превью при пустом списке значений уточняются по реализации.

## Группы товаров

Характеристики для настройки группы выбираются из тех, которые админ добавил на вкладке «Главные». Выбранные настройки сохраняются общей кнопкой формы.

Способ формирования и именования конфигураций в дереве, доступные операции с существующей группой и результат изменения состава группы проверяются при прогоне. Удалённая группа по ТЗ архивируется вместе с вложенными записями и настройками. Вход в удаление группы и его ограничения уточняются отдельно.

## Сохранение

Кнопка «Сохранить» сохраняет изменения всех вкладок за одно действие. При переключении вкладок введённые правки остаются в форме. После сохранения и повторного открытия показываются актуальные настройки. Закрытие формы крестиком или кликом вне окна сбрасывает несохранённые изменения.

## Добавление товара после настройки модели

Чтобы сохранить товар, нужно выбрать значения обязательных характеристик. Если у обязательной характеристики нет доступных значений, сохранить товар нельзя.

Когда у модели нет доступного набора характеристик, в окне «Добавить товар» показано предупреждение о том, что сначала нужно задать характеристики на вкладке «Главные». Кнопка «Сохранить» недоступна, вместо названия показана подсказка «Название соберётся из выбранных характеристик». Этот сценарий показан на скриншоте от 4 ноября. Пустой список значений у отдельной характеристики проверяется отдельно.

## Сверка со старым проектом

На сопоставимых тестовых данных сначала проверить в старом проекте, как добавление и удаление характеристики модели влияет на значения, название и конфигурацию существующих товаров. Затем повторить на новом стенде. Зафиксировать отличия и предложить ожидаемое поведение для нового проекта по итогам сравнения.

При прогоне отдельно зафиксировать доступность применения настроек к существующим товарам и группировке. Проверки продажи, поставщицкого стока, прав и отображения в других разделах выполнять при наличии соответствующих зависимостей. [ТЗ «Номенклатура»](https://app.clickup.com/t/90182877012/z8wf5rj831)
