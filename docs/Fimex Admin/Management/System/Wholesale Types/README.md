# Управление → Система → Типы опта

[Чек-лист](CHECKLIST.md) · [Проценты](<../../../Settings/Percents/README.md>)

Вкладка управляет типами опта, которые используются как типы оплаты в настройках процентов и при назначении клиенту. Требования основаны на предоставленных скриншотах и уточнениях от 25 ноября 2026 года. Проверки на стенде ещё не выполнялись.

## WO-R01. Доступ и список

- Путь в админке — «Управление → Система → Типы опта». По подсказке в интерфейсе раздел «Система» доступен супер-админам.
- Тип привязан к стране реализации. На скриншоте Deira и Free zone показаны отдельными блоками. В каждом блоке своя кнопка «Добавить».
- Для строки доступны перетаскивание, редактирование через карандаш и удаление через корзину.

## WO-R02. Создание

«Добавить» открывает форму «Новый тип опта» для выбранного блока. Изменения сохраняются кнопкой «Сохранить».

| Поле | Правило |
| --- | --- |
| Название | Одно обязательное поле. Максимум 150 символов. Одинаковые названия внутри одной реализации допускаются. |
| Иконка для светлой темы | Необязательное поле. |
| Иконка для тёмной темы | Необязательное поле. |

Для иконки указан максимум 2 МБ. Допустимые форматы и точную границу в байтах требуется уточнить. Можно сохранить тип без обеих иконок или с иконкой только для одной темы.

## WO-R03. Редактирование

Название можно изменить у любого типа, в том числе уже выбранного у клиента. Иконку каждой темы можно заменить или убрать. При переименовании сохраняются клиентские привязки и ранее установленные проценты.

## WO-R04. Удаление и клиентские привязки

Удаление запрещено, если тип выбран хотя бы у одного клиента. Для успешного удаления используется тестовый тип без клиентских привязок и активных заказов.

| Страна реализации | Где выбирается тип для клиента |
| --- | --- |
| Free zone | В приложении |
| Deira | В админке |

## WO-R05. Порядок

Порядок меняется перетаскиванием внутри блока страны реализации. Новый порядок сохраняется сразу. После обновления страницы список сохраняет новый порядок, а в «Процентах» колонки этой реализации идут в той же последовательности.

## WO-R06. Уведомления

После успешного создания, редактирования и удаления отображается тост. Текст уведомления при запрете удаления требуется уточнить.

## WO-R07. Связь с «Процентами»

- Каждый тип выводится отдельной колонкой для своей страны реализации. Например, тип Deira появляется в связках UAE × Deira и USA × Deira. Колонки Free zone сохраняют свой состав.
- В новой колонке по умолчанию стоит «-» для всех позиций. Это означает, что продажа по новому типу запрещена до настройки процента. Появление колонки не сбрасывает существующие проценты и тумблеры.
- Процент задаётся для конкретной колонки, позиции и пары стран. Переименование и перестановка сохраняют значения за исходным типом. После успешного удаления его колонка исчезает, значения остальных колонок сохраняются.
