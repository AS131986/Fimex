### Согласованные особенности номенклатуры

- Дерево: **бренд → категория → модель → конфигурация**. Группа товаров называется конфигурацией. Конкретные товары отображаются справа в таблице.
- Список товаров открывается только после выбора конфигурации. Сборного списка по бренду, категории или модели не требуется.
- В дереве порядок задаётся перетаскиванием внутри родителя; новый элемент появляется внизу. Порядок частей названия — отдельная настройка. Обязательная алфавитная сортировка строк таблицы не установлена.
- Последний выбор и раскрытие дерева после перезагрузки не сохраняются. Сохранённые данные и ручной порядок сохраняются.
- Редактирование бренда, категории и модели открывается из контекстного меню правой кнопкой мыши; поля заполнены актуальными данными. Закрытие формы крестиком или вне окна отменяет несохранённые изменения.
- **В номенклатуре все загружаемые изображения ограничены 2 МБ на каждый файл**, включая светлые/тёмные иконки и фотографии товаров. Ровно 2 МБ допустимо. Это уточнение пользователя заменяет отсутствие лимита в PDF. Не распространять его автоматически на другие страницы.
- В выборе характеристик справочник идёт по алфавиту. В «Главных» выбранные характеристики идут в порядке выбора, новые в конце, порядок можно менять перетаскиванием.
- Характеристику из «Главных» нельзя удалить, пока она используется в «Выводе данных». Взаимодействие с настройкой группы пока исследовательское.
- Без собственного набора модель использует родительский. Собственный набор заменяет родительский целиком. При наследовании собственный «Вывод данных» недоступен, используется родительский.
- Для собственного вывода нужна хотя бы одна характеристика. Части выбираются из «Главных». Превью использует первые значения справочника в порядке вывода. Название существующего товара использует его собственные значения.
- В «Группах товаров» доступны характеристики из «Главных». Формирование конфигураций и последствия изменения групп пока требуют исследования.
- Одна кнопка сохраняет все три вкладки. Переключение вкладок сохраняет черновик внутри формы.
- Без доступного набора характеристик добавление товара блокируется с предупреждением. Если у обязательной характеристики нет доступных значений, сохранить товар нельзя.
- «Товар в продаже» означает предложение, выставленное поставщиком. Это нельзя подменять только видимостью товара у клиента.
- Удаление мягкое, с отправкой в архив. Копирование открывает заполненную форму; название по умолчанию получает `copy`.

### LADA: актуальные тестовые данные третьего блока

Набор синтетический, достоверность реальных комплектаций автомобилей не требуется. «Модель автомобиля» и «Тип кузова» — **два отдельных справочника**.

Полные значения, порядок, роли узлов, товары S1–S3/V1 и подготовка каждого сценария находятся в [README третьего блока](Settings/Nomenclature/03-category-model-settings/README.md). Не считать описанную подготовку уже выполненной в интерфейсе: фактическое состояние нужно зафиксировать перед прогоном.

| Профиль | «Главные» | «Вывод данных» |
| --- | --- | --- |
| A у категории Granta | Модель автомобиля, Тип кузова, Двигатель, Коробка передач | Модель автомобиля → Тип кузова → Двигатель → Коробка передач |
| B у модели Granta лифтбек, временно для проверки своего набора | Модель автомобиля, Тип кузова, Комплектация, Цвет кузова | Тип кузова → Модель автомобиля → Цвет кузова → Комплектация |

- У Granta лифтбек исходно нет собственного набора: проверяется наследование A. Затем назначается B: должны использоваться четыре характеристики B, без примеси двигателя и коробки из A.
- Разные наборы необходимы для обнаружения ошибочного объединения родительских и собственных характеристик. Одинаковые наборы не позволяют увидеть эту ошибку.
- Granta седан имеет собственный полный набор H: Модель автомобиля → Тип кузова → Двигатель → Коробка передач → Комплектация → Цвет кузова.
- Порядок O: Модель автомобиля → Тип кузова → Комплектация → Двигатель → Коробка передач → Цвет кузова. Эталон состава превью: `Granta Седан Базовая 1.6 8V Механика Белый`; точное оформление исследуется.
- Группа G: Двигатель → Коробка передач.
- Vesta / Vesta седан / Vesta SW используются для независимости настроек. Largus универсал — для исследований на существующих товарах, Largus фургон без родительских и собственных характеристик — для пустого набора. «QA Пустая» — характеристика без значений.
- После временных изменений восстанавливать исходные профили. Для проверки предупреждений у категории временно подготавливается полный набор по предусловиям конкретного пункта, затем Granta возвращается к A.
