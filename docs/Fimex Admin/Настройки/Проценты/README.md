# Настройки → Проценты

Рабочий черновик функциональной документации. [Чек-лист](CHECKLIST.md). Проверки интерфейса и расчётов по этому документу ещё не выполнялись.

## 1. Назначение

Страница задаёт наценку площадки к цене поставщика и разрешает либо запрещает продажу позиций номенклатуры. Настройки индивидуальны для каждой пары «страна поставки × страна реализации».

**Страны поставки** — UAE, USA и другие страны поставщиков. **Страны реализации** — Deira (Mabetex), Free zone (Fimex) и другие реализации. Страна спецификации устройства, например Australia у варианта iPhone, — другой признак товара.

Наценка к цене поставщика на этой странице, дополнительная наценка клиента для реселлера и процент экспорта Excel — разные настройки. Их списки значений и правила не подменяют друг друга.

Пример ТЗ: цена поставщика 1000, процент 1% → клиентская цена 1010: `1000 × (1 + 1 / 100)`. Полный порядок расчёта с валютой, точностью и округлением единицы/суммы ещё не согласован — **PCT-Q05**.

## 2. Область действия

| Настройка | Область действия |
| --- | --- |
| Набор колонок типов оплаты | Общий для выбранной страны реализации при любой стране поставки. |
| Процент | Выбранные страна поставки, страна реализации, позиция дерева и колонка типа оплаты. «-» запрещает продажу только по этому типу оплаты, 0 задаёт нулевую наценку. |
| Тумблер позиции | Выбранные страна поставки, страна реализации и позиция дерева. Один тумблер строки относится ко всем её колонкам оплаты. |
| Изменение процента родителя | Все вложенные позиции только в выбранной связке и колонке оплаты; прежние значения перезаписываются. |
| Выключение или включение самого родителя | Все вложенные позиции только в выбранной связке. |
| Список доступных процентов | Настраивается в «Конфигурациях»; на странице доступен только выбор из актуального списка. |

Например, изменение процента iPhone в колонке Cash для UAE × Deira не меняет Online этой пары, USA × Deira или UAE × Free zone.

В [«Закупке и реализации»](<../Закупка и реализация/README.md>) «Продажи» — общая настройка реализации, а «Закупка» относится к стране поставки. Тумблер позиции на странице «Проценты» действует внутри конкретной пары и не подменяет эти ограничения.

## 3. Выбор стран и просмотр дерева

- Вверху выбираются страна поставки и страна реализации; таблица соответствует выбранной паре.
- Выключенную страну поставки или реализацию можно настраивать. Изменение её процентов не включает ни «Закупку», ни общие «Продажи».
- По ТЗ фильтры содержат все страны поставки и реализации. Обработка удалённых стран, пустых списков и выбор по умолчанию ещё требуют уточнения — **PCT-Q06**.
- Выводится вся номенклатура, включая позиции без стока и выключенные позиции.
- Иерархия: **бренд → категория → модель → вариант**. Пример: Apple → iPhone → iPhone 18 Pro Max → A3717 Australia.
- Уровни раскрываются и сворачиваются стрелкой; просмотр дерева не меняет настройки.
- Бренд — заголовок группы без процента и тумблера. Проценты и тумблеры доступны у категории, модели и варианта.
- Выключенная позиция остаётся на странице настроек и отображается серой.
- Кнопка «+» возле фильтров текущей реализации добавляет тип опта. Вместе с управлением справочником это действие переносится в «Конфигурации» и исключено из функциональных проверок этой страницы.

## 4. Типы оплаты и колонки

«Типы опта» и «типы оплаты» обозначают один справочник. «Наличный расчёт» и «Банковский перевод» на скрине — примеры настроенных типов, а не неизменный набор.

- Тип оплаты принадлежит выбранной стране реализации; набор её колонок общий для всех стран поставки.
- Каждому выводимому типу соответствует одна колонка. Число, названия и порядок колонок соответствуют справочнику.
- Значения процентов индивидуальны для каждой связки, позиции и типа оплаты. Если Cash = «-», а Online = 1%, покупка запрещена только за Cash; Online остаётся доступен при выполнении остальных условий.
- У нового типа оплаты все значения новой колонки — дефолтные «-»: продажа по новому типу запрещена. Старые колонки и тумблеры строк от его появления не меняются.
- Выключенный или удалённый тип скрывается из таблицы; его сохранённые проценты возвращаются при возврате этой же сущности типа.
- Создание другого типа с названием удалённого — новая колонка с «-», а не восстановление прежних процентов.

Управление справочником — добавление, редактирование названий, иконок, удаление и перетаскивание — проверяется в «Конфигурациях». В «Процентах» проверяются получившиеся колонки, их значения и независимость связок. Обновление после изменения справочника относится к отложенным межстраничным проверкам.

## 5. Проценты

### 5.1. Выбор значения

Нажатие на процент открывает список. Доступен **только выбор**, произвольный ручной ввод не предусмотрен. Изменение сохраняется сразу, без общей кнопки сохранения страницы.

**«-» и 0 имеют разные значения.** Их нельзя нормализовать друг в друга при сохранении или отображении.

| Выбор | Результат |
| --- | --- |
| «-» | Покупка товара запрещена только для типа оплаты этой колонки. Общий тумблер строки не выключается; другие типы оплаты не блокируются. Это не 0% и не наследование. |
| 0 | Товар продаётся без наценки этой страницы при выполнении остальных условий доступности. |
| Положительный процент | Для доступного товара применяется выбранная наценка к цене поставщика. |

Выбор «-», 0 или другого процента не переключает общий тумблер строки. Включённый тумблер остаётся включённым и при «-» в одной или всех колонках. Отдельно выключенный тумблер продолжает запрещать продажу по всем типам оплаты.

Пример: строка включена, Cash = «-», Online = 1% → Cash недоступен, Online доступен с наценкой 1%. Заменить Cash на 0 → Cash становится доступен без наценки; Online и общий тумблер не меняются.

| Тумблер строки | Значение в выбранной колонке | Результат для этого типа оплаты |
| --- | --- | --- |
| Выключен | Любое | Покупка запрещена. |
| Включён | «-» | Покупка запрещена только по этому типу. |
| Включён | 0 | Продажа без наценки этой страницы. |
| Включён | Положительный процент | Продажа с выбранной наценкой. |

Для всех разрешающих строк таблицы дополнительно нужны включённые «Закупка» и общие «Продажи», подходящий сток и остальные условия покупки. При «-» во всех колонках ни один тип оплаты не разрешает покупку, даже если тумблер строки включён.

Список значений управляется в «Конфигурациях». Числовые значения выводятся по возрастанию. При проверке состав и порядок нужно сверять с актуальным справочником, а не считать первоначальный набор постоянными ограничениями страницы.

### 5.2. Изменение родителя и вложенных строк

- Процент родителя применяется ко всем вложенным позициям выбранной связки и колонки и перезаписывает ранее заданные частные значения.
- Изменение категории обновляет её модели и варианты, включая свёрнутые и находящиеся ниже экрана строки; изменение модели — её варианты.
- Другие ветки, колонки и связки сохраняют свои значения.
- Выбор «-» у родителя перезаписывает значения всех потомков в выбранной колонке на «-» и запрещает их продажу только по этому типу оплаты. Остальные колонки и состояния тумблеров не меняются.
- Выбор 0 у родителя задаёт потомкам явную нулевую наценку, а не «-» или прежние частные проценты. Включённые позиции становятся доступны по этому типу без наценки при остальных выполненных условиях; отдельно выключенные тумблеры остаются выключенными.
- Значение можно изменить и сохранить у выключенной позиции либо позиции без стока. Это не включает ни локальный тумблер, ни выключенную «Закупку», ни общие «Продажи». Выбор «-» запрещает покупку по своему типу оплаты независимо от включённого локального тумблера.
- Сохранённая настройка предназначена в том числе для будущего товара. Проверка фактической цены выполняется после появления стока и готовности расчёта.
- Новая наценка относится к товару для продажи, а не является командой пересчёта уже оформленных заказов.

Пример перезаписи: задать двум моделям разные проценты, затем изменить процент их категории. Обе модели и их варианты получают новый процент категории, а не сохраняют исключения.

### 5.3. Начальные значения и восстановление страны

| Событие | Проценты | Тумблеры позиций |
| --- | --- | --- |
| Новый товар номенклатуры | «-»: продажа запрещена | Выключены по ТЗ, в том числе у нового варианта под ранее настроенным родителем. |
| Новый тип оплаты | Вся новая колонка «-»: покупка по новому типу запрещена | Прежние состояния сохраняются. Другие колонки не меняются. |
| Новая связка стран | Дефолтные «-»: продажа запрещена, проценты другой пары не копируются | Визуальное начальное состояние требует уточнения — **PCT-Q04**. |
| Восстановление страны | Значения её затронутых связок возвращаются к «-»: продажа запрещена, прежние проценты не возвращаются | Визуальное начальное состояние требует уточнения — **PCT-Q04**. |
| Возврат прежнего типа оплаты | Возвращаются его сохранённые проценты | Возврат колонки не подменяет состояние строк. |
| Другой тип с названием удалённого | Новая колонка «-»: покупка по ней запрещена, прежние значения не присваиваются | Прежние состояния сохраняются. Другие колонки не меняются. |

Дефолты при восстановлении страны относятся к настройкам страницы «Проценты». Это не отменяет отдельные правила сохранения КТ, рабочих дней, доставки и остальных настроек в «Закупке и реализации». Восстановление страны и возврат типа оплаты имеют разные правила для процентов.

## 6. Включение и выключение позиции

- Выключение снимает товар с продажи только в выбранной связке. Другие страны поставки и реализации сохраняют свои настройки.
- Выключение категории выключает все её модели и варианты; выключение модели — все её варианты, включая свёрнутые.
- **Включение самого родителя включает всех его детей** на всех вложенных уровнях.
- **Включение одного ребёнка при выключенном родителе** включает этого ребёнка и его предков до категории. Остальные дети остаются выключенными.
- Выключение последнего активного ребёнка **не выключает родителя**. Если выключен последний вариант модели, модель остаётся включённой; если выключена последняя модель категории, категория остаётся включённой.
- Поэтому включённый родитель сам по себе не означает, что все его дети включены. Для частично включённой ветки нужно проверять каждую строку.
- Бренд остаётся заголовком без тумблера при любых каскадах.
- Выключение тумблером или запрет значением «-» не удаляет номенклатуру, страны, поставщиков или клиентов. Тумблеры сохраняют числовые настройки колонок; выбор значения в колонке не переключает тумблер. Превращение 0 в «-» меняет разрешение продажи и не является допустимым форматированием.

После выключения позиции общим тумблером:

| Контур | Результат |
| --- | --- |
| Клиент | Не видит товар для покупки в выбранной связке. |
| Админский сток | Товар остаётся видимым как неактивный; на предоставленном скрине строки iPhone 15 приглушены. |
| Поставщик | Продолжает видеть товар и работать с ним. |

Включение позиции или выбор 0 не включает автоматически выключенную «Закупку» страны поставки или общие «Продажи» реализации. 0 означает отсутствие наценки, но не отменяет выключенный тумблер строки. Включение строки при сохранённых «-» в колонках не превращает эти значения в 0: продажа по соответствующим типам остаётся запрещена.

Если запрет задан только через «-» одной колонки, остальные разрешённые типы оплаты продолжают работать. Админ и поставщик не теряют товар из-за этого запрета; оформление смешанного состояния в админском стоке проверяется отдельно без предположения, что вся строка обязана выглядеть как полностью выключенная.

Поведение клиентских подписок при выключении тумблером, выборе «-» и последующем возврате продажи включено в отложенные проверки: зафиксировать, сохраняются ли подписки или удаляются. Ожидаемый результат по подпискам пока не задан — **PCT-Q07**.

## 7. Сохранение и ошибки

Процент и тумблер сохраняются сразу. Успешное сохранение проверяется сменой связки и возвратом, затем перезагрузкой страницы.

Массовое изменение родителя сохраняет всех затронутых потомков, а не только видимые строки. Настройка остаётся связана с той же позицией, парой стран и типом оплаты после обновления таблицы.

Сбой запроса не считается успешным сохранением. При прогоне фиксируются сообщение об ошибке, данные после повторной загрузки и возможность повторить изменение. Конкретный вид уведомления, визуальный откат и атомарность каскада отдельно не заданы; требование о тосте с другой страницы сюда автоматически не переносится.

## 8. Зависимость от «Конфигураций»

Предоставленный комментарий задачи описывает служебные настройки двух справочников:

- **Значения процентов:** можно добавлять и удалять, список сортируется по возрастанию. Нельзя удалить значение, установленное хотя бы у одного товара в любой связке. Настройка выключенного товара также остаётся установленным значением; отдельного исключения для него в комментарии нет.
- **Типы оплаты:** выбирается страна реализации, для неё доступны добавление, изменение, удаление и сортировка перетаскиванием. Названия RU/EN и иконка обязательны, название уникально внутри реализации. Иконка одна для светлой и тёмной темы: SVG/PNG до 2 МБ. Редактирование через карандаш в той же форме, сохранение кнопкой «Сохранить». Для удаления требуется подтверждение. Удаление разрешено при активных заказах; оформленные заказы продолжают штатную обработку до «Заказ выдан».

Это правила смежной конфигурации, а не дополнительные формы на странице «Проценты». Её собственная валидация и CRUD не входят в данный чек-лист; проверяются только результаты изменения справочников на странице и нужные межстраничные последствия.

## 9. Права и границы текущей проверки

ТЗ предусматривает просмотр и редактирование, настраиваемые в «Пользователях». **Все проверки прав отложены**, поскольку права ещё не реализованы.

Сейчас проверяются выбор стран, состав колонок на готовых данных, дерево, выбор из списка, сохранение и каскады внутри страницы. Создание номенклатуры, изменение конфигураций, жизненный цикл стран, фактические цены, сток, продажи, заказы и подписки проверяются после готовности зависимостей.

Для этой страницы действует правило текущего ТЗ: у бренда нет процента и тумблера. Отдельный механизм настройки или отключения бренда не установлен. Дополнительная наценка реселлера и наценка экспорта остаются отдельными правилами приложения.

## 10. Оставшиеся детали

- **PCT-Q04 — тумблеры новой/восстановленной связки.** Дефолт «-» уже означает запрет продажи. Осталось определить начальное состояние общего тумблера при создании и восстановлении связки; сам выбор «-» его не выключает.
- **PCT-Q05 — точная математика и обновление цены.** Возможность менять процент без стока и при выключенной позиции подтверждена. Остаются база и порядок применения курса/процента, точность и округление единицы/суммы, реакция уже открытого клиентского прайса.
- **PCT-Q06 — выбор стран.** Подтверждены настройка выключенных стран без их включения и дефолтные проценты при восстановлении. Остаются обработка удалённых стран в фильтрах, пустые списки и первоначальный выбор пары.
- **PCT-Q07 — результат проверки подписок.** По поручению пользователя сценарий включён в отложенный чек-лист. При прогоне зафиксировать судьбу подписок и область действия; до согласования результата не объявлять ни сохранение, ни сброс обязательным поведением.

Ошибки, конкурентные изменения и агрегированное отображение родительского процента исследуются по разделу 2 чек-листа без выдуманных требований к интерфейсу.
