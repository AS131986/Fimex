# Fimex QA Docs

Structured QA documentation for Fimex, separated by product area.

## Areas
- `admin/` — admin panel
- `mobile-buyer/` — buyer mobile application
- `supplier-lk/` — supplier personal account
- `shared/` — cross-system artifacts shared across areas

## Supplier LK
- `supplier-lk/01-product-overview/` — product context and scope
- `supplier-lk/02-modules/` — module-level notes
- `supplier-lk/03-pages/` — page descriptions and UI behavior
- `supplier-lk/04-business-rules/` — business rules and constraints
- `supplier-lk/05-test-design/` — checklists, scenarios, and coverage
- `supplier-lk/06-bugs-and-risks/` — bug notes and known risks
- `supplier-lk/07-open-questions/` — unresolved questions and dependencies
- `supplier-lk/08-test-data/` — test data sets and prerequisites
- `supplier-lk/09-integrations/` — integration-specific notes
- `supplier-lk/10-api-notes/` — API observations and mismatches
- `supplier-lk/11-access-and-roles/` — roles, permissions, and data isolation
- `supplier-lk/12-regression/` — regression packs and impact notes
- `supplier-lk/templates/` — reusable templates
