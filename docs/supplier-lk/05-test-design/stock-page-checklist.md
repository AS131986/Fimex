# Stock page checklist

Scope: Supplier LK → `Stock`

## 1. Добавление товара в сток

### 1.1. Выбор даты
- [ ] **SLK-STOCK-001 — Доступность текущей даты до КТ без выходных**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Открыть `Add Stock` до КТ, без `admin holiday` и `supplier holiday`**
  - **Ожидаемый результат:** текущая дата доступна.

  </details>

- [ ] **SLK-STOCK-002 — Недоступность текущей даты после КТ и в выходные**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Открыть `Add Stock` после КТ / при `admin holiday` / при `supplier holiday` на текущую дату**
  - **Ожидаемый результат:** текущая дата недоступна.

  </details>

- [ ] **SLK-STOCK-003 — Доступные даты окна продаж**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Открыть `Add Stock`, когда часть ближайших дней недоступна**
  - **Ожидаемый результат:** показаны только доступные даты из окна продаж.

  </details>

- [ ] **SLK-STOCK-004 — Открытие товаров выбранной даты**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Выбрать дату в стартовом окне**
  - **Ожидаемый результат:** открывается список товаров для выбранной даты.

  </details>

- [ ] **SLK-STOCK-005 — Пересчёт товаров при смене даты**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Сменить дату уже в окне выбора товара**
  - **Ожидаемый результат:** список товаров и состояния пересчитываются под новую дату.

  </details>

- [ ] **SLK-STOCK-006 — Отсутствие старого количества после смены даты**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Сменить дату в окне выбора товара с даты, где товар уже есть, на дату, где его нет**
  - **Ожидаемый результат:** количество/состояние товара обновляется под новую дату, старые данные не остаются.

  </details>

- [ ] **SLK-STOCK-007 — Real-time недоступность даты открытой формы**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Оставить `Add Stock` открытым до наступления КТ / назначения `admin holiday` / `supplier holiday`**
  - **Ожидаемый результат:** дата становится недоступной без refresh.

  </details>

- [ ] **SLK-STOCK-008 — Запрет добавления на недоступную дату**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Попробовать добавить товар на дату, ставшую недоступной при открытой форме, или на дату вне списка доступных**
  - **Ожидаемый результат:** отображается ошибка, товар не добавляется.

  </details>

### 1.3. Уже добавленные товары в `Add Stock`

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Открыть `Add Stock` на дату, где товар A уже добавлен**

  </details>

  <details>
  <summary>Подробности проверки</summary>

  </details>

  </details>

- [ ] **SLK-STOCK-017 — Запрет редактирования чужого количества разными способами**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Попробовать изменить количество чужого товара через inline-edit / Enter / клик вне поля**
  - **Ожидаемый результат:** изменение не сохраняется.

  </details>

- [ ] **SLK-STOCK-018 — Актуализация количества от другого пользователя**

  <details>
  <summary>Подробности проверки</summary>

  - **Проверка:** **Изменить количество товара A другим пользователем при открытом `Add Stock`**
  - **Ожидаемый результат:** отображаемое `Q-ty` обновляется корректно.

  </details>
