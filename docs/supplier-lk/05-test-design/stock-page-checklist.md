# Stock page checklist

Scope: Supplier LK → `Stock`

Правила таргетирования обновлены по уточнениям пользователя от 31 октября 2026 года. Проверки приложения и API не выполнялись. `[ ]` не означает Fail; результаты будущего прогона фиксируются отдельно.

Условия проверок таргетирования:
- Все товары — iPhone 13 128 GB Midnight, если в пункте не указано другое. Brazil, Argentina, Australia, Japan и USA в названии товара — страны устройств; ОАЭ и США у поставщика — страны поставщиков.
- Первая, следующая и третья даты — доступные даты товара в Stock поставщика, по порядку. Дата доставки клиента не заменяет дату Stock.
- Если разные даты явно не указаны, товары пункта находятся на одной дате Stock. Участвуют только перечисленные предложения; остальные конкуренты исключены из набора данных.
- Поставщики всех стран участвуют совместно. Rank и подсказка считаются отдельно по датам; одинаковые цены разных стран устройств дают рейтинг 1, 1, 2. Цена одного товара одной страны устройства уникальна только внутри одной даты.
- Дальний товар той же страны устройства виден клиенту только при строго меньшей цене; при равной или большей цене скрыт. Это не меняет его рейтинг в Stock поставщика.
- Продажа разрешена, количества достаточно. Для сравнения цен в клиентских сценариях использовать основного покупателя, нулевые наценки и заполненный тариф карго 0; гарантию не выбирать. Если пункт задаёт иные условия, использовать их.
- Реальное состояние клиентского прайса сверять после повторного открытия. Это не заменяет проверки real-time обновлений Supplier Stock.
- Для цепочки из трёх занятых цен и новой записи нужны четыре поставщика; в набор включить поставщиков ОАЭ и США. Автоперенос настраивать так, чтобы отдельно оговорённые записи целевой даты не переносились вместе с проверяемой.
