# Test Design

Этот раздел содержит тест-дизайн для Mabetex Buyer mobile app.

## Что хранить здесь
- test strategy;
- test matrix;
- checklists;
- positive / negative scenarios;
- edge cases;
- boundary values;
- flow coverage.

## Рекомендация
Держать сценарии так, чтобы их было удобно переиспользовать для regression.
