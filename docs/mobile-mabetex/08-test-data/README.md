# Test Data

Этот раздел содержит тестовые данные для Mabetex Buyer mobile app.

## Что хранить здесь
- users;
- corporate accounts;
- products;
- variants / SKUs;
- offers;
- orders;
- payments;
- shipments;
- invoices;
- edge-case datasets.

## Рекомендация
Данные лучше держать по типам, чтобы было проще собирать сценарии.
