# Mabetex Buyer Mobile App Docs

Этот каталог содержит документацию по **Mabetex Buyer mobile app**.

## Назначение
Здесь хранятся:
- product overview;
- modules;
- screens;
- business rules;
- test design;
- bugs and risks;
- open questions;
- test data;
- integrations;
- api notes;
- access and roles;
- regression.

## Правила
- Этот контур относится только к **Mabetex Buyer mobile app**.
- Не смешивать с `docs/mobile-buyer/`.
- Общие cross-contour артефакты хранить только в `docs/shared/`, если это действительно необходимо.
- Если есть сомнение, по умолчанию использовать `docs/mobile-mabetex/`.

## Как работать
- Новые документы размещать в соответствующем разделе.
- Для каждого раздела желательно иметь `README.md` как точку входа.
- Для экранов, сценариев и правил использовать шаблоны из `templates/`.
