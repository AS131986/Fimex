# Templates for Mabetex Buyer Mobile App Docs

Этот раздел содержит шаблоны для документов Mabetex Buyer mobile app.

## Зачем нужны шаблоны
Шаблоны помогают:
- поддерживать единый формат;
- ускорять создание документов;
- не терять важные поля;
- облегчать сравнение с Fimex;
- унифицировать QA-документацию.

## Доступные шаблоны
- `template-page.md`
- `template-module.md`
- `template-screen.md`
- `template-business-rule.md`
- `template-test-case.md`
- `template-bug.md`
- `template-open-question.md`
- `template-test-data.md`
- `template-integration.md`
- `template-api-note.md`
- `template-role.md`
- `template-regression.md`

## Рекомендация
При создании новых документов:
1. выбирай подходящий шаблон;
2. заполняй только подтвержденные данные;
3. отдельно отмечай assumptions;
4. не смешивай facts и guesses.
