# Modules

Этот раздел содержит описание функциональных модулей Mabetex Buyer mobile app.

## Что хранить здесь
- module overview;
- responsibilities;
- related entities;
- entry points;
- main flows;
- negative scenarios;
- module-level risks.

## Рекомендация
Каждый модуль описывать отдельным файлом.
Если модуль большой — можно добавлять подпапку со screen-level деталями.
