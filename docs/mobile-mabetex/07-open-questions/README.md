# Open Questions

Этот раздел содержит открытые вопросы по Mabetex Buyer mobile app.

## Что хранить здесь
- product questions;
- business rule clarifications;
- API / integration gaps;
- screen behavior questions;
- access / role questions;
- unresolved assumptions.

## Рекомендация
Каждый вопрос фиксировать так, чтобы было понятно:
- почему он важен;
- какой риск несет;
- что будет, если его не уточнить.
