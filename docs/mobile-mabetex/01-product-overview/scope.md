# Scope

## In scope
- Buyer mobile app features
- catalog
- search
- PDP
- cart
- checkout
- orders
- invoices
- payments
- shipments
- purchase history
- corporate account flows, if applicable

## Out of scope
- Supplier-side features
- Admin-side features
- unrelated shared documentation unless explicitly cross-contour

## Risks
- Scope creep if shared artifacts are copied without clear ownership.
