# Integrations

Этот раздел содержит описание внешних и внутренних интеграций Mabetex Buyer mobile app.

## Что хранить здесь
- payment integrations;
- shipment integrations;
- notification integrations;
- auth / identity integrations;
- price / stock sync notes;
- any cross-system dependencies.

## Рекомендация
Для каждой интеграции фиксировать:
- направление;
- trigger;
- payload-level notes;
- success/failure behavior;
- risks.
